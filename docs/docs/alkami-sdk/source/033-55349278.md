Whether you’re pushing pixels, crafting code, or weaving words, it helps to have design patterns to follow. It makes creating web and mobile experiences easier, saves time, and ensures we’re always aligned with what we’re building. With Iris, you’ll find everything is all in one place. We’re happy you’re here.

The current design system component libraries, known as Iris 2, are all built to meet the direction and vision of Alkami Design. The alkami.design website (https://www.alkami.design/) is where can learn about the principles (https://www.alkami.design/) behind the Alkami Design Language and dive into the specific use cases and design documentation of over 35 components (https://www.alkami.design/components) that make up Iris 2.

### Setting up Iris Vue in your widget
#### Using Iris Vue (Vue.js based Iris 2 components)

The Iris 2 component library became available to Alkami SDK clients with the Iris Vue library in February 2022. This is the same code library that Alkami uses internally, so you can be sure that your custom widgets take on the same look and feel as Alkami-built experiences.

Whereas the documentation links above provide general information about each component, in-depth technical documentation for all the Vue.js (https://vuejs.org/) (version 2.x) components can be found at iris-vue.alkami.design (https://iris-vue.alkami.design).

#### Original Iris component library is end of lifeReplaced with Iris 2

The original Iris Design System, now called "Iris Classic (https://iris.alkamitech.com/)" is has been replaced with a more modern approach to Design and front-end code utilizing Vue.js (https://vuejs.org/) (version 2.x).
