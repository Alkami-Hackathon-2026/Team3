Alkami.Patterns is a collection of regex patterns that are shared across the application.

More will be added soon. If you have one in mind, please submit a PR to the orb-shell-js (https://bitbucket.corp.alkamitech.com/projects/UP/repos/orb-shell-js/browse) repository!

#### POBox (RegExp)

RegEx to validate a PO Box address.

Example

```
if (address1.match(Alkami.Patterns.POBox)) {
errors.push(Alkami.Localization.SiteText["Addresses.CannotBePOBox"]);
}
```
