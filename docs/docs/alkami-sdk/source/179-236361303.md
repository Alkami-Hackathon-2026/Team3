This is a list of commands that comes with the Alkami.Powershell.SDK tooling.

| Command | Summary |
| ### Get-SDKSupport | A function that gets system information and all SDK/Alkami installed packages along with the Windows Experience Index. There will be a file location provided as the output of this command |
| ### Install-SDKRelease | A function that installs or updates an SDK Release.Switches-latest: This will install or upgrade to the latest released SDK version Parameters-VersionType: stringValue for this should be the desired SDK Version-FeaturesType: stringValue for this is tab-completed and typically includes API or similar |
| ### New-SDKMachineSetup | A function that encapsulates the setup of a new machine and completes the operations found on Hardware and Software Requirements.Switches-Alkamist: Use this if you are an Alkamist-Daily Use this if you are wanting to use the Daily feedParameters-UsernameType: stringValue for this should be the username that was configured for the package feedMandatory: true-PasswordType: stringValue for this should be the username that was configured for the package feedMandatory: true |
| ### Remove-SDK | A function that will remove some or all SDK artifacts from a machine.Switches-sites: This switch will remove the standard sites(DeveloperDynamic WebAdmin and ClientFacing) and supporting files. -appPools: This switch will remove the App pools that were created by Alkami-devDb: This switch will remove the DeveloperDynamic DB-MainDb: This switch will remove the AlkamiMaster DB-Hard: This switch will combine all of the ones above, and will remove everything, including Port Exclusions and nuget/choco sources. This will require a full install from scratch to come back from. |
| ### Remove-SDKServices | A function that will remove window services from the services registry where the name contains "Alkami". There is a "Are you sure?" prompt to continue removal of the services. |
| ### Restart-SDKServices | A function that will restart all of the Alkami services on a machine, including Redis. |
| ### Restart-SDKWebClients | A function that will restart the WebClient and WebAdmin IIS processSwitches-ClearTempIf supplied the Temp ASP.NET files will be removed. |
| ### Set-SDKServiceRecovery | A function that will set the recovery options for (One or All)Alkami SDK Service(s)Parameters-ServiceNameType: stringMandatory: trueFormat for multiple: '{FullServiceName1}','{fullServiceName2}' Do not include curly bracesCan use 'All' for all ALkami services-ActionType: stringMandatory: falseDefault Value = 'TakeNoAction'Options:'TakeNoAction','recovery' |
| ### Set-SDKServiceStartupType | A function that will set the start up mode for (One, Some, or All) Alkami Window Service(s)Parameters-ServiceNameType: stringMandatory: trueFormat for multiple: @('{FullServiceName1}','{fullServiceName2}') Do not include curly bracesCan use 'All' for all Alkami services-StartupTypeType: stringMandatory: falseDefault Value = 'Manual'Options:'Automatic','Disabled','InvalidValue','Manual'Note: if you want auto start (delayed) then you need to use a command like this:sc.exe config Alkami.MS.Householding.Service.Host start= delayed-auto |
| ### Start-SDKServices | A function that starts both IIS and Alkami window services Parameters-maxParallelType: integerMandatory: falseDefault Value = 10 |
| ### Stop-SDKServices | A function that stops all running Alkami SDK services |
| ### Update-DeveloperModules | A function that is used to update developer modules in a consistent manner. This is useful for reducing manual module management by developers. This function does not look for advanced modules to be downloaded, and will only update local modules. |
### How to update Alkami.Powershell.SDK
Powershell Upgrade

```
choco upgrade Alkami.Powershell.SDK -y
```
