## Parameters

Usual parameters asked for JWT creation are the following:

- Payload
- Headers
- CertificateThumbprint
- HMACSecretKey
- TokenExpiryInMinutes
- SigningAlgorithm
#### Required
- Payload
- SigningAlgorithm
- TokenExpiryInMinutes
- CertificateThumbprint ((conditional))
- HMACSecretKey (conditional)
## Certificates

Signing certificates should be generated by Alkami as they provide the vendor with the signature of who is issuing the JWT and is done with a private key (pfx).

Please see Installing Encryption & Signing Certificates for StandardSSO (/spaces/SDKC/pages/556889814/Installing+Encryption+Signing+Certificates+for+StandardSSO) for how to install these certificates.

## Parameters Details
- Payload - Payload contains the list of key value pairs of strings which will be payload/data in JWT. This value is required.
- Headers - Headers contains the list of key value pairs of strings which will be added in header of JWT. This is optional. By default, JWT header will have 'alg' and 'type' values in header. 'alg' will have a value of 'SigningAlgorithm' and 'type' will be 'jwt'.
- SigningAlgorithm - This value is required. Signing algorithms supported are as belowHS256HS384HS512RS256RS384RS512PS256PS384PS512ES256ES384ES512
- TokenExpiryInMinutes - This value is required. This is the token expiry value in minutes.
- CertificateThumbprint - This value is required conditionally when signing algorithm is one of the types in RS256, RS384, RS512, PS256, PS384, PS512, ES256, ES384, ES512. This will be the thumbprint of the certificate to be used for signing the token.
- HMACSecretKey - This value is required conditionally when signing algorithm is one of the HMAC algorithms i.e., HS256, HS384, HS512HMAC secret key has validation for the minimum key length based on algorithm as belowHS256 - 32 bitHS384 - 48 bitHS512 - 64 bit
## JWE Params
### With JWK
- Payload - Payload contains the list of key value pairs of strings which will be payload/data in JWT. This value is required.
- JWK - This is a standard JWK object as shown below. Currently Accepted Algorithms belowRSA1_5RSA_OAEPRSA_OAEP_256
- JweEncryptionAlgorithm - Used to determine the Encryption Algorithm for the payload. This value is required.A128CBC_HS256A192CBC_HS384A256CBC_HS512A128GCMA192GCMA256GCM
JWKExample

```
{
"BankIdentifier": "d0dcff30-5618-40dc-9570-76ad416a16cb",
"ProviderName": "Cotribute",
"Description": "Cotribute",
"HttpRequest": {
"DisplayLocation": "NewWindow",
"Uri": "https://onboard-api-uat.cotribute.co/prefill-requests?",
"Method": "Post",
"ContentType": "application/json",
"QueryParameters": {
"JWT": "{{ Jwt('JwtToken') }}",
},
},
"Services": [{
"Key": "JwtToken",
"Jwt": {
"Request": {
"Payload": {
"prefillTemplateUuid": "SomePayloadValue",
"completionRedirectURL": "url.com"
},
"JWK": {
"kty": "RSA",
"kid": "AnExampleKid",
"use": "enc",
"alg": "RSA_OAEP",
"e": "AQAB",
"n": "AnNValueHere"
},
"TokenExpiryInMinutes": "60",
"JweEncryptionAlgorithm": "A256GCM"
}
}
}
]
}
```

### With Cert
- Payload - Payload contains the list of key value pairs of strings which will be payload/data in JWT. This value is required.
- CertificateThumbprint - Thumbprint of the certificate used for Signing and Encryption. Required
- CertKeyType - The algorithm used for Signing. RequiredRSA1_5RSA_OAEPRSA_OAEP_256
- JweEncryptionAlgorithm - Used to determine the Encryption Algorithm for the payload. This value is required.A128CBC_HS256A192CBC_HS384A256CBC_HS512A128GCMA192GCMA256GCM
JWEWithCert

```
{
"BankIdentifier": "d0dcff30-5618-40dc-9570-76ad416a16cb",
"ProviderName": "JWECertTest",
"Description": "JWECertTest",
"HttpRequest": {
"DisplayLocation": "NewWindow",
"Uri": "https://someUrl.com/testest",
"Method": "Post",
"ContentType": "application/json",
"QueryParameters": {
"JWT": "{{ Jwt('JwtToken') }}",
},
},
"Services": [{
"Key": "JwtToken",

"prefillTemplateUuid": "SomePayloadValue",

"CertKeyType": "RSA_OAEP_256",
"JweEncryptionAlgorithm": "A256GCM"
}
}
}
]
}
```

### Field Level Encryption Example

This is an example of defining a service, and then using it to pass in specific params to encrypt the plain text of an expression. In this case it is used to encrypt only the form values, not the entire form.

JWKExample

```
{
"BankIdentifier": "d0dcff30-5618-40dc-9570-76ad416a16cb",
"ProviderName": "Cotribute",
"Description": "Cotribute",
"HttpRequest": {
"DisplayLocation": "NewWindow",
"Uri": "https://onboard-api-uat.cotribute.co/prefill-requests?",
"Method": "Post",
"ContentType": "application/json",
"FormFields": {
"prefillTemplateUuid": "73a06193-41da-488e-9eac-6d5fc5b7433b",
"ssn": "{{ Jwt('JwtToken', TaxId) }}",
"firstName": "{{ Jwt('JwtToken', FirstName) }}",
"lastName": "{{ Jwt('JwtToken', LastName) }}",
"Email": "{{ Jwt('JwtToken', Email) }}",
"birthday": "{{ Jwt('JwtToken', BirthDate('yyyy-MM-dd')) }}",
"address": "{{ Jwt('JwtToken', AddressLine1) }}",
"city": "{{ Jwt('JwtToken', City) }}",
"state": "{{ Jwt('JwtToken', State) }}",
"zip": "{{ Jwt('JwtToken', PostalCode) }}",
"completionRedirectURL": "url.com"
}
},
"Services": [{
"Key": "JwtToken",
"Jwt": {
"Request": {
"Payload": {
"prefillTemplateUuid": "SomePayloadValue",
"completionRedirectURL": "url.com"
},
"JWK": {
"kty": "RSA",
"kid": "AnExampleKid",
"use": "enc",
"alg": "RSA_OAEP",
"e": "AQAB",
"n": "AnNValueHere"
},
"JweEncryptionAlgorithm": "A256GCM"
}
}
}
]
}
```
