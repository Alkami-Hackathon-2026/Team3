This module provides methods and a component to interact with Alkami's Multi-factor Authentication features.

### Examples
#### Using Alkami.Security.Post

Check out Alkami.Helpers.ajax (https://bitbucket.corp.alkamitech.com/projects/UP/repos/orb-shell-js/browse/docs/alkami-helpers.md#ajax) for more examples.

NOTE: Catch the failed promise. A user clicking the cancel button is a rejection.

```
Alkami.Security.post({
url: '/Settings/Security/UpdatePassword',
data: {
PasswordCurrent: 'Test12345!',
PasswordNew: 'Test12345!',
PasswordConfirmation: 'Test12345!',
},
contentType: 'application/x-www-form-urlencoded'
}).then((request) => request.json())
.then((body) => console.log(body))
.catch((error) => console.error(error));
```

#### Using the MFA Component outside a modal

```
Alkami.Security.post({
url: '/Settings/Security/UpdatePassword',
data: {
PasswordCurrent: 'Test12345!',
PasswordNew: 'Test12345!',
PasswordConfirmation: 'Test12345!',
},
contentType: 'application/x-www-form-urlencoded',
mfaAction: (data) => {
const { verificationToken, transactionId } = data;
const containerElement = document.getElementById('element_to_insert_mfa');
const submitButtonElement = document.getElementById('button_to_submit_mfa_forms');
let mfaComponent;

return Alkami.Security.MFAComponent.init({
submitButtonElement: submitButtonElement,
escalationKey: verificationToken,
transactionId: transactionId
}).then((mfa) => {
mfaComponent = mfa;
containerElement.appendChild(mfaComponet.element);
return mfaComponent.promise;
}).then(() => {
mfaComponent.destroy();
});
},
}).then((request) =\> request.json())
.then((body) =\> console.log(body))
.catch((error) =\> console.error(error));
```

### API
#### Security Ajax Options (SecurityAjaxOptions)

```
interface SecurityAjaxOptions extends AjaxOptions {
url: string; // URL to send the request to
contentType?: string; // The content type to use.
// Popular ones would be:
// * application/x-www-form-urlencoded
// * multipart/form-data
// * application/json
headers?: { [key: string]: string }; // Key value pair of headers for the request
data?: string | {} | FormData | URLSearchParams; // Data to send to the server
responseType?: 'xml' | 'html' | 'json' | 'text'; // The type of data expected back from the server
method: 'GET' | 'HEAD' | 'POST' | 'PUT' | 'DELETE' | 'CONNECT' | 'OPTIONS' | 'TRACE' | 'PATCH'; // The HTTP Method to use to send the data. `POST` by default.
mfaAction?: function that initializes the MFA component for you. defaults to using initMFAModal
}
```

#### post(options)

does an ajax post and determines if MFA is required or not. See [Alkami.Helpers.ajax](AjaxOptions (https://bitbucket.corp.alkamitech.com/projects/UP/repos/orb-shell-js/browse/docs/alkami-helpers.md#ajax) for more detail on ajax calls.

Arguments

- options (SecurityAjaxOptions)

Returns

- (Promise<Response>): Returns a promise that resolves into the response. The Promise will reject if the HTTP Request fails or has a response code not in the 200s.
#### MFAComponent

A component that wraps the MFA process. This component gets included by default into the Alkami.Security.post function but can be used separately when needed to be integrated into a workflow.

##### MFAComponent.init(options)

Helper function to get a fully functional MFAComponent instance

Arguments

- options (MFAComponentOptions)

Returns

- (Promise<MFAComponent>): Returns a promise that resolves to a MFAComponent ready for use.
##### MFAComponent.insertStyles()

Helper function to install the MFA styles needed for the component.

Returns

- (Promise<HTMLLinkElement>): Returns a promise that resolves if the css loaded without error.
##### new MFAComponent(options)

Build an MFA Component to be used to verify MFA.

Arguments

- options (MFAComponentOptions & IMFAModelResponse)

Returns

- (MFAComponent): Returns an MFA Component.

Properties

element - HTMLElement - get the HTML element that the MFAComponent is bound.

promise - Promise<void>- get the promise that signals the success of the MFA process.

#### MFA Component Options

```
interface MFAComponentOptions {
submitButtonElement: HTMLButtonElement; // Button to tie form functions to
escalationKey?: string; // Escalation Key to send with MFA answers
transactionId?: string; // Transaction ID to send with MFA answers
}
```
