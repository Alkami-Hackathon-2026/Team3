A dashboard module is really just a partial view in one of your Widgets.

## Create a Partial View

To create a partial view, your controller will use PartialView(), instead of View(). Following is an example or a return statement for a partial view

SomeMvcController.cs

```
return PartialView("ExamplePartial", model);
```

For a partial view you will not include the sections that a full view contains. Here's a simple example of the view file

ExamplePartial.cshtml

```
@model Sample.Client.Widget.DashboardModule.Models.SampleDashboardModuleModel

<div id="help">
<span style="font-weight:bold;">(Sample1) This is a Module from the SDK</span>
<br />
<h2>Message: @Model.BannerMessage</h2>
<br />
This was created using a partial view in a Widget built using the Alkami SDK.
```

## Define and Position the Module

To define the module you will use the User Interface Settings admin feature.

Select the Modules tab, then click on Add Module.

Now enter the details describing the partial view (module). Give the module a name. This name will appear above the module on the dashboard. Desktop is the only supported platform at the current time. The Path is the url slug for displaying the partial view you created in your Widget. After you fill out these fields, save the module definition.

Now, use the Layout tab to place the module on the dashboard. Click the Edit button, then click on Add Module.

Check the box next to your module and save it.

The module will now appear with the other modules on the layout. Click the title of the module to drag it to the desired location then save the layout. Now login as a user and you will see your module on the dashboard. The User Interface Settings take effect immediately.
