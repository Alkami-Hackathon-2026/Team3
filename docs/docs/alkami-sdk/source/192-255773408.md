Release notes:

We encourage you to upgrade your SDK environments to this version soon so you will be able to test with the same version that is in the Alkami Stage environment and will soon be in the Production environment.

As always, please be sure you follow the current version of the SDK installation and instructions as posted on https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html (https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html)
These instructions are frequently updated.

Don't forget that if you have a stage-match site that you may need to also manually upgrade the core-specific chocolatey packages related to the core connection. If your stage-match site is not working after the upgrade, check the website configuration in the IIS Manager. You might have extra sites defined, or incorrect bindings for the WebClient and WebClientAdmin sites, or the bindings that are there are missing the selection of the certificate. If you have sites listed in the IIS manager with the name admin-developer.dev.alkamitech.com (http://admin-developer.dev.alkamitech.com), developer.dev.alkamitech.com (http://developer.dev.alkamitech.com), or ip.dev.alkamitech.com (http://ip.dev.alkamitech.com) you will want to remove them and rely on the sites named WebClientAdmin, WebClient, and IPSTS.

There are some helpful troubleshooting and support tips on https://confluence.alkami.com/sdk/common-support-solutions-216493829.html (https://confluence.alkami.com/sdk/common-support-solutions-216493829.html) if you need them.

If you have a stage-match site and are using a Symitar core, don't forget to upgrade the SymConnect package as listed on the Confluence instructions.
