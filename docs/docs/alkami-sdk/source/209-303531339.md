Alkami.Localization includes methods used for acquiring and using localizable content in the Alkami Platform.

### Site Text

Site Text provides a way to utilize Alkami Platform localized and configurable text.

#### get(siteTextKey, arg1?, arg2? ...)

Utilize Site Text localization keys for the currently selected locale. Provide multiple arguments to replace formatted placeholders that are 0 index based. e.g. 'There are {0} shoes.' By default all global and current widget's Site Text is available.

Arguments

- siteTextKey (string)
- arg1? (string)
- arg2? (string)

Returns

- (string): Returns the localized string represented by the key provided or an empty string if the key doesn't exist.

Example

```
const userNoticeElement = document.querySelector('.user-notice');
userNoticeElement.innerText = Alkami.Localization.SiteText.get('Widget.User.Notice');

const disclaimerElement = document.query('.disclaimer');
// Widget.Disclaimer.Text = 'Hello {0}, Please accept our disclaimer.'
disclaimerElement.innerText = Alkami.Localization.SiteText.get('Widget.Disclaimer.Text', 'Mike Brady');
```

#### SiteText[siteTextKey]

You may see this pattern being used throughout the application. This method is discouraged. Utilizing SiteText in this way will return undefined if the value does not exist. It also does not provide a simple way to handle formatted placeholders.

Returns

- (string | undefined): Returns the localized string represented by the key provided or undefined if the key doesn't exist.

Example

```
const element = document.querySelector('.user-notice');
element.innerText = Alkami.Localization.SiteText['Widget.User.Notice'] || '';
```
