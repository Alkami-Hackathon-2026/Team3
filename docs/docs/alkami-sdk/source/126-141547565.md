Future Feature in 2021.05

Before ORB version 2021.05 is that there was not a way to reset the are you still here timer when working inside an IFrame.

Place this code in the parent page:

Parent page

```
parentFunction eventHandler() {
window.parent.postMessage('idletimeout-reset');
}
```

Place this code in the Iframe:

IFrame Code

```
['keydown', 'mousedown', 'touchstart', 'touchend'].forEach((eventName) => {
document.addEventListener(eventName, eventHandler);
}
```
