### My First SSO Provider

The following example describes what the SSO (Single Sign-On) provider service is and how to create a service with Alkami's Visual Studio template.

Developers use SSO Provider services to define configurable settings and their Single Sign-On implementation. Widgets can use these services to automatically log in logged in users to other associated applications or domains. Manage the settings from Alkami's Admin Portal. To do this, go to the Setup menu and select Integration Settings>Providers. Admin users can manage those settings without requiring code changes.

### Generic SSO

The Generic SSO provides a standardized contract for communicating with a microservice to accomplish a Single SignOn. There are several Alkami Widgets that know how to call this contract, and there are several Alkami-built microservices that can respond to these calls.

Using the SDK, you can build your own custom widget and call one of the Alkami microservices* or you can use the SDK to built a custom microservice using the Generic SSO template and configure the Alkami system to execute the SSO using your service.
