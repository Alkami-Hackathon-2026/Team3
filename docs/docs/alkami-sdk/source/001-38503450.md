## Install the Alkami SDK Templates

Alkami's templates are installed using the chocolatey package manager.

Close Visual Studio

Before running this install, close any open instances of Visual Studio.

Run the following command to add them to your Visual Studio 2022 instance.

```
choco install Alkami.SDK.Templates -y
```

## Available Templates
| Template | Description |
| Admin Widget | Create an admin widget for the Alkami admin web platform. |
| Card Management Service | The project template for a card management provider service. Creates the projects and files for a new Card Management provider service. |
| Client Widget | Create a client widget for Alkami web client application. |
| Embedded Snippet | Create an embedded snippet to extend an existing client widget in Alkami's web client application. |
| Event Processor | Framework and references needed to create an Event Management Processor. |
| Facts Provider | Contains the framework and references needed to create an Alkami facts provider. |
| Logical Service | Contains the framework and references needed to create a logical microservice as well as the corresponding client and tests. |
| Provider Service | Contains the framework and references needed to create a distributed provider based micro service as well as the corresponding client and tests. |
| Quick Apply Service | Creates projects necessary for a new Alkami QuickApply Provider micro service. |
| Slim Logical Service | Contains the framework and references needed to create a minimal service as well as the corresponding client. |
| Single Sign On Service | Contains the framework and references to build a Generic SSO microservice. |
