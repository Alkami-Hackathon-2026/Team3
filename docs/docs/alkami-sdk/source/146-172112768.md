The SDK team will assist with configuring and getting your SDK microservices and widgets up and running in your Staging environment. However, when it comes time to shift over to Production, the PSO group will step in to assist with the last steps. This only applies to new widgets/services. If you're simply upgrading an existing item, then PSO does not need to be involved.

Please engage the PSO team in your ticket by directing a comment to "@PSO" (this does not trigger a Jira group reference in the ticket, but is a visual cue for the team).

### Configuration
- The PSO team will copy the settings of the widget and/or microservice that has been validated in Staging over to the Production environment. This process should be coordinated with a pod bounce. All new widgets require a pod bounce before they'll become available to use.
- If there are settings/values that are different between Staging and Production, these differences will need to be added in the comment. Otherwise, the exact settings from Staging will be copied to Production.
### Pilot Testing
- For new widgets in Production, it's recommended to "Pilot" test these in an isolated package before taking live to your full membership. This will allow you to validate that the feature is functioning as expected in a Live environment before rolling out to all users.
- Along with the configuration request (item #1), please include the name of your test/pilot package. We'll add the widget and - following the pod bounce - you'll be able to add users to the pilot package and test the functionality. If you don't have a Pilot/Test package created, please request one and we can clone or duplicate another package (for example, "Please clone our Default Retail package to create a new SDK Test Package").
