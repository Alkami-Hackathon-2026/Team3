Warning

Please review the Code Guidelines and Standards (/spaces/SDKC/pages/51352122/Code+Guidelines+and+Standards) before submitting projects to Alkami. It's important to adhere to these standards in order to have a successful submission.

Be sure to test the package you are submitting using the choco install command. Many issues arise from untested packages being submitted to Alkami. The Visual Studio mechanisms for deploying your code during development is not sufficient to test the integrity of a package. Please make sure to QA any work before submitting.
