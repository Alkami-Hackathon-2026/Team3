Before completing your virtual training session with the Alkami SDK Team, you must have an environment that is properly prepared for this training, so we start immediately on the first day. Even if we have already spent some time with you testing the basic operation of your SDK environment, please follow the steps in this document to ensure everything is covered. If you are using a virtual machine for the SDK, follow these steps in the VM.

This final prep and readiness check assumes you have already installed the SDK by following the steps on these pages:
Hardware and Software Requirements (/spaces/SDKC/pages/55347103/Hardware+and+Software+Requirements)
SDK Machine Setup (/spaces/SDKC/pages/40403249/SDK+Machine+Setup)

If you have difficulty with the setup, or the following setup and validation steps in this document and cannot resolve them on your own, contact the Alkami SDK team and we will work with you to resolve your issue. Do not defer the resolution until the training day unless we tell you to do so.

### Credentials

Check to make sure you can log into each of the following online systems and that you know what the credentials are:
● https://jira.alkami.com/ (https://jira.alkami.com/)
● https://confluence.alkami.com/display/SDKC (https://confluence.alkami.com/display/SDKC) (same credentials as Jira in the previous bullet)
● https://feeds.alkamitech.com/ (https://feeds.alkamitech.com/)

## Software Application Validation

Use the steps in Logging Into Developer Dynamic On Your Local SDK (https://confluence.alkami.com/display/SDKC/Logging+Into+Developer+Dynamic+On+Your+Local+SDK) to validate your local build.

## Your Workspace

We strongly recommend that you have two monitors to view the web meeting on one monitor and perform your SDK tasks on the other.

● We recommend that you clear your calendar of all other items during the training sessions the same as you would for an in-person training session.

● Make sure the room you will be using is comfortable and is not too noisy. If there is background noise, we recommend that you have a headset.
At a minimum, know how to mute your computer or headset microphone.

● If you plan to use wireless headphones, ensure the battery is sufficient for up to 5 hours of meeting.

Download the Notes and Tips page from Documentation Files and Other Resources (https://confluence.alkami.com/display/SDKC/Documentation+Files+And+Other+Resources).
