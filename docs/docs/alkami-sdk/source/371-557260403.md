A Specific XCode version is REQUIRED.

This is because XCode is tied to specific Swift language versions. When iOS binaries are compiled with a specific version of Swift, they must be run with that Swift version.

Find the required XCode version HERE (https://gitlab.mgmt.alkami.net/MP/app-foundation/-/blob/main/.circleci/config.yml?ref_type=heads#L1415) (search the config file for "xcode")

XCode will auto-update itself to the latest version.

This guide will walk you through renaming your XCode app to prevent it from auto-updating.

#### Downloading

Xcode can be installed from the App Store, but it is not possible to manage the version the app store installs, so it is recommended to download the version needed from
https://developer.apple.com/download/all/?q=Xcode (https://developer.apple.com/download/all/?q=Xcode)
(You will need to be signed in to an Apple Developer account to access the downloads, your alkami email / saml creds should be valid developer credentials)

From here download the specific version you are looking for
(It's a large file and an even longer install, this may take some time)

#### Rename Existing Application

If this is your first installation of Xcode, you can skip this step until you've successfully installed the app
in the next step

While the app is downloading, you should rename the Xcode app in the applications folder.

This will help prevent Xcode from auto updating, and allows you to run multiple versions of Xcode on a single machine
which may be required for certain testing situations.

The easiest way to stay organized is to rename Xcode in the applications folder of your Mac from

```
Xcode > Xcode-version
```

#### Installation

For this step, double click the file downloaded in the first step to unzip / install the versioned Xcode app

After installation is complete, open the Applications folder and rename the new Xcode app (named just Xcode) to follow the convention to rename above

Launch Xcode and allow any prompts for installing additional tools

If this is your first install of Xcode, you are now finished. If you are maintaining multiple Xcode versions, the next step walks through how to specify the
one used to build the Flutter app

#### Setting Xcode version

If you have multiple versions of Xcode installed on your machine, you have to set the command line tools to use the desired version to properly build the app
for iOS simulators / devices using Xcode or any of the Flutter run / build commands from the terminal / debug menu.

To see the current version of the Xcode build tools being used, run

```
xcodebuild -version
```

Output:

Next, point the xcode command line tools to the correct version of Xcode with

```
sudo xcode-select -s /Applications/Xcode-{version}.app
```

And you can verify the xcodebuild version again, as well as the command line tools location with

```
xcode-select -p
```

Output:

The version of xcode now used to build the Flutter app from terminal or debugger in Vscode is set and
you can now use these commands to switch between desired versions.
