### .NET Framework 4.7.2

The 2019.02 NuGet packages for Alkami.Client and Alkami.Common are now requiring a minimum of.NET Framework 4.7.2. Please update your environment using the Visual Studio installer and target the proper framework when necessary.

The following Powershell script can determine if .NET Framework 4.7.2 has already been installed:

PowerShell

```
Get-ChildItem "HKLM:SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full\" | Get-ItemPropertyValue -Name Release | ForEach-Object { $_ -ge 461808 }
```

If the output is true, then the correct version has already been installed. If you need to upgrade, the installer can be found here: http://go.microsoft.com/fwlink/?linkid=863262 (http://go.microsoft.com/fwlink/?linkid=863262)

### Themes

We have componentized the ORB theme packages, they are now installed as an add-on component called "Alkami.Orbital".

Also, we're excited to announce Alkami's rebranding effort is officially live and featured on our new www.alkami.com (http://www.alkami.com/) website and within the SDK itself.

### Risk Evaluation

Alkami is in the final steps of switching to a new Risk suite that is comprised of two new services and a web module. This will impact very few SDK developers. If you're a team working on Risk related projects then Alkami should have already reached out to help with these changes. If you have any questions regarding future development please reach out to the SDK Team.

### Snippets

The Snippets Runtime has been updated to v2.0.0 and now allows SDK clients to submit and run their snippets. This was a slight delay and we appreciate your patience. We will be publishing some examples to the documentation site with some more details regarding this new feature.

### JetBrains.Annotations

Alkami.Common 2019.02 may cause build errors if a widget is using the JetBrains member annotations. It is safe to completely remove these annotations from your widget, we recommend doing this unless the annotations are purposeful to your development. If you'd like to maintain your annotations then you will need to install the JetBrains.Annotations NuGet package from Alkami's ThirdParty feed https://feeds.alkamitech.com/feeds/ThirdParty/JetBrains.Annotations/10.0.0 (https://feeds.alkamitech.com/feeds/ThirdParty/JetBrains.Annotations/10.0.0)

### Preview Notes
.NET Framework 4.7.2

The Alkami Platform team has upgraded ORB <TargetFrameworkVersion> from 4.6.2 to 4.7.2 in release 2019.02 (currently our develop branch at the time of this post)

### Action items:
- Install .NET Framework 4.7.2 on your machine (Please make sure this is the Developer Pack and not the runtime. The runtime is sufficient any QA or test environments.)https://dotnet.microsoft.com/download/thank-you/net472-developer-pack
- Upgrade Alkami.Modules.RiskEvaluation to version 2.0.2 on your machine (This is a result of removing JetBrains.Annotations from Alkami.Common as mentioned in the "other changes" section)
- (Optional) Upgrade your widget/module's TargetFrameworkVersion to 4.7.2. Please make sure your widget/module is versioned correctly after this change. (the new version will only be able to be deployed in 2019.02 release.)
- (Optional) If you widget/module is referencing assemblies from ORB, upgrade your ORB NuGet packages to the latest 2019.02 version.
