To install and get the TransferV2 widget working you must perform several steps and install packages.

### Step 1: Install the widget

```
choco install Alkami.Client.Widgets.TransferV2 -y
```

### Step 2: Execute this script in the DeveloperDynamic schema

This assumes that is the schema in which you are testing. If you plan to run this against a stage matched database, then you must change the database name in the use statement to match your environment.

Insert TransferV2 Widget

```
use DeveloperDynamic

----------------------- WIDGET + FLAVOR -----------------------
IF NOT EXISTS (SELECT ID FROM core.Widget WHERE Name = 'TransferV2')
BEGIN
DECLARE @BankID bigint

SELECT @BankID = ID FROM core.Bank

INSERT INTO core.Widget
(BankID, Name, AssemblyInfo, Salt, Active, IconImage, IconContentType, CanBeRemoved, DisplaySettings, WidgetType, IconName)
VALUES
(@BankID, 'TransferV2', 'Alkami.Client.Widgets.TransferV2', 0, 1, null, null, 1, 7, 2, 'transfers')

DECLARE @WidgetID int
SET @WidgetID = @@IDENTITY

INSERT INTO core.FlavorWidget (FlavorID, WidgetID, AddedByDefault, FavedByDefault, Ordering)
SELECT DISTINCT f.ID, @WidgetID, 0, 0, MAX(fw.Ordering) + 1
FROM core.Flavor f JOIN core.FlavorWidget fw ON f.ID = fw.FlavorID
WHERE fw.Ordering < 999 GROUP BY f.ID
END
```

### Step 4: Install the following packages

```
choco install Alkami.MicroServices.AchTemplates.Service.Host -y
choco install Alkami.MicroServices.ACHTransfersRequests.Service.Host -y
choco install Alkami.MicroServices.LoanPayment.Service.Host -y
choco install Alkami.MicroServices.NachaFileGenerator.Service.Host -y
choco install Alkami.MicroServices.TransferShim.Service.Host -y
choco install Alkami.Admin.Widgets.BusinessBanking -y (This is possibly already installed)
choco install Alkami.App.Providers.ACH.NachaOutput -y
choco install Alkami.WebExtensions.SignalR -y (This should have been installed by default with the MachineSetup)
```

### Step 5: Configure the packages and package assignments
- Open the Admin site and login.
- Go to Setup > Packages.
- Click the eye icon on the Adults package line and then click the Widgets tab
- Go to the Transfer V2 widget and toggle the slider to the right and select the box.
- Toggle the Transfer widget's slider to turn it off (left).
- Save the package.
- If you are working with the Brady family, update the package assignment for the members you are using for testing. For this example we will use Mike Brady
- Go to Support > Members.
- Find Mike Brady in the list and click his name.
- Go to the Features and Access section and click Change button in the Package line.
- Select the Kids package and save the change.
- Repeat Step 10 & 11 but this time select the Adults package.
- Open the Member site and if Mike Brady is already logged in log him out and log back in.
- After he is logged back in you should see the TransferV2 widget in the favorites menu and can begin testing.
### When you install or upgrad to TransferV2 version 4.3.0, you need specific version requirements for the SDK and some packages. You must also install additional packages.
##### Packages requiring minimum versions:

SDK needs to be at 2020.6 or above

Alkami.MicroServices.Audit.Service.Host needs to be at 6.32.0 or above
Alkami.MicroServices.Iav.Service.Host needs to be at 1.0.0 or above
Alkami.MicroServices.Settings.Service.Host needs to be at 4.7.0 or above
##### Additional packages:

choco install Alkami.MicroServices.Transfers.Service.Host -y
choco install Alkami.MicroServices.Limits.Service.Host -y
choco install Alkami.MicroServices.LinkedAccounts.Service.Host -y
choco install Alkami.Client.Widget.AccountLinking -y
