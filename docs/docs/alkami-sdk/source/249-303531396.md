### Mocking an Input Response

In case you didn't realize already, we've already technically mocked an API request and response; but we only accounted for Rendering. Now let's account for some Input with a static response to keep our scenario moving along through each step.

For our AccountInput scenario, we need to get a list of accounts back once the user has made it passed the first step in our widget. So, let's define our InputResponse.

For this, we're actually going to define a couple different resources:

- accountInputResponse: IInputResponse — The Input response for our request.

#### Generating Multi-Stage Responses

Now we'll need to return the appropriate response... But don't we usually handle data, and return responses accordingly? How will we know which response to return at what time?

Our method for doing so is actually relatively straightforward using a resetting counter. Let's look at our scenario:

- First, the widget is rendered to be interacted with
- Then, after providing input, the Input response is expected

A simple counter is a perfectly acceptable solution for toggling through scenario responses. Let's add some flags to our "server/index.ts", and then code some logic to differentiate between the accountRenderInlineResponse and the accountInputResponse.

server/index.ts

```
// We will need miragejs
import { Server, Response } from 'miragejs';
// Grab all of our mocks
import * as MOCKS from './mocks';

+ // responseFlags might be a good way to
+ // keep track of where you are in the
+ // scenario
+ const responseFlags = {
+ accountInputInlineScenario: 0
+ };

// Define our createMockServer
export function createMockServer(options: { environment: string }) {
// Define our Server object
return new Server({
environment: options.environment,

// Define our routes() method
routes() {
// Define our route namespace
this.namespace = '/StandardSSO';

// Routes
// =============================================================================

this.post(
'/accountInputInlineScenario/StepExecutionResult',
() => {
+ // If the flag is 0, we need to prompt for input and flip the flag to 1
+ // If it's 1, we should return the render response
+ if (responseFlags.accountInputInlineScenario === 0) {
+ responseFlags.accountInputInlineScenario += 1;
+ return new Response(200, {}, MOCKS.accountInputResponse);
+ }
+
+ responseFlags.accountInputInlineScenario = 0;
+ return new Response(200, {}, MOCKS.accountRenderInlineResponse);
}, { timing: 1000 });
},
});
}
```
