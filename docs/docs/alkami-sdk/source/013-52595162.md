### Update your widget:

First, install NuGet package Alkami.RiskEvaluation.WebExtension to your widget: https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.RiskEvaluation.WebExtension (https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.RiskEvaluation.WebExtension)

Then, remove this from widget's desktop and mobile views:

```
@Second Factor Authentication@
<div id="second_factor" class="modal fade" role="dialog" style="display: none;"> @Html.RenderPartial("~/Areas/API/Views/SecondFactorAuthentication/(Mobile)SecondFactorAuthentication.cshtml") </div> @End Second Factor Authentication@
```

Make sure this is included in the widget view:

```
@Html.IncludeSiteTextScript()
```

Finally, update t (https://bitbucket.corp.alkamitech.com/projects/MMB/repos/alkami.apps.businessach/browse/Alkami.Apps.BusinessACH/Attributes/HandleMultiFactorAuthenticationAttribute.cs)he code in your widget controller where the shouldprompt2fa method is called. Developers will need to replace the old code with the following code based on your ActionType.

For example, if your actiontype is ChangePassword, your code will be:

```
var request = new ChangePasswordRiskRequest(){
//If your widget needs to pass additional parameters to the risk evaluation microservice, you can add them to the below SessionInformation
//SessionInformation = new Dictionary<string, string>()
};
if (!this.IsAllowedByRiskEvaluation(request)) { return null; }
```
