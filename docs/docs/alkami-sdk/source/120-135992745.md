### Sample.Client.Widget.ChangeAddress

Before you use the ChangeAddress Widget, run the following command in an Admin PowerShell window to install the Alkami.MS.UserContacts.Service.Host.

```
choco install Alkami.MS.UserContacts.Service.Host -y
```
