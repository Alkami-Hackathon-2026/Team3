## Overview

This page documents what requirements are needed and capabilities are available to integrate a SSO requiring Transaction data. Originally built for Check Imaging providers implemented using Standard SSO. This functionality does not involve the Standard SSO widget.

### Setup

#### Configuration Scripts

Additional Details

Transaction Data Source is not available from the Standard SSO widget. It is available if the Standard SSO MicroService is called directly with the new parameter:

Transaction:

| /// <summary> /// Parameters relating to transactions /// </summary> public class Transaction { /// <summary> /// The id of the transaction to fetch an image for. /// </summary> [DataMember(EmitDefaultValue = true)] public long Id { get; set; } /// <summary> /// The micr to fetch an image for. /// </summary> [DataMember(EmitDefaultValue = true)] public string Micr { get; set; } /// <summary> /// The routing number to fetch an image for. /// </summary> [DataMember(EmitDefaultValue = true)] public string RoutingNumber { get; set; } /// <summary> /// The side to fetch an image for. /// </summary> [DataMember(EmitDefaultValue = true)] public string ImageSide { get; set; } } |

Example:

| "Transaction": { "Id": 1111, "Micr": "2222", "RoutingNumber": "111222233", "ImageSide": "Front"} |

##### Expressions

There are several new available expressions for the Transaction Data Source (not available from the Standard SSO widget):

| Name | Example | Description |
| TransactionAmount | {{ TransactionAmount }} | Returns the Transaction amount.Notes:Requires the Transaction Id to be passed in. |
| TransactionBatchNumber | {{ TransactionBatchNumber }} | Returns the Transaction batch number.Notes:Requires the Transaction Id to be passed in. |
| TransactionCheckNumber | {{ TransactionCheckNumber }} | Returns the Transaction check number.Notes:Requires the Transaction Id to be passed in. |
| TransactionCode | {{ TransactionCode }} | Returns the Transaction code.Notes:Requires the Transaction Id to be passed in. |
| TransactionCoreSequence | {{ TransactionCoreSequence }} | Returns the Transaction core sequence.Notes:Requires the Transaction Id to be passed in. |
| TransactionCreateDate | {{ TransactionCreateDate('MM-dd-yyyy') }} | Returns the Transaction's create date (if available) formatted with the provided format string.Arguments:#1 - A constant string that is the format string for the transaction create date.Notes:Requires the Transaction Id to be passed in.The format string must adhere to C# DateTime format standards. |
| TransactionEffectiveDate | {{ TransactionEffectiveDate('MM-dd-yyyy') }} | Returns the Transaction effective date (if available) formatted with the provided format string.Arguments:#1 - A constant string that is the format string for the transaction effective date.Notes:Requires the Transaction Id to be passed in.The format string must adhere to C# DateTime format standards. |
| TransactionImageSequence | {{ TransactionImageSequence }} | Returns the Transaction image sequence.Notes:Requires the Transaction Id to be passed in. |
| TransactionImageSide | {{ TransactionImageSide }} | Returns the Transaction image side (used for Check Imaging).Notes:Requires the Transaction Id to be passed in.Requires the ImageSide parameter to be passed in. |
| TransactionMerchant | {{ TransactionMerchant }} | Returns the Transaction merchant classification code.Notes:Requires the Transaction Id to be passed in. |
| TransactionMicr | {{ TransactionMicr }} | Returns the Transaction MICR Account Number.Notes:Requires the Transaction Id to be passed in. |
| TransactionPostingDate | {{ TransactionPostingDate('MM-dd-yyyy') }} | Returns the Transaction posting date (if available) formatted with the provided format string.Arguments:#1 - A constant string that is the format string for the transaction posting date.Notes:Requires the Transaction Id to be passed in.The format string must adhere to C# DateTime format standards. |
| TransactionPostingSequence | {{ TransactionPostingSequence }} | Returns the Transaction posting sequence.Notes:Requires the Transaction Id to be passed in. |
| TransactionRoutingNumber | {{ TransactionRoutingNumber }} | Returns the Transaction Routing Number.Notes:Requires the Transaction Id to be passed in.Requires the RoutingNumber parameter to be passed in. |
| TransactionSourceMicr | {{ TransactionSourceMicr }} | Returns the Transaction Source MICR Account Number.Notes:Requires the Transaction Id to be passed in.Requires the RoutingNumber parameter to be passed in. |
| TransactionTraceNumber | {{ TransactionTraceNumber }} | Returns the Transaction trace number.Notes:Requires the Transaction Id to be passed in. |
