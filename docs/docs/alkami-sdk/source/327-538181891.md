Alkami Embedded provides access to its theming tool, Iris Toolkit. Iris Toolkit contains:

- A library of widgets that match theme settings made in the Alkami Theme Builder.
- A collection of values used in all theming sorted by categories such as color, shape, typography, and spacing.
#### Iris library of widgets

Just by including the Alkami Embedded, various Iris widgets can used. Most of these adhere to the Iris naming convention, such as IrisListHeader, IrisButton, or IrisAvatar.

Iris widgets all adhere to same theme and so can be used without having to apply consistent settings yourself. For example, the IrisButton and IrisSwitch will have the same color. The IrisButton and the IrisTooltip will have the same border radius.

#### Iris Toolkit values

If new widgets need to be made, or existing widgets need their settings adjusted, consistency can be maintained using values known as design tokens from IrisToolkit.

final iris = GetIt.instance<IrisToolkit>();

iris.color.affordanceBase // a color matching the primary brand color

iris.spacing.brandedCompact // a double used for spacing

iris.spacing.insetAllNano // an EdgeInsetsGeometry object used for padding

iris.surface.platformRaisedShadowY // a double used for elevation or drop shadows

All Iris widgets are built using the design tokens in Iris Toolkit. Each of these design tokens are set by data sent to Alkami Embedded from Alkami Theme Builder.

Find out more about how Iris Toolkit works by viewing theming_example.dart.
