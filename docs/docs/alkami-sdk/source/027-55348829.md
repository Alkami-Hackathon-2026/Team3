Preparing for 2018.06

Per Alkami’s Platform Team,

As part of an effort to eliminate the need to manually increase the permission count in PermissionMask, we will be adding 4 additional permission claims to the user’s claimsidentity.

- PermissionsExpandable
- UserExpandable
- EntityExpandable
- AccountExpandable

We will now hold 4 duplicate versions of the same permissions. The difference between them is the way they are serialized and the new claims can now hold more permissions.

Without going into too much details, the reason why we have to keep the old implementation of the permissions is to maintain backwards compatibility with the Alkami Legacy Adapter.

Research is still underway to implement this, and we need your help to see if this implementation will impact your areas of the system.
