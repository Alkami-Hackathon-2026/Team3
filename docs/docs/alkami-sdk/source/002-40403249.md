The development environment must be downloaded and installed to run and view the work, but is not required to write and compile code against Alkami's libraries.

Install the Environment

In order of importance, complete these pages where applicable.

- See Hardware and Software Requirements to install the the SDK environment prerequisites.
- See Alkami Platform Machine Setup to install or upgrade the ORB platform environment.
- See Troubleshooting Machine Setup if any issues arise.

Download SDK Templates and Samples

Developers can download the templates and samples to inspect the code and compile them without setting up the entire ORB environment.

- See Alkami's Visual Studio Templates
- Reference Alkami's Sample Projects
## Merlin - Simplified Installer

Simplify your installs and upgrades with Merlin.

As of March 2025 we now support upgrade and installs via Merlin.
Feel free to use our legacy installation method; however Merlin will be much faster and requires less user interactions

#### Download Merlin
- Windows x64: Download Merlin for Windows
- Windows VM on Mac (via Parallels) arm64: Download Merlin for Windows VM on Mac
#### Installation Steps
- Run as Administrator and log in with your Feeds credentials.
- Fresh Install:Just follow the in-app prompts after logging in.
- Upgrade (from SDK 2024.x):Click the gear icon (top-right).Scroll down and click Upgrade once your current SDK version is detected.
- Uninstall:⚠️ Uninstalling will remove any SDK stage match.Click the gear icon (top-right).Scroll down and click Uninstall.Once complete, return to the main menu to start a fresh install.
