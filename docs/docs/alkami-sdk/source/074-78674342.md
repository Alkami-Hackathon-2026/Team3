The templates require users to be on Visual Studio 2019 and are in a single Visual Studio Extension (VSIX) and Chocolatey package (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.SDK.Templates). This requires developers to remove older templates from their Visual Studio instance. This page provides a step-by-step guide to help with this transition. See the Visual Studio Templates page for more details about this template.

## Install the new template

Close Visual Studio

Before running this install, close any open instances of Visual Studio.

```
choco install Alkami.SDK.Templates -y
```

## Remove obsolete templates
- Open Visual Studio.
- Under the main menu, select Extensions.
- Keep the new extension called Alkami SDK Templates, but remove any other Alkami extensions currently installed.This screen shot demonstrates what should be removed with a red X while highlighting the one to keep in the green box.After the old template extensions have been uninstalled, the new Extension list should look something like this:
## Select New Project Templates

You can sort the templates by their platform (Windows), language (C#), and project (Alkami) tags. Additional project tags (such as service, database, and events) are also available. When creating a new project, you can view the full list of templates with these filters.
