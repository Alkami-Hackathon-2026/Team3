This page is only for developers using the Corelation core system and who have created a custom microservice to call the core using keybridge.

If you are using v2 of v3 of this package and you update to v4, then you will get compilation and runtime errors.

There was a change between version 3 and version 4 of the nuget package Alkami.Microservices.Core.Common.Corelation.

The changes are really quite simple and what it does is facilitate the Alkami code to use some additional caching for the Corelation session details. For the caching to have context from which to create the cache key, a BaseRequest object must be available to the Alkami code.

If you are using the Builders and BusinessLogic approach to creating the request to send to Corelation, then you need to make a change like the following:

```
// you probably have a type defined like this
public class GetCPAccountAction : Alkami.MicroServices.Core.Common.Corelation.BaseAction

// you will need to add the a generic type to the BaseAction and it will look like this:
public class GetCPAccountAction : Alkami.MicroServices.Core.Common.Corelation.BaseAction<BaseRequest>
// or you can use the actual type of your request like this
public class GetCPAccountAction : Alkami.MicroServices.Core.Common.Corelation.BaseAction<GetCustomerIdRequest>

.
.
.
// within the class you will need to change lines that look like
public GetCPAccountAction(ProviderSettings parameters, GetCustomerIdRequest request) : base(parameters)

//To look like
public GetCPAccountAction(ProviderSettings parameters, GetCustomerIdRequest request) : base(parameters,request)

```

You will still get an error when executing the actual call to the core. If you examine the stack trace you will see that the error is inside the Alkami.Microservices.Cache.AsyncCache code.

To fix this error, we simply need to initialize the cache during the startup of the service.

Add this package to the Host project.

The add this line in the program.cs file before the OnStart() call.

```
Alkami.Microservices.Cache.Redis.Setup.UseRedisForCaching();
```
