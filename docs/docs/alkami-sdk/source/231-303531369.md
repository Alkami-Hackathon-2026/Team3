This folder is for all of the TypeScript interfaces that an application will utilize. The recommended pattern is to have each file have a single interface that it exports and the filename is the interface name. Additionally, all interfaces must begin with a capital "I" and be in pascal case.

IBaseTransaction.ts

```
export interface IBaseTransaction {
categoryId?: number;
categoryName?: string;
categoryColor?: string;
checkNumber?: number;
hasDisputed?: boolean;
minAmount: number;
maxAmount: number;
generalDescription: string;
specificDescription: string;
type?: string;
}
```

ITransaction.ts

```
import { IBaseTransaction } from './IBaseTransaction';

export interface ITransaction extends IBaseTransaction {
amount: number;
balance: number;
displayDate: string;
transactionId: number;
}
```

Things of note:

- All interfaces must begin with a capital "I"
- Interface filenames should be the same as the interface name
- All interface files should export a single member
- Interface files can import other interfaces to extend or inherit from
#### Internal Interfaces

For complex objects, it is often required to define multiple interfaces that make up the definition for that object. In this case its fine to define those interfaces in the same file they will be used, as long as there is only one interface exported from the file.

Complex Interface

```
interface IAccount {
accountIdentifier: string;
userAccountId: number;
nickname: string;
accountNumber: string;
accountType: string;
requiresRegD: boolean;
balance: number;
}

export interface IProfile {
firstName: string;
lastName: string;
bankName: string;
accounts: IAccount[];
defaultAccount: IAccount;
isAdmin: boolean;
}
```
