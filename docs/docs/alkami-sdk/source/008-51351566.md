If you are submitting a new version of an existing SDK project please ensure that there is not an open submission ticket for a previous version. If there is an open submission ticket for a previous version please cancel that submission before creating the SDK Submission ticket for the new version. If for some reason you do not have the ability to cancel the submission please leave a comment on the submission to be canceled and a member of the SDK team will cancel it for you. Please remember to tag sdksupport (/display/~sdksupport@alkamitech.com) in the comment for visibility. Failure to do this could result in a bad version being deployed if it is in the correct status prior to cancellation.

### ProGet package link

Make sure you have a proper package link before submitting, otherwise please see Add a package to your development feed (/spaces/SDKC/pages/51351561/Add+a+package+to+your+development+feed).

### Submitting a project...

Open your browser and navigate to https://jira.alkami.com/ (https://jira.alkami.com/)

- Click "Create" at the top of the page

- Select your Client Services or Delivery project as the project type. Select SDK Submission as the issue type. Reach out to your account manager or the SDK team if you're not sure what your Account Management or Delivery projects names are.

- Add a Summary and Description that includes information related to this submission. The summary should contain at least the name of the project being submitted, the version and/or any settings or configurations that need to be added or updated. The description can be as detailed as you feel it may need to be. Any special instructions should be added to the description.

- The SDK Component Type is the type of project you are submitting. The types are Widget, Provider, Microservice, Repository or Snippet.
- Add your name to FI Contact and add your email to FI Contact Info. This can be someone different than the submitter of the issue, it's the FI's choice who will be the contact for these submissions.
- The Package URL is the URL of the package you are submitting. This URL represents where the package is hosted in your dev feed and the version you are submitting. In this example the URL is hidden by the text field, it's full value reads as: https://feeds.alkamitech.com/feeds/fi1.choco.dev/FIOne.Client.Widgets.MemberServices/1.0.0For more information, see How to... add a package to your development feed
- Add any issues to the Linked Issues section that may be related or otherwise dependent on this submission.
- Lastly, click Create - the package is now submitted, please wait for updates on your ticket.
