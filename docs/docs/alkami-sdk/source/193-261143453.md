#### General

In order for the native app to detect and display a PDF with sharing capabilities, the web page much trigger a navigation request in the embedded webView. Then the app inspects this request and looks for specific criteria so the app knows the request is a .pdf.

- The URL must have a queryString param named nativeDocType=pdf
#### Triggering a navigation request in the native iOS app

There are (roughly) three scenarios to trigger the load of a PDF and trigger a navigation request in the webView.

- Link - Using an <a> element, the user clicks on a link that attempts to navigate to a pdf (most likely a resource with a .pdf extension). You can pass in a target attribute and this must be _self to trigger the navigation delegate inside the native apps so that we can react to a pdf. The default target value for a link is _self.

```
<a href="/TrainingHelloWorld/GetPdf?nativedoctype=pdf" target="_self">Get PDF</a>
```

- Button - Using a <button> element, the user clicks on the button to trigger a pdf load. If the button isn’t submitting a form , this means that the action will be handled in JavaScript and will most likely open a new window to navigate the browser to the correct URL. By default, opening a new window essentially has a target value of _blank since it is supposed to open a new window. In this case, you would need to pass in a target value of _self to ensure the native app gets the navigation request to react to it. window.open(url, _self);.

```
<input type=button onClick="window.open('/TrainingHelloWorld/GetPdf?nativedoctype=pdf', '_self');"
value='Do The Window'>

<input type=button onClick="'location.href='/TrainingHelloWorld/GetPdf?nativedoctype=pdf'" target="'_self'" value='click here'>
```

The following is an example of a method for a controller that will stream out a pdf to the browser or app.

```
// add this nuget package: hiqpdf_x64
// add the following line to the top of the controller
using HiQPdf;

public ActionResult GetPdf()
{
HtmlToPdf htmlToPdfConverter = new HtmlToPdf();

//htmlToPdfConverter.SerialNumber = serialNumber;

htmlToPdfConverter.Document.PageSize = PdfPageSize.A4;
htmlToPdfConverter.Document.PageOrientation = PdfPageOrientation.Portrait;
htmlToPdfConverter.Document.PdfStandard = PdfStandard.Pdf;
htmlToPdfConverter.Document.Margins = new PdfMargins(1, 1, 1, 1);
htmlToPdfConverter.Document.FontEmbedding = true;
htmlToPdfConverter.TriggerMode = ConversionTriggerMode.Auto;

string depPath = Path.Combine(System.Web.HttpContext.Current.Server.MapPath(@"~/Areas/TrainingHelloWorld/bin"), "HiQPdf.dep");
htmlToPdfConverter.SetDepFilePath(depPath);

string htmlToConvert = "<html><body>Hello World</body></body>";

// Note if you use an image in your html, then the src for your img tag will need to contain the base64 encoded image as data

byte[] byteInfo =
htmlToPdfConverter.ConvertHtmlToMemory(htmlToConvert, "http://127.0.0.1");

MemoryStream myStream = new MemoryStream();
myStream.Write(byteInfo, 0, byteInfo.Length);
myStream.Position = 0;

return new FileStreamResult(myStream, "application/pdf");

}

// Add this line to your .nuspec
// <file src="bin\Hiqpdf.*" target="lib" exclude="**\*.config"/>
```
