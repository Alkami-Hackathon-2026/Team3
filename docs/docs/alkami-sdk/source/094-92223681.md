### If you need to retrieve simple data from some http web service or webpage, this Alkami microservice can save you the effort of creating your own microservice to do the job.

### Install the GenericProxy microservice

Run the sql script to add the provider type and provider instance.

Install the service

```
choco install Alkami.MS.GenericProxy.Service.Host --source https://feeds.alkamitech.com/nuget/choco.dev/ -y
```

### Add the code to your Widget

Add the latest versions of the following NuGet packages to your Widget:

Alkami.MS.GenericProxy.Client

Alkami.MS.GenericProxy.Data

update the NuGet packages in your project to make sure they are up-date-date (except for any pacakges that might not be permitted)

add this line to the .nuspec file for your Widget

<file src="bin\Alkami.MS.GenericProxy.*" target="lib" exclude="**\*.config"/>

Here's the code you'll need in your Widget

Widget Code

```
using Alkami.MS.GenericProxy.Contracts;
using Alkami.MS.GenericProxy.Contracts.Requests;
using Alkami.MS.GenericProxy.Contracts.Responses;
using Alkami.MS.GenericProxy.Service.Client;
using WebToolkit;
using Sample.Client.Widget.GenericProxy.Models;

// inside the class add this static Func
public static Func<IGenericProxyServiceContract> genericProxyServiceFactory = () => new GenericProxyServiceClient();

// inside your controller action method
ProxyRequest req = new ProxyRequest();
this.AugmentRequest(req);
req.HttpMethod = "GET";
req.RequestUri = new Uri("https://www.google.com");

ProxyResponse resp = AsyncHelper.RunSync(() =>
genericProxyServiceFactory().ExecuteRequestAsync(req));

myModel.ContentToDisplay = resp.Body;

```

Note: www.google.com (http://www.google.com) is on the default whitelist for the provider. Use the admin site and edit the provider settings to add whatever host and domain you need to reach.
