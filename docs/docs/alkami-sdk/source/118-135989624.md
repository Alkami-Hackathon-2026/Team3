#### Description

To increase installation speed and conserve space, the basic SDK machinesetup does not include the packages needed to use the Alkami API. If you want to use the API in your SDK you must install additional software.

Note: Beginning with SDK Release 2021.5, you might find that all these components are already installed in your SDK environment.

#### Install Prerequisites

To be able to effectively run AFX V2. You will need the Windows Hosting Bundle for ASP.NET Core 8.0 Runtime (https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-aspnetcore-8.0.16-windows-hosting-bundle-installer). As of this writing 8.0.16 is the latest.

#### Install API Packages

To enable the API, install the following Chocolatey packages. This lets you use native apps.
Note: Any API you are developing to point to the Alkami API or return data from the Alkami API requires these Chocolatey packages.

```
// Install these packages using Powershell (running as admin)

choco install Alkami.Api.AFX
choco install Alkami.Api.OrbFX
choco install Alkami.Api.CUFX
choco install Alkami.Api.AFX.V2
choco install Alkami.Api.Admin
choco install Alkami.Api.Fdx
choco install Alkami.Services.Afx.User
choco install Alkami.Services.Afx.Business
choco install Alkami.Services.Afx.Account
```

#### Documentation

After installing the previous packages you can access the online Swagger documentation for the API from one of these pages:

- https://developer.dev.alkamitech.com/CUFX/swagger/ui/index
- https://developer.dev.alkamitech.com/AFX/V1/swagger/ui/index
- https://developer.dev.alkamitech.com/OrbFx/swagger/ui/index

#### Use The API

Based on how you want to use the API, install the following items, as you prefer.

```
// Using Powershell (running as admin), install the packages your FI will be using.
choco install Alkami.MicroServices.ApplicationSettings.Service.Host
choco install Alkami.MicroServices.Payments.Service.Host
choco install Alkami.MS.AccountsOrchestration.Service.Host
choco install Alkami.Client.Widgets.OAuth

## If you want the admin widget for managing Registered Applications add this package (should already be installed)
choco install Alkami.Admin.Widgets.ApiApplications
```

#### Edit Admin Roles

To manage your Registered Applications, you need admin permissions and must verify that the previous package is installed.

- Login to the admin site at https://admin-developer.dev.alkamitech.com.
- Go to Setup > Staff.
- From Staff, select Admin Roles.
- From the Edit Admin Role page, for Role Name, enter General Admin.
- From the Setup group, select the Manage Registered Applications checkbox.
- Click Save.

Repeat the preceding steps for all FI admin users with the specified Admin Role (for example, General Admin) to have access to manage their registered applications. This will allow them to verify that the API packages are installed.

When finished enabling AFX and CUFX in your SDK, proceed to the OAuth Workflow Demo (https://confluence.alkami.com/sdk/oauth-workflow-demo-55346046.html) page.
