Signing Certificates

This certificate should be created by Alkami, it is a private key (pfx) and the public key is shared with the FI.

Encryption Certificates

This certificate is managed by the FI and shared with Alkami, it is a public key (crt).

There are several different kinds of certificates that can be required when creating/implementing a StandardSSO widget. There can be PFX, CER, CRT, etc. These go inside certain stores within the Certificate Manager.

You will want to open the Windows search and look for "Manage Computer Certificates." This will bring up the Certificate stores for the local computer. Depending on the kind of certificate you are dealing with is where it will go in the certificate store.

- Any certificates that Alkami creates (ie signing certificates) will be placed in the Personal store
- Any certificates that are External and placed in the Trusted People store.
- Any External CA certificates should be placed in the Third-Party CA store
### Installing PFX Certificates

Generally, all PFX certs will go in the Personal store.

1. You will right click the Certificates folder in the Personal store → All Tasks → Import

2. After you do this, an Import Wizard will pop. Find the PFX file and click Next.
3. You will then be prompted to fill out the Private Key Protection. Along with the PFX, a password should have been provided that will allow you to install the cert on your machine.
Make sure to check the "Mark this key as exportable" option in the Import options.

4. Hit next on the Certificate Store screen and then finish. Your PFX has been Imported into your Personal Store. The next step is making sure the IIS has permissions to use the Certificate.
5. Once the certificate is imported, right click on the Certificate → "All Tasks" → "Manage Private Keys..." This will open a Permission prompt for the certificate.
You are going to want to add the following users:

- IIS_IUSRS
- dev.nag
- dev.radium
- dev.dbms
- dev.micro

IIS_IUSRS is found on your local machine and the others are Alkami SDK Users.

To find the SDK Users, make sure to click Advanced... → Object Types... → Service Accounts. The SDK Users are set up as Service Accounts and are not checked on this screen by default.

6. Verify that the certificate is fully installed by checking the Certification path. You can do this by double clicking the cert and then going to Certification Path

### Installing Signing & Encryption Certs

Next up will signing and encryption certs.

First we will cover where they come from since this is a very important distinction.
Signing certificates for both Staging and Production come from Alkami's Security Engineering team.

Encryption certificates come in a ".crt" or ".cer" format. These always come from the 3rd party which they send over through the FI. #### Installation

1. You will open the Computer's Certificate store
2. Right click the certificate store → Import
3. Find the cert and then click Next until you're done

Importing Signing/Encryption Certs are much easier than PFXs
