### Session Information

This session will demonstrate how you can integrate and communicate with your core using Alkami's Core communcation framework. This is useful in scenarios were ORB's current core implementation doesn't map data required in your MicroService. Some of the topics covered include

- Overview of Alkami's core integrations
- Including a reference to the desired core common nuget package
- How to build requests and make core calls

Speaker: Paul Sawey
