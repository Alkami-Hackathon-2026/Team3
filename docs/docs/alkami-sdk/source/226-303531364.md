Every Vue application starts with a single entry point, most commonly see as either `main.ts` or `app.ts`. This is what Webpack will start with when attempting to compile an application and is the script that will create the Vue instance and bind it to the DOM. This file is responsible for a handful of things:

- Importing the various Vue libraries needed for the application (e.g. Vue)
- Importing the main Vue component (e.g. App.vue)
- Importing the router and store modules or other plugins
- Preparing any mock data available
- Creating the main Vue app instance and binding it to the DOM

Let's take a look at an example of this file:

app.ts

```
import { createPinia } from 'pinia';
import { createApp } from 'vue'; // Imports Vue from node_modules for TypeScript support. Will later be stripped out by Webpack and will need to be included as a script tag in the index.cshtml file.
import App from './App.vue'; // Imports main Vue component to be used for the application.
import router from './router'; // Optional: If using the router, import the main file here.

void (async () => {
const pinia = createPinia()

const app = createApp(App);
app.use(pinia);
app.use(router);

if (process.env.NODE_ENV === 'development' && process.env.ALBUS_LOCAL_DEV === 'cypress') {
// Setup mock data if needed. This code will tree shake out via replacement of variables above.
const { setup } = await import('./tests/e2e/setup')
await setup();
}

app.mount('#app');
})();

```
