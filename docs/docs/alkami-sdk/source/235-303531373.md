The views folder is where all of the primary views for your application go. Each file in this folder should map to a route defined in the router.

For example, for a router definition like this:

router.ts

```
const routes = [
{
path: '/',
name: 'home',
components: {
navbar: NavBar,
page: Home,
},
},
{
path: '/choose',
name: 'choose',
components: {
navbar: NavBar,
page: () => import('./views/ChooseTenant.vue'),
},
},
];

// Determine if we are the mobile or the desktop widget
const isMobile = location.pathname.toLowerCase().startsWith('/mobile');

const router = createRouter({
routes,
// take advantage of the browser history object
history: createWebHistory((isMobile ? '/Mobile/' : '/') + 'WidgetName/'),
});
```

Your views folder would look like this:

Views Folder

```
└── views
├── Home.vue
└── ChooseTenant.vue
```
