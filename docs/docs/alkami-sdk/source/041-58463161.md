## Session Information

Card Management allows end users to view information about their debit and credit cards, control the use of these cards, and maintain their status without having to contact your FI directly. This session will show how SDK developers can extend Card Management features by adding a new Card Management Provider MicroService within the existing framework.

Presented by: Vinod Srinivasan and Trevor Brown

## Creating a Custom Card Provider MicroService
### Pre-requisites
- Install the Card Management WidgetInstall choco package Alkami.Apps.CardManagementV2Run SQL script to install and configure widget
- Install PrismInstall choco package Alkami.MicroServices.CardManagement.Service.HostNo additional configuration required
- (Optional) Install Card Management Admin WidgetInstall choco package Alkami.Admin.CardManagement
### Steps
- Get the Visual Studio TemplateInstall choco package Alkami.Template.CardProvider
- Create new project from templateGenerates all required classes and methodsGenerates provider installation scriptGenerates sample capability mapping script
- Customize providerMay need to add external packages to communicate with the core/secondary providerImplement contract methodsGetProviderCapabilitiesReturn list of supported capabilitiesUsed for configuring the capability mapping table through the Admin UIGetCardNumbersReturn a list of card numbers for the logged in userGetCardsReturn a list of cards for the logged in userInclude card details (e.g. Block status, Limits)InitiateCardActionPerform specified action on the selected cardUpdate card object before returning
- Run the SQL script to install the new provider
- Build and run the MicroService from Visual Studio
- Configure the mapping tableUse the SQL script generated by the template of the Admin UI
- Open online banking and go to the Card Management Widget
