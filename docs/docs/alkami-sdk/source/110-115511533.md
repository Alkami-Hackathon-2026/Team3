You can use widgets or services to send Alerts to the Alkami Alerts Microservice. Each alert begins as a template and each template contains predefined variables. These templates are stored in the platform database under the notification.DefaultTemplates table. Alkami creates and maintains many of the templates, while custom templates are specific to each financial institution.

### Global Templates

Each template is wrapped in a predefined GLOBAL_TEMPLATE that handles the header, footer, styling, and formatting of the email alert. A custom template only defines what will be rendered in the <body/> tag of the global template's HTML.

In this example image, the text circled in GREEN is defined by a custom template while the surrounding header and footer is based on Alkami's GLOBAL_TEMPLATE.

### Create a Default Template

Each alert must begin with a template. The template content is raw un-escaped HTML. Leave the other values as-is.

Run the following SQL in your local environment to create a new custom template for this sample. Reference the table after the code for values that you can customize.

```
USE [DeveloperDynamic]
GO

INSERT INTO [notification].[DefaultTemplates]
([BankIdentifier]
,[OriginatorName]
,[TemplateContent]
,[TemplateTarget]
,[TemplateName]
,[NotificationActionName]
,[MediumType]
,[TemplateTransformType]
,[LocaleId]
,[CreateDate]
,[Subject])
VALUES
('78554577-9DE6-43CD-9085-5868977156D1'
,'USBFI'
,'<p>You are receiving this from a sample SDK project on @Model.Date</p>'
,'{"id": "System.Object","type": "object","properties": {}}'
,'USBFIGeneralEmailAlert'
,'USBFIGeneralEmailAlert'
,1
,2
,1033
,GETDATE()
,'USBFI Hello World Alert')
GO
```

| Name | Value Description |
| OriginatorName | A unique identifier of your choice |
| TemplateContent | Raw un-escaped html |
| TemplateTarget | Dynamic objects, leave this as is |
| TemplateName | A unique identifier of your choice |
| NotificationActionName | A unique identifier of your choice, same as TemplateName typically |
| MediumType | Email, SMS, and so on |
| TemplateTransformType | Email, SMS, and so on |
| LocaleId | The language, default is English 1033 |
| Subject | The subject of your alert. This can be as generic or specific as you'd like. |
### Send Requests to the Alerts Service

You can use this snippet of code to send a request to the Alerts service. You must add the NuGet packages for the Alerts Client and Contract libraries.

```
// required using statements
using Alkami.MicroServices.Alerts.Contracts.Requests;
using Alkami.MicroServices.Alerts.Contracts.Responses;
using Alkami.MicroServices.Alerts.Contracts;
using Alkami.MicroServices.Alerts;

...

// required functional delegate to alerts service
private static readonly Func<IAlertsServiceContract> AlertsFactory = () => new AlertsServiceClient();

...

// example method for sending alert
[HttpPost]
public async Task<JsonResult> SendAlert()
{
var request = new SendAlertRequest();
this.AugmentRequest(request);

var notifcationData = new
{
AlertTitle = "Sample Alert!",
Date = DateTime.UtcNow,
AlertReason = "This is an example alert.",
Signature = "Your Special Signed Signature"
};

request.Alert = new GeneralAlert(notifcationData)
{
ContactIds = null,
TemplateName = "USBFIGeneralEmailAlert",
OriginatorName = "USBFI",
DestinationUserIdentifier = request.UserIdentifier,
TemplateTransformType = TemplateTransformType.Razor,
FallbackToPrimaryEmail = true,
AlertDate = DateTime.UtcNow
};

var response = await AlertsFactory().SendAlertAsync(request);

Logger.TraceFormat("Sending alert. UserIdentifier: '{0}' TemplateName: {1}", request.UserIdentifier, request.Alert.TemplateName);

return Json(new { success = !response.HasError });
}
```

You can add a button like this to your view page and then trigger the post action to the controller so the success is determined by errors returned from the microservices.

```
<button class="iris-button iris-button--primary" id="send_alert">Send Alert</button>
```

```
var sendAlertButton = document.getElementById('send_alert');

if (sendAlertButton) {
sendAlertButton.addEventListener('click', function (event) {
var success = function (response) {
console.log("hey now: " + response.success);
}
var error = function () {
console.log("oh no: " + response.success);
}

$.ajax({
method: 'POST',
url: 'SampleAlerts/SendAlert',
data: '{}',
contentType: 'application/json',
success: success,
error: error
});
});
}
```

### Check Notification Audits

Each alert triggers a notification request and results in an entry in the audit.UserNotificationAction table. If you have a local SMTP server configured, you will see an email corresponding to a new entry in this table.

```
select * from [audit].[UserNotificationAction]
```
