Setting up your project is really easy. There are only a few configuration items you need to create so that Albus can run.

#### Allow your project access to the Alkami npm feed

Create an .npmrc file at the root of your solution (a peer of package.json) that lets npm know your solution is using our private npm repository.

.npmrc

```
# Specify the registry for Alkami scoped packages
@alkami:registry=https://packagerepo.orb.alkamitech.com/npm/npm.dev/
```

#### Install Albus into your dependencies

Run this command from a terminal in your solution directory:

Install Albus and Albus CLI

```
$ npm install @alkami/albus-cli @alkami/albus --save-dev
```

#### Choose a preset to install

To get a set of functionality in Albus, at least one preset must be installed. Review the available presets (/spaces/SDKC/pages/303531412/Presets) and follow the installation instructions of the one(s) that fit your needs best.

#### Create your configuration

Inside of your project folder you will want to create a file name albus.config.js. If you don't need to configure any of your presets your configuration may literally look like this:

albus.config.js

```
module.exports = {
tokens: {
orbWidgetName: "Widget"
},
presetConfiguration: {}
}
```

#### TypeScript support (optional)

If you plan to use TypeScript you will want to create a tsconfig.json in your project folder and point it to the correct Albus base TypeScript Configuration. Here are some examples:

##### Legacy Preset
Legacy tsconfig.json

```
{
"extends": "../node_modules/@alkami/albus-preset-legacy/configs/tsconfig.json",
"include": [
"**/*.ts"
],
"exclude": [
"node_modules",
"**/*.spec.ts",
"**/__tests__",
"**/__mocks__",
"packages/**"
]
}
```

##### Vue Preset
Vue tsconfig.json

```
{
"extends": "../node_modules/@alkami/albus-preset-vue/configs/tsconfig.json",

"**/*.ts"
],
```

#### Hook up Visual Studio build to use Albus

You may need to update your project's csproj to point to the script. Look for the <PreBuildEvent> or in Visual Studio navigate to Project > Properties > Build Events > PreBuild and prepend with the following script:

Visual Studio prebuild event

```
powershell.exe -noninteractive -command "npx --userconfig '$(SolutionDir).npmrc' --package @alkami/albus-vs-run@~1 albus-vs-run" '$(SolutionDir)' '$(ProjectDir)' '$(ConfigurationName)'
if %errorlevel% NEQ 0 exit %errorlevel%
```
