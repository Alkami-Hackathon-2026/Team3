Currently, Alkami supports the following grant types:

- authorization_code: RFC 6749 - Section 4.1
- refresh_token: RFC 6749 - Section 6
#### Workflow

As part of their interactions with the API, third-party applications must perform the following operations:

- Authorize the Registered Application
- Generate the Tokens
- Call the API
- Refresh the Tokens

For expanded explanations about these operations, see the OAuth 2.0 Product Guide (https://midas.alkami.com/product-guide/oauth-2-0-product-guide/).

The resulting OAuth workflow will be as follows when authorizing your FI’s registered application to generate the tokens for use against the API.
