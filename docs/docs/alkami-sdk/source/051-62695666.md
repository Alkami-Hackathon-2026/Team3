### Opening SDK Support Incidents

Most of the issues pertaining to SDK projects can be addressed by opening an SDK Support Incident. The SDK team will help open any additional tickets if required so that the initial support issue can act as a point of reference for Alkami and the reporter. View this video for a walk-through of creating a support incident (https://www.youtube.com/watch?v=v8ziBm2gEEE)

### Staging Environment Issues

If you're testing SDK projects in the staging environment and things are not working as expected then open an SDK Support Incident and include as much detail as possible about the issues you are seeing. We will ask for clarity if needed and follow up with additional support where necessary.

### Local SDK Development Errors: Check List (Support Incidents where a run time error is blocking the developer)

If you're having errors in your environment please copy paste and complete this checklist and include in the "Description" of the incident:

- A detailed explanation of what the issue is and the steps to reproduce
- If an ORB browser error, attach the WebClient and WebClientAdmin log files
- If a service(s) error, attach the specific service log file(s)
- ORB Version: (Navigate to https://developer.dev.alkamitech.com/version.txt)
### General Questions and Information

Make sure to be detailed in your questions and provide as much back ground information as possible. Many times these questions are part of a larger design initiative, it will help if you describe the requirements of the project to better inform Alkami of the intended purpose.
