After successful code review and Fortify scan, the package is promoted to you private staging feed (myfi.choco.stage).

### Staging Testing

Once your submission is in the staging environment, you can test your submission in a production-like environment. It is your responsibility to adequately test your submission in the staging environment.

- Navigate to the staging platfom at: https://developer.dev.alkamitech.com/Dashboard
- In the ORB Financial Dashboard, click the More (ellipsis) option and select Widget Options.
- Under the Widgets tab, locate your widget and click Add to add your widget to the available navigation options. The selected widget's content opens.
- In the widget that opens, validate that everything is working as expected.
- Make any needed changes in Visual Studio. Any changes made are deployed to the target environment.
- Once you have tested your submission and are satisfied that it is ready for production deployment, click the Stage Validation Passed button to indicate that the testing in the staging platform has passed. The ticket will transition to an Awaiting Configuration status. The SDK team will be notified that you have approved your package for production deployment.
- In the Awaiting Configuration status work with SDK Team to verify you have provided all the needed information about your deployment and roll out plans. The SDK Team will validate that all needed configuration steps are either completed or scheduled to be completed. If you don't want the submission deployed before a certain date, please specify that in the communications in this stage.
- When successful, the SDK Team will transition the ticket to the Waiting for Production Deployment state. The submission will be scheduled for the next production time slot for the Pod that is assigned to your FI.
### Deploy and Submit the Package (Developer completes these steps)
- In ProGet, open your Feeds listing https://feeds.alkamitech.com/feeds and initially open the current package deployed to Dev (myfi.choco.dev).
- Open and compare your Staging feed to confirm your Dev package numbering matches the Staging feed.
- Open the Staging Content in the Repo.
- Apply any changes needed in the source code.
- Roll the semantic version number.
- Click Build in Visual Studio to build the widget on your local machine. You will see a message of 'Successfully crated package <path to file>widget name.semantic number.nupkg'.
### Install the Local Build into the Dev Feed and Test the Functionality
- In ProGet, in the Dev feed (myfi.choco.dev), click Add Package (to upload build to choco.dev).
- In the Add Package window, click Upload from Disk and then click Choose File in the Upload from Disk window.
- Navigate the directory where the build was completed, select the build package file, and then click the UploadNote: In the Choco.dev feed, you will see the semantic numbering align with the current build.
- Open the Dev feed and ensure the file reflects the current update. Note: You will see the current Project URL, Last Update date, Package Source, Release Notes, and Tags assigned.
- Copy the Project URL.
