Many presets have an "Additional Files" section that lists various ancillary files required for certain presets to work properly. Each of these files ship with the presets themselves and will be added to your project directory after running albus catalyst when first configuring your project. If you are manually configuring a project, or would like to reference the contents of a particular file that was scaffolded, here are the contents of each of those files.

#### tslint.json

Required to offer linting in both Vue and Webpack projects.

tslint.json

```
{
"defaultSeverity": "warning",
"extends": [
"tslint:recommended"
],
"linterOptions": {
"exclude": [
"node_modules/**"
]
},
"rules": {
"quotemark": [true, "single"],
"indent": [true, "spaces", 4],
"interface-name": false,
"ordered-imports": false,
"object-literal-sort-keys": false,
"no-consecutive-blank-lines": false,
"no-console": false
}
}
```

#### tsconfig.json

Required to properly transpile TypeScript files, inheriting from the correct preset base.

tsconfig.json

```
{
// Modify the line below with the correct preset you have installed
"extends": "./node_modules/@alkami/albus-preset-{your-preset}/configs/tsconfig.json",
"include": [
"**/*.ts",
"**/*.vue" // Only include this line if you are using the Vue preset
],
"exclude": [
"node_modules",
"**/*.spec.ts",
"**/__tests__",
"**/__mocks__",
"packages/**"
]
}
```

#### .browserlistrc

Required to properly provide CSS autoprefixing for SCSS files.

.browserlistrc

```
extends @alkami/browserslist-config-albus
```

#### postcss.config.js

Required to properly autoprefix CSS files as well as minify them.

postcss.config.js

```
module.exports = {
plugins: {
autoprefixer: {},
cssnano: {
preset: 'default',
}
}
};
```
