TITLE: Integrate a widget with a microservice
PARENT: How-to Articles

-----
This guide shows how you (a developer) can add a client package for an existing microservice to your existing widget. When a service is added, it's the widget's responsibility to bring those libraries with it when deployed to ORB. What does this mean? This means that you must make sure the service libraries make it into the projects /bin directory so that Chocolatey can package it properly.

Prerequisites:

- A widget equipped with an installer no older than v2.0.1
- Feed access to https://feeds.alkamitech.com
- A running ORB environment 2018.05 or later
- Select a service and add the client and contract packages. This example uses the Accounts microservice.
- You must package these new Microservice libraries in the Chocolatey package. NuGet Package Manager automatically adds all references and defaults the CopyLocal property to true, however, we recommend that you confirm this.
- Update Chocolatey's .nuspec package manifest to target these new .dll files as package-able artifacts. A new line is under the existing <file src="bin\USBFI.* that targets the Transactions libraries we've previously referenced.USBFI.Client.Widget.MyMoney.nuspec ``` <files> <!-- The following defines where to find the files for packaging and what to exclude--> <file src="tools\chocolateyInstall.ps1" target="tools" /> <file src="tools\chocolateyUninstall.ps1" target="tools" /> <file src="AlkamiManifest.xml" target="AlkamiManifest.xml" /> <file src="**\*.*" target="src" exclude="**\obj\**\*.*;**\.vs\**\*.*;**\bin\**\*.*;**\packages\**\*.*;**\.nuget\**\*.*;**\.git\**\*.*;**\.gitignore;**\node_modules\**\*.*;**\.suo;**\.user;**\Tests\**\*.*;**\Test\**\*.*;**\UnitTest\**\*.*;**\UnitTests\**\*.*;**\tools\**\chocolatey*.ps1" /> <!-- bin files | define the libraries that should be a part of this package --> <file src="bin\USBFI.*" target="lib" exclude="**\*.config"/> <file src="bin\Alkami.MicroServices.Transactions.*" target="lib" exclude="**\*.config"/> <!-- WebClient content --> <file src="**\Scripts\" target="content\Areas\App" /> <file src="**\Styles\" target="content\Areas\App" exclude="**\*.scss" /> <file src="**\Views\" target="content\Areas\App" /> <file src="**\Images\" target="content\Areas\App" /> <file src="**\_SiteText\" target="content\Areas\App" exclude="**\*.xx.xml"/> </files> ```
- Call the service in a C# class with the following delegate factory pattern:WidgetController.cs ``` /*The using statements are for example purposes, replace with references to real services*/ ... using Webtoolkit; using USBFI.MS.MyService.Data.Contracts; using USBFI.MS.MyService.Service.Client; /// <summary> /// Replace the IServiceContract and ServiceClient types with the proper type to call a microservice /// </summary> public static Func<IServiceContract> serviceFactory = () => new ServiceClient(); public async Task<ActionResult> Index() { try { Logger.DebugFormat("[GET] Controller/Index"); var request = new GetSomethingRequest(); this.AugmentRequest(request); var results = await serviceFactory().GetSomethingAsync(request); var model = new WidgetModel { Data = results.Data }; return View("Index", model); } catch (Exception e) { Logger.Error("Error [GET] Controller/Index", e); return View("Error"); } } ```
