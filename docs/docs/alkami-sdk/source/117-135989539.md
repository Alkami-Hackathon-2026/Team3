### Remove unneeded widgets from the core.widget table in your SDK

The initial installation of the SDK includes a database that has several entries in the core.widget table for widgets that are not used, or for which the widget files do not exist in the "areas" folder. Each time WebClient starts, this creates quite a few error messages in the log file for WebClient. If you would like to remove all of these widgets, use the following file:

RemoveUnusedWidgetsFromSDK.sql (/download/attachments/135989539/RemoveUnusedWidgetsFromSDK.sql?version=1&modificationDate=1622328551517&api=v2)
