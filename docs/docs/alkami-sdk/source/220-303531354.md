## Using Chart.js
### Include Scripts In your View

In your Scripts section of your cshtml you will want to include the following:

Index.cshtml

```
@* core chart library *@
@Html.ScriptWithCacheExpiration("~/lib/chartjs/chart.min.js")

@* If using Time Scales in chart.js then add the following *@
@Html.ScriptWithCacheExpiration("~/lib/chartjs-adapter-date-fns/chartjs-adapter-date-fns.bundle.min.js")
```

### Using Charts in your Widget

Following the charts documentation (https://www.chartjs.org/docs/3.5.1/) should give you a great start on how to use it with your widget.

TLDR Example:

View.cshtml

```
<div style="width: 500px; height: 250px">
<canvas id="myChart" role="img" aria-label="Include meaningful Data here"></canvas>
</div>
<button id="randomize"> Randomize Data </button>
```

app.js

```
const today = new Date();

function randomizeData(date) {
const startDate = new Date(date).setMonth(date.getMonth() - 1);
const endDate = new Date(today);
const DAY_MILLS = (1000 * 3600 * 24);

const days = [];
let d = startDate;
while (d < endDate) {
d = new Date(d);
d.setTime(d.getTime() + DAY_MILLS);
days.push(d);
}
const data = days.map((d) => {
return {
x: d,
y: Math.floor(Math.random() * 401),
}
});

return data;
}

///! ----- THE GOOD STUFF ---- !///

// Get the context of the canvas for the chart
const canvasElement = document.getElementById('myChart');
const ctx = canvasElement.getContext('2d');

// Create the chart with the context, the data, and the options for the chart
const myChart = new Chart(ctx, {
type: 'line',
data: {
datasets: [{
label: 'Account Balance',
data: randomizeData(today),
backgroundColor: 'rgb(0, 113, 229)', // set the color of the inside of the point
borderColor: 'rgb(0, 113, 229)', // set the color of the line and the point border
borderWidth: 1, // make the line thin
fill: {
target: 'origin', // fill the area under the line
above: 'rgba(0, 113, 229, .5)', // set the color of the area under the line
},
}]
},
options: {
plugins: {
legend: {
display: false, // don't show a legend, we will use html for that
},
},
scales: {
x: {
type: 'time', // set this axis as a time axis. requires chartjs-adapter-date-fns
display: true,
ticks: {
maxTicksLimit: 5, // only show 5 values on this axis at any time
// max: endDate, // set an endDate to guarantee you end your graph at a certain time
// min: startDate, // set a startDate to guarantee you start your graph at a certain time
},
grid: {
display: false, // remove the vertical lines
drawBorder: false, // remove the border from the bottom between the text and the graph
},
},
y: {
beginAtZero: true,
grid: {
drawBorder: false, // remove the border from the left between the text and the graph
},
ticks: {
maxTicksLimit: 5, // only show 5 values on this axis at any time
// Include a dollar sign in the ticks
callback: function(value, index, values) {
return '$' + value;
}
},
}
}
}
});

// Make our happy little button work.
const dateFormatter = new Intl.DateTimeFormat('en-US');
const currencyFormatter = var formatter = new Intl.NumberFormat('en-US', {
style: 'currency',
currency: 'USD',
});
document.getElementById('randomize').addEventListener('click', () => {
const randomDay = Math.floor(Math.random() * 100) - 50;
const newStart = new Date(today.setDate(today.getDate() - randomDay));
const data = randomizeData(newStart);
myChart.data.datasets[0].data = data;

// This line sets the aria label to something meaningful for screen readers.
chartElement.setAttribute(`account balance history values in dollars per date. ${data.map(d => dateFormatter.format(d.x) + ': ' + currencyFormatter.format(d.y) + ', '}`);
myChart.update();
});
```

## Using Chart.js with Vue

If your chart data is very simple and you are only passing what is needed for drawing the chart (the values) then the vue-chartjs wrapper can get you up and running quickly in your Vue application with ChartJS.

If you are using a custom data object you will want to use ChartJS directly as the vue-chartjs wrapper does not support custom data such as passing in labels, amounts, and other data along with each element within your chart.

### Include the packages into your project

We are including these packages for types only. At the end of the day they will be pulled out via webpack.

```
npm install chart.js chartjs-adapter-date-fns vue-chartjs
```

### Using Charts in your Components

vue-chartjs gives hooks into chart.js by providing Components for developers to extend. The is is as follows

- Bar
- Bubble
- Doughnut
- HorizontalBar
- Line
- Pie
- PolarArea
- Radar
- Scatter

This Getting Started Guide (https://vue-chartjs.org/guide/) and Coding Reference (https://vue-chartjs.org/api/) was pretty handy when figuring out what to do with the vue components.

Essentially, you can utilize any of these charts by creating components like the Doughnut one in the example below. Just replace Doughnut and the chartOptions with the ones you need:

Doughnut.vue

```
<!--Notice no template -->
<script lang="ts">
import Vue, { PropOptions } from 'vue';
import { Doughnut, mixins } from 'vue-chartjs';
import { ChartData, ChartOptions } from 'chart.js';

const { reactiveProp, reactiveData } = mixins;

export default Vue.extend({
extends: Doughnut,
data() {
return {
options: {
cutout: '85%',
responsive: true,
maintainAspectRatio: true,
plugins: {
legend: {
display: false,
},
},
} as ChartOptions,
};
},
props: {
chartData: {
type: Object,
required: true,
} as PropOptions<ChartData>,
label: {
type: String,
required: true,
},
},
watch: {
label() {
this.setLabel(this.label);
},
},
mixins: [reactiveProp, reactiveData],
methods: {
chart() {
return this as unknown as Doughnut;
},
setLabel(label: string) {
const canvas = this.chart().$refs.canvas as HTMLCanvasElement;

if (canvas) {
canvas.setAttribute('role', 'img');
canvas.setAttribute('aria-label', label);
}
},
},
computed: {},
mounted() {
this.chart().renderChart(this.chartData, this.options);
},
});
</script>
```
