Alkami is using Vue.js in most for the client-side code in most of our widgets. Although you are not required to use Vue.js, if you do then you can benefit from all of the Vue components in Iris.Vue. (also know as Iris 2).

Up until the middle of 2022, you would need to load the Vue libraries from a public CDN. But not most of the files you will need are available from Alkami servers and content locations. We strongly encourage you to use the Alkami-provided files. And if building a dashboard module, you should not include a Vue (or any other client framework files) from a public CDN if those files are already loaded by Alkami. Otherwise, there would be version conflict.

### Including the Vue compiler

The sample code below demostrates the proper way to include these files into your views.

```
@using Alkami.Client.WebClient.Shared.Helpers

@section TitleContentPlaceholder{
@Html.SiteText("Title")
}

@section StyleSheetContentPlaceholder{
@Html.IrisVueLinksSnippet()
}

@section JavaScriptIncludeContentPlaceholder{
@Html.ScriptWithCacheExpiration("~/lib/vue/vue.min.js")

@Html.IrisVueScriptsSnippet()

<script>

new Vue({ ... // continue on with your Vue.js code here
```

In the same way as demonstrated above, if you want to include your own css files or if you do include any style of script files from a CDN, please use the Alkami helper functions that ensure the files are cached.

```
@section StyleSheetContentPlaceHolder {
@Html.CssWithCacheExpiration("~/Areas/SampleAccounts/Styles/SampleAccounts.css")
}

@section JavaScriptIncludeContentPlaceHolder {
@Html.ScriptWithCacheExpiration("~/Areas/SampleMyWidget/Scripts/SampleSpecialScripting.js")
}
```
