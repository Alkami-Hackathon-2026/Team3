### Configuration Tool

Configuration tool is a very instrumental tool that helps with the creation, validation, and testing of the Standard SSO's configuration, a configuration tool (https://packagerepo.orb.alkamitech.com/feeds/choco.dev/Alkami.Microservices.StandardSSO.ConfigTool/versions) was created. The tool has the following features:

- Supports generation of configuration through a visual designer.
- Validate configuration (using the Standard SSO's Engine).
- Evaluate configuration (using real or mocked responses).
- Provides several example configurations to help explore the Standard SSO's feature set.
- Allows for exporting the resulting request as a cURL request (which subsequently can be imported into Postman).If the result's URI is relative it will use the Request's RelativeUriHost from the Input Data tab as the host to build an absolute URI.

NOTE: It is highly recommended to check the syntax of the config with the StandardSSO Config Tool.

### How to install

https://packagerepo.orb.alkamitech.com/feeds/choco.dev/Alkami.Microservices.StandardSSO.ConfigTool/versions (https://packagerepo.orb.alkamitech.com/feeds/choco.dev/Alkami.Microservices.StandardSSO.ConfigTool/versions)

Using the command line on your application server, execute the following command to install the Alkami.Microservices.StandardSSO.ConfigTool for the first time, or after removal.

```
choco install Alkami.Microservices.StandardSSO.ConfigTool -y
```

To upgrade the microservice if it is already installed use this command instead

```
choco upgrade Alkami.Microservices.StandardSSO.ConfigTool -y
```

To specify a specific version include the the following for both install and upgrade: --version {versionNumber}.

### How to test
- Open the config tool. You can open any sample request file as needed.

2. You will get the sample Json file under "Raw JSON tab"

3. Add your Raw JSON config and hit "Validate". It will show "success" upon validation.

4. You can evaluate the configuration by adding your values under "Input Data".

5. Then "Execute" your config. It will create the SSO Url. You can either copy the Url and paste directly in browser or copy the response by hitting "Copy to Clipboard" and test it using postman.
