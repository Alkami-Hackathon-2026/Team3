## Prizeout API Documentation
### Base Path

```
/third-party/v1
```

### Endpoints
#### GET /third-party/v1/prizeout

Description: Initializes Prizeout session and retrieves balance and widget information for the authenticated user. Creates a session, returns a scoped URL and JWT, and retrieves the current cashback balance and widget information.

Authorization: Requires authentication ([Authorize]).

Responses:

- 200 OK: Returns ApiResponse<GetPrizeoutResponse> containing session details, redirect URL, cashback balance, product information, and token data for client-side widget integration.
- 401 Unauthorized: Returns ApiResponse if the user is not authenticated.
- 403 Forbidden: Returns ApiResponse if the user is authenticated but forbidden.
- 500 Internal Server Error: Returns ApiResponse for unexpected errors.

Swagger Annotations:

- Tags: prizeout
- Summary: Initializes Prizeout session and retrieves balance and widget information for the authenticated user
- Description: Initializes the Prizeout integration for the authenticated user. This operation creates a session, returns a scoped URL and JWT, and retrieves the current cashback balance and widget information.
### Models
- GetPrizeoutResponse: Contains session details, redirect URL, cashback balance, product information, and token data.
- ApiResponse: Standard API response wrapper.
### Request

Method: GET

Path: /third-party/v1/prizeout

Headers:

- Authorization: Bearer {token}

Request Body: None

### Response Model Details
#### ApiResponse
| Property | Type | Description |
| isValid | bool | Indicates if the operation was successful |
| statusCode | int | HTTP status code |
| result | T | The response data (see below) |
| error | ErrorDetails | Error details if operation failed |
| timestamp | string (UTC) | Response timestamp |
| correlationId | string | Optional correlation ID for tracking |
#### GetPrizeoutResponse
| Property | Type | Description |
| productName | string | Product name (e.g., "CashBack+") |
| availableBalance | string | Available balance for the account in dollars |
| prizeoutLogoUrl | string | URL to the Prizeout logo |
| fullPageUrl | string | Full page URL for the Prizeout widget (redirect URL) |
| layoutName | string | Layout name for the offer item |
| offerItems | OfferItemDto[] | List of reward offers with cashback/reward information |
| ctaLabel | string | Label text for the CTA button |
#### OfferItemDto
