The Transactions Microservice is responsible for controlling access / allowing updates to transactions, transaction categories, and merchant classification codes. If you need information about a user's or account's transactions, this is where you go.

#### Before you begin
- Ensure you have access to [https://feeds.alkamitech.com](https://feeds.alkamitech.com)
- Validate you have Alkami.MicroServices.Transactions.Service.Host running in your IIS
- You have referenced these two packages in your code Alkami.MicroServices.Transactions.Client and Alkami.MicroServices.Transactions.Client

### Guide

Reference the contract file (https://feeds.alkamitech.com/package-files/download?packageId=Alkami.MicroServices.Transactions.Contracts&version=1.25.0&feedName=nuget.dev&path=src%2FAlkami.MicroServices.Transactions.Contracts%2FITransactionServiceContract.cs) to see the full list of endpoints. In this guide we'll focus on retrieving account information by using GetTransactionsAsync().

#### Usage

```
Call the service in a C# class with the following delegate factory pattern:
```

```
...
using Alkami.MicroServices.Transactions.Contracts;
using Alkami.MicroServices.Transactions.Contracts.Requests;
using Alkami.MicroServices.Transactions.Contracts.Responses;
using Alkami.MicroServices.Transactions.Service.Client;
...

public static Func<ITransactionServiceContract> TransactionService = () => new TransactionServiceClient();

...

```

Get User Accounts With Security Microservice

```
public List<Transaction> GetTransaction(long accountId) {
try {
List<Transaction> results = new List<Transaction>();
int page = 0;
// We are assuming that the accountId is a valid account that belongs to the user.
// Reference the previous example of working with Accounts Microservice to understand how to retrieve the user accounts

// Notice in the Filter we specified that we only want to include all the transactions from last year onward
var transRequest = new GetTransactionsRequest
{
Filter = new Alkami.MicroServices.Transactions.Contracts.TransactionFilter
{
AccountIds = new List<long> { accountId },
StartDate = DateTime.UtcNow.AddYears(-1),
DateSearchField = TransactionDateFields.PostingDate
},
Mapping = new TransactionMapper
{
IncludeSplits = true,
IncludeTransactionCategories = true,
IncludeAdditionalInfo = true,
IncludeTransactionType = true
}
};

this.AugmentRequest(transRequest);

// Since we specified what we want all the transactions from last year
// The result set may be very big
// Is this the most optimal way handling this? Could you think of different approach?
do
{
transRequest.MaxResults = 1000;
transRequest.Page = page;
response = await transactionService.GetTransactionsAsync(transRequest);

if (response.Transactions?.Count > 0)
{
results.AddRange(response.Transactions);
}

page++;
} while ((response.Transactions?.Count > 0) && (results.Count < response.TotalResults));

return results;
} catch (Exception e) {
// Do some sort of Error handling here...
throw e;
}
}
```
