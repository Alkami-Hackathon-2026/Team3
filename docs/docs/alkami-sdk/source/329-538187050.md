The Alkami Embedded should be initialized as soon as the app starts, right after all dependency services are registered in GetIt.

In order to initialize the Alkami Embedded you must create an instance of the AlkamiEmbeddedImpl class. Once you have that you will need to call the initialize method

```
Future<void> initialize({required AlkamiEmbeddedOptions embeddedOptions});
```

This initialize method requires an instance of the AlkamiEmbeddedOptions class. The constructor of AlkamiEmbeddedOptions accepts the following parameters.

```
// This value allows you to hide the Alkami Global Navigation (the top bar and bottom bar
bool hideGlobalNavigation;
// This value allows you to control whether analytics are enabled
bool enabledAnalytics;

// This value is a method that will allow you to override any registered Alkami route within the app.
// The parameter String route is the route that is about to be shown on the screen.
// You can inspect that value and return a bool value indicating if you would like that route to be prevented or shown.
// Where RoutingCallback is defined as typedef RoutingCallback = bool Function(String route);
RoutingCallback? routingCallback;
```

After initialization, AlkamiEmbedded needs to be set with an API environment to access the appropriate data, whether it's live customer data in Production, or test data in Staging or QA.

```
Future<List<EnvironmentModel>> getEnvironments();
Future<void> selectEnvironment({required EnvironmentModel environment});
```

To start an authenticated session with Alkami, you will need to call startAuthSession and pass it your JWT. The code will then exchange this JWT for an Alkami access token, which will be used to manage API requests for the duration of the session. This method will return the access token if successful. For more information, see JWT Authentication (/spaces/SDKC/pages/594820847/JWT+Authentication).

```
/// Starts an authenticated session with Alkami Embedded using a JWT.
/// [jwt] - The JSON Web Token string for authentication
///
Future<String?> startAuthSession(String jwt);
```

To end an authenticated session with Alkami, you need to call endAuthSession. This will log you out of the Alkami system and will require you to re-authenticate via the previous startAuthSession method.

Please note, work on this is ongoing and this is not fully implemented yet. This is being tracked as DEV-220024 (https://jira.alkami.com/browse/DEV-220024).

```
/// Ends the current authenticated session with the Alkami eco-system.
///
Future<void> endAuthSession()
```

The following method is used to navigate to a specific route with the Alkami embedded part of the code. For example the accounts or transfers widget. In order for this to work successfully, you will have to have previously initialized the AlkamiEmbedded framework, selected an environment and started an Alkmai auth session.

```
/// Navigates to a specific route within the Alkami Embedded.
///
/// [routeUrl] - The route path to navigate to (e.g., "accounts", "transfers", "more")
/// [arguments] - The arguments to pass to the route (optional)
///
Future<void> navigate({required String routeUrl, Map<String, dynamic>? arguments});
```

The following method is used to get the main Alkami app widget so that it can be embedded in the host app. In order for this to work successfully, you will have to have previously initialized the AlkamiEmbedded framework, selected an environment and started an Alkami auth session.

```
/// Gets the main Alkami app widget that can be embedded in the host app.
///
/// This returns the complete Alkami banking experience as a widget that can
/// be placed anywhere in the host app's widget tree.
///
/// The Alkami Embedded must be fully initialized before calling this method.
/// [routeUrl] - The initial route path to load within the Alkami widget
///
Widget alkamiWidget({required String routeUrl});
```
