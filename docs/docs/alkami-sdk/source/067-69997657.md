The *.dev.alkamitech.com certificate gets updated from time to time. Sometimes even before its expiration. When the certificate is updated, the old certificate is revoked which prevents IIS from using that certificate. This article describes how to update an existing certificate within IIS.

### Chocolatey Upgrade

```
choco upgrade Alkami.DeveloperKit.Certificates.Wildcard -y
```
