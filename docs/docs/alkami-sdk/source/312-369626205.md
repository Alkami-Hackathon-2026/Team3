TITLE: Deprecate BusinessAchProcessing MS
PARENT: SDK Documentation

-----
Use this guide if you are currently using the Alkami.MicroServices.BusinessACHProcessing.Client or Alkami.MicroServices.BusinessACHProcessing.Data nuget packages in your SDK project. The backing service for these two packages are being deprecated by the 2025.1 ORB release, and so switching over to the ACHTemplates MS is necessary before that date.

Note: The new endpoints for AchTemplates MS are only available starting with ORB release 2024.3

### Step-by-step guide

- Remove nuget references to Alkami.MicroServices.BusinessACHProcessing.Client and Alkami.MicroServices.BusinessACHProcessing.Data
- Add or update nuget references for Alkami.MicroServices.AchTemplates.Service.Client and Alkami.MicroServices.AchTemplates.Contracts
- The same endpoints which were previously available on BusinessACHProcessing are now also available on AchTemplates. So switch to using the AchTemplates clientNote: If you have build errors after switching to the new contracts, you may need to update some of the request properties which were slightly altered in the move. We removed references to the Range type and split filter properties into Start and End properties.
