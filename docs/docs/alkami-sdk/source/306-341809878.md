This document describes the setup and configuration of the software needed to test native mobile apps on physical devices with your local SDK instance.

### Step 1: Download Proxyman

Do a Google search for Proxyman or go to https://proxyman.io/ (https://proxyman.io/).

Select the Proxyman for your platform.

### Step 2: Install ProxyMan

If a Security alert opens about opening the firewall, click Allow access.

### Step 3: Install the Proxyman certificate
- Go to Certificate > Install Certificate on this Windows.
- Click Install & Trust.
- Click Yes.
### Step 4: Install the certificate on the mobile device (assuming physical device)

Go to Certificate > Install Certificate on iOS or Install Certificate on Android, based on your device. A Setup Guide opens.

| | |

If an emulator is being used please follow the instructions below for the emulator being used.

iOS: https://docs.proxyman.com/debug-devices/ios-simulator (https://docs.proxyman.com/debug-devices/ios-simulator)

Android: https://docs.proxyman.com/debug-devices/android-device (https://docs.proxyman.com/debug-devices/android-device)

### Step 5: Enable testing in your local SDK

If you installed fresh with 2024.2 or higher, skip to the next step.

If you did a fresh installation of the SDK before version 2024.2, complete this step.

To test the native mobile app against your local SDK instance:

- Use the following SQL to add the Oauth widget to your database (DeveloperDynamic and Stage Match).Oauth Widget SQL ``` if(exists (select * from core.Widget where AssemblyInfo = 'Alkami.Client.Widgets.Oauth')) begin print 'This has already been added to the core.widget table' end else begin insert into core.widget values (30, 'Oauth', 'Alkami.Client.Widgets.Oauth', 0, 1, NULL, NULL, 0, NULL, GETUTCDATE(), 5, 0, NULL) end ```
- After the script completes, execute Restart-SDKServices in an admin Powershell window.
### Step 6: Download the Native App

Download your app from https://dl.alkami.com/release (https://dl.alkami.com/release) and install it on your device.

### Step 7: Configure the Native app
- After launching the app, an environment picker landing screen opens.
- Tap the empty space on the screen 5 times to open the menu.
- To enable Proxyman, tap Developer Tools. The Dev Tools landing screen opens.
- Tap the Debugging tab.
- Tap the Proxy toggle to the on position. Your system proxy should be autodetected, but you can modify your IP address and port here then tap Save. The Proxyman default port is 9090.
- Return to the environment picker landing screen and select Custom Environment.
- From the Create a Custom Environment screen, in the Default Environment Picker list select a default environment for DeveloperDynamic or enter your stage match site information.
- After you select an environment or enter your environment information, click Make it so. The system returns to the environment picker landing screen.
- Select your testing environment. The app opens and connects to your local SDK instance. You can now use Proxyman to view the app's web traffic and debug and test. The proxy on/off setting is retained even if you force close the application. If you must deactivate it, go to Developer Tools.
### Step 8: Start Testing
## Troubleshooting:
### Disclosure not accepted

If you get a disclosure error once you login that states "Disclosure not accepted Please refresh and accept the disclosure to sign in to the app" with a button that says "Refresh Disclosure" but clicking it just causes the message to close and reopens again. You will need to make sure the alkami.microservices.cms.service.host package is installed by using the command below.

```
choco install alkami.microservices.cms.service.host -y
```
