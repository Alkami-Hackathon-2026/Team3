Presets are like groups of Albus functionality, curated for a specific use case. An example is the legacy preset which handles transpiling TypeScript, compiling SCSS files, and minifying JavaScript and CSS files.

#### Legacy Preset

If you are converting a project that uses a gulpfile.js you almost certainly will use the legacy preset. This preset contains all of the tasks that the ORB gulpfile.js that widgets use.

Check out the preset documentation (/spaces/SDKC/pages/303531414/Legacy+Preset) for more information about this preset.

```
$ npm install @alkami/albus-preset-legacy --save-dev
```

#### SCSS Preset

Use this preset if you need SCSS compilation on it's own or with another preset (e.g., Webpack).

Check out the preset documentation (/spaces/SDKC/pages/303531415/SCSS+Preset) for more information about this preset.

```
$ npm install @alkami/albus-preset-sass --save-dev
```

#### Vue Preset

If you are building on a Vue 2 application. This preset wraps a Webpack flow that compiles Vue files into javascript and css modules.

Check out the preset documentation (/spaces/SDKC/pages/303531417/Vue+Preset) for more information about this preset.

```
$ npm install @alkami/albus-preset-vue --save-dev
```

#### Vue3 Preset

If you are building a brand new frontend experience then this will most likely be your preset. This preset wraps a Webpack flow that compiles Vue files into javascript and css modules utilizing Vue 3.

Check out the preset documentation (/spaces/SDKC/pages/303531416/Vue+3+Preset) for more information about this preset.

```
$ npm install @alkami/albus-preset-vue3 --save-dev
```
