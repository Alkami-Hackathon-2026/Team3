## Why

Sometimes you need to display within the Alkami experience content that comes from another website. Usually this will be through a Single Sign experience. If you are building a single SSO, then we encourage you to use the Alkami Standard SSO approach which is described at Alkami Standard SSO Configuration Tool (Jarvis) (/spaces/SDKC/pages/141527390/Alkami+Standard+SSO+Configuration+Tool+Jarvis)

If you are building something completely custom, then the examples below should get you started. Note that you may have CORS issues that prevent your content from being displayed. Additionally, in the native mobile apps, the mobile OS imposes additional restrictions on the contents of webviews-- especially accessing sites from other domains.

## In a Desktop View
### IFrame (Inline)

```
<iframe src="https://alkami.com"></iframe>
```

### Pop-Up

```
@section JavaScriptIncludeContentPlaceholder{
<script language="javascript" type="text/javascript">
function popitup(url) {
newwindow = window.open(url, 'name', 'height=200,width=150');
if (window.focus) { newwindow.focus() }
return false;
}
</script>
}

<h2>New Window (desktop)</h2>
<br>
<br>
<a href="https://www.google.com" onclick="return popitup('https://www.google.com')">Click here for popup</a>
```

## In a Mobile View
### IFrame (Inline)

```
<h2>Mobile</h2>

<br>
This page is going to try to display an iFrame below. But it will probably not work due to CORS or other security restrictions.
<br>
<iframe src="https://google.com"></iframe>
```

### Pop-Up

```
@section BodyScripts{
<script>
window.nativeHook.setNavBar({
text: '@Html.SiteText("MobileTitle")',
left: { button: 'drawer' }
});
</script>

<script language="javascript" type="text/javascript">

function popitup(url) {
newwindow = window.open(url, 'name', 'height=200,width=150');
if (window.focus) { newwindow.focus() }
return false;
}
</script>
}

<h2>New Window (Mobile)</h2>
<br>

<a href="https://www.google.com" onclick="return popitup('https://www.google.com')">Click here for popup</a>

<br>
<a href="/Areas/SamplePopups/Images/SamplePDF.pdf?nativeDocType=pdf" onclick="return popitup('/Areas/SamplePopups/Images/SamplePDF.pdf?nativeDocType=pdf')">Click here for a PDF</a>
```
