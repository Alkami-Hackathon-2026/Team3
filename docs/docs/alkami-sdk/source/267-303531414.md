If you are converting a project that currently uses a gulpfile.js to process front end assets, this is the Albus equivalent. This preset contains all of the same functionality that the gulpfile has as well as a few additional bells and whistles. This preset is responsible for these tasks:

- Minifies JavaScript files
- Minifies CSS files
- Bundles using the bundle.json convention
- Compiles SCSS files
- Transpiles TypeScript files
### Installation

To install this preset use the following command:

```
$ npm install @alkami/albus-preset-legacy --save-dev
```

#### Additional Requirements

This preset has additional file requirements. Either run albus catalyst or manually create them (/spaces/SDKC/pages/303531407/Additional+Files).

If you are using TypeScript:

- tsconfig.json
- tslint.json

If you are using SCSS:

- postcss.config.js
- .browserslistrc

All of these files go into the solution's root.

### Plugins

This preset has a handful of plugins available to accomplish an array of tasks.

#### Bundle-js

This plugin bundles all js in the bundle.json pattern established in ORB. For more on bundles check out the documentation (/pages/viewpage.action?pageId=30934048).

Default configuration

```
'bundle-js': {
destination: '.', // Where the files end up on build
files: [ // Glob of files to be minified
'<projectNamespace>/Scripts/**/*.bundle/bundle.json'
],
watch: [ // Glob of files to be watched
'<projectNamespace>/Scripts/**/*.bundle/bundle.json',
'<projectNamespace>/Scripts/**/*.bundle/*.{js,min.js}',
'!<projectNamespace>/Scripts/**/*.bundle/*.bundle.{js,min.js}'
],
clean: [ // Glob of files to be deployed
'<projectNamespace>/Scripts/**/*.bundle/*.bundle.{js,min.js}{,.map}'
],
deploy: [ // Glob of files to be watched
'<projectNamespace>/Scripts/**/*.bundle/*.bundle.{js,min.js}{,.map}'
]
}
```

#### Minify-js

This plugin minifies any standard js file using uglify-es.

Default configuration

```
'minify-js': {
destination: '.', // Where the files end up on build
files: [ // Glob of files to be minified
'<projectNamespace>/Scripts/**/*.js',
'!<projectNamespace>/Scripts/**/*.bundle/*.js',
'!<projectNamespace>/Scripts/**/*{.min,-ts}.js'
],
clean: [ // Glob of files to be cleaned
'<projectNamespace>/Scripts/**/*.min.js{,.map}',
'!<projectNamespace>/Scripts/**/*.bundle/*.min.js{,.map}',
'!<projectNamespace>/Scripts/**/*-ts.js{,.map}'
],
deploy: [ // Glob of files to be deployed
'<projectNamespace>/Scripts/**/*.min.js{,.map}',
'!<projectNamespace>/Scripts/**/*.bundle/*.min.js{,.map}',
'!<projectNamespace>/Scripts/**/*-ts.js{,.map}'
],
watch: [ // Glob of files to be watched
'<projectNamespace>/Scripts/**/*.js',
'!<projectNamespace>/Scripts/**/*.bundle/*.js',
'!<projectNamespace>/Scripts/**/*{.min,-ts}.js'
]
}
```

#### Compile-sass

This plugin uses the albus-preset-sass to compile SCSS files into CSS.

Default configuration

```
'compile-sass': {
sassOptions: { // options to pass to the node-sass*
outputStyle: 'compressed'
},
destination: '.', // Where the files end up on build
files: [ // Glob of files to be minified
'<projectNamespace>/Styles/**/*.scss'
],
clean: [ // Glob of files to be cleaned
'<projectNamespace>/Styles/**/*.min.css{,.map}'
],
deploy: [ // Glob of files to be deployed
'<projectNamespace>/Styles/**/*.min.css{,.map}'
],
watch: [ // Glob of files to be watched
'<projectNamespace>/Styles/**/*.scss'
]
}
```

To see what other options are available to pass to the compiler, check out the node sass options (https://github.com/sass/node-sass#options).

#### Compile-ts

This plugin transpiles TypeScript files and minifies the output.

Default configuration

```
'compile-ts': {
tsconfigPath: 'tsconfig.json', // provide location of tsconfig.json (v1.7.0+)
minify: true, // minify output using uglify
suffix: null, // add a suffix. To support a codebase that uses something like '-ts'
files: [], // manually specify files to build instead of inferring from tsconfig
destination: '.' // where the files end up on build
}
```

### Configuration

There are times that the the presets default behavior isn't right for your application. This is where you can alter the configuration to tweak it more to your liking. Don't need Typescript building? remove it from the plugins property. Javascript not in Scripts folder, change the globs.

Here is a sample configuration for reference:

Configuration reference

```
module.exports = {
tokens: {
projectNamespace: 'Alkami.Apps.Widget',
orbWidgetName: 'Widget'
},
presets: ['legacy'],
presetConfiguration: {
'legacy': {
plugins: [
'bundle-js',
'compile-sass',
'compile-ts',
'minify-js'
],
pluginConfiguration: {
'bundle-js': {},
'compile-sass': {},
'compile-ts': {}
'minify-js': {},
}
}
}
};
```
