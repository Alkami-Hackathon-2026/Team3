## Overview

This documents how Client Facing technical teams such as Support and the Technical Consultants should engage other groups for troubleshooting an issue for a Standard SSO widget.

## New Rollouts

New rollouts mean these are products that were recently completed by a development team such as Carbon, Campaigns, Card Experience, etc. for a go live or Phase 2 commitment.

- Support finds an issue and performs their troubleshooting with some guidance from Standard-SSO - How to Troubleshoot StandardSSO. If further dev assistance is needed, Support must create a Technical Review ticket to document all troubleshooting steps that have been performed. This should be assigned to the Development team that owns the SSO product itself. A quick way of doing this is to refer to the tech guide and see which sprint team owns the product. An easy way to start searching for Tech Guides is through Technical Guides. Questions will supplement the details provided in the Technical Review ticket that are needing to be addressed by a development team should be forwarded to the slack channel #sme-carbon or #eng-ask-carbon and should be a thread within the channel.
- The scrum team receives the Tech Review ticket and works with Support as needed to troubleshoot.
## Existing SSOs or SSOs that were Converted to Standard SSO
- Standard SSO Conversions are classified as Category 1 projects for PSO. Below is a table that details the Role and Access for each group for this project category.
- Support engages the PSO Technical Consultant assigned to this project for troubleshooting. If the Technical Consultant needs further assistance, they will need to open a Tech Review ticket with details on what troubleshooting steps have been performed and what type of input they are looking for from the development team. This ticket must be assigned to the owning scrum team and can be easily confirmed via the Tech Guides which can be found in Technical Guides. Questions that are needing to be addressed by a development team to supplement the details in the Tech Review ticket should be forwarded to the slack channel #sme-carbon or #eng-ask-carbon and should be a thread within the channel.
