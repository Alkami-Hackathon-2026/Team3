- Once the SDK Submission team receives the approval, they will transition the SDK Submission ticket to the Waiting for Prod Deployment state. The submission will be scheduled for the next production time slot for the Pod that is assigned to your Financial Institution.
- When it is deemed functionally acceptable and secure, Alkami will install your submission into production and run your configuration scripts to activate the code in the Production server for Production Deployment. This is the final stage and once this is complete the code will be available to your end users.
