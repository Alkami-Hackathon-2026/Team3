Generally speaking, expressions can be either an operation to be evaluated or a constant string. Expressions can be used anywhere that the configuration schema allows and expects expressions to exist. Once evaluated, all expressions ultimately produce a string as a result.

The following page will provide general syntax rules building expressions.

## Guidelines
#### Expression Escapes

Operations within an expression are escaped using "{{" to start an operation and "}} to end it.

NOTE: There cannot be any spacing between the curly braces.

| Examples | Result |
| ``` {{ FirstName }} ``` | John |
| ``` {{ FirstName }}, {{ LastName }} ``` | John, Doe |
| ``` Who is {{ FirstName }}? ``` | Who is John? |
#### Quotes

Expressions can declare strings within an operation using a single tick or double quotes (i.e. ' or ").

| Examples | Result |
| ``` {{ 'Single Tick' }} vs. {{ "Double Tick" }} ``` | Single Tick vs. Double Tick |
#### Quote Strings

Expressions can escape the quote string by doubling up the quote string.

| Examples | Result |
| ``` {{ 'Bob said ''Does that work?''' }} ``` | Bob said 'Does that work?' |
| ``` {{ "Bob said ""Does that work?""" }} ``` | Bob said "Does that work?" |
| ``` {{ "Bob said 'Does that work?'" }} ``` | Bod said 'Does that work?' |
#### Mixed Quotes

Expressions can mix using single tick or double quotes to avoid escaping the quote character.

| Examples | Result |
| ``` {{ "Bob said 'Does that work?'" }} ``` | Bod said 'Does that work?' |
#### Case Insensitivity

Expressions are not case-sensitive.

| Examples | Result |
| ``` {{ Append('A', 'B') }} ``` | AB |
| ``` {{ append('A', 'B') }} ``` | AB |
#### White-space Tolerant

Expressions do not require specific white-space, though it is recommended to improve readability.

| Examples | Result |
| ``` {{Append('A','B')}} ``` | AB |
| ``` {{ Append ( 'A' , 'B' ) }} ``` | AB |
#### Numbers

Expressions can contain numbers, but will ultimately be treated as strings.

| Examples | Result |
| ``` {{ 12345 }} ``` | 12345 |
#### Methods

Expressions can refer to methods by prefixing the method name with the '@' symbol. Methods compute a value once and can be reused in multiple places. See Method documentation (https://confluence.alkami.com/display/ISG/Standard+SSO+-+Methods) for more details.

NOTE: The method name must exist in the configuration, must have a name of at least one character in length, and is case-insensitive.

| Examples | Result |
| ``` {{ @hash }} ``` | pDwbCqU6DJCIEMBqsf85Zw== |

Valid Hash Algorithms:

SHA256,SHA384,SHA512

Valid Encoding:

Hex, Base64
