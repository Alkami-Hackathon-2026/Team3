Alkami.FlashBanner is a component to notify users about the status of the application through a temporary banner across the top of the screen.

#### hide()

Hides the visible banner early before the timer is triggers. Does nothing otherwise.

Arguments

- None

Returns

- (void): Returns void.
#### show(message, type)

Shows a message in a banner on the screen of the notification type specified.

Arguments

- message (string)
- type (string) - 'bulletin', 'caution', 'error', 'message', 'info', 'success', or 'warning'

Returns

- (void): Returns void.

#### flashBanner(messageElement, bannerOptions)

function to show a message in a banner with detailed option handling.

Arguments

- messageElement (HTMLElement)
- bannerOptions (IFlashBannerOptions)
##### Banner Options (IFlashBannerOptions)

The default Banner Options display a success banner for 6 seconds attached to the #meta_header element. Your options will be merged with the default.

```
interface IFlashBannerOptions {
attachToElement?: HTMLElement; // element in which the banner should be attached to
flashBannerDisplayTime?: number; // the amount of time to show the banner (in ms)
bulletin?: boolean; // display bulletin banner instead of success
caution?: boolean; // display caution banner instead of success
error?: boolean; // display error banner instead of success
message?: boolean; // display message banner instead of success
info?: boolean; // display info banner instead of success
success?: boolean; // display success banner
warning?: boolean; // display warning banner instead of success
}
```
