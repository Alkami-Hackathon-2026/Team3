A widget can be enabled for desktop, mobile and tablet devices. Below are the devices and their corresponding values that should be set in the core.Widget and core.FlavorWidget tables

| Device | Value |
| Hidden | 0 |
| Desktop | 1 |
| Mobile | 2 |
| Desktop and Mobile | 3 |
| Tablet | 4 |
| All | 7 |

These values should be set in the install_widget.sql script that comes with the widget template. Below is a small snippet of that script to illustrate what needs to change, the very last line is where the value should be set.

install_widget.sql

```
SELECT @WidgetName = 'USBFCUTravelNotes' --required
,@WidgetAssemblyInfo = 'USBFCU.Client.Widget.TravelNotes' --required
,@WidgetDisplayName = 'Travel Notes' -- User friendly display name
,@WidgetDescription = 'A widget for traveling notes.' -- User friendly description
,@WidgetIconName = 'list'
,@WidgetDisplaySettings = '0' -- This is a HIDDEN widget.
```
