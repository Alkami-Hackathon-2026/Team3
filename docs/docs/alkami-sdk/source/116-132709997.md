The current problem is that every time the Index page is loaded the snippet is recompiled and a new DLL is created in the temporary internet files. In order to avoid a compile we will be returning a static static string in the form of a ContentResult from the Index controller action in EmbeddedSnippetBehavior.cs.

###### Depending on how complex your code is and the amount and type of characters that may need escaping will play a role in deciding which of the solutions below are chosen.
#### Solution 1:
###### If you have a small snippet that does not have alot of quotes that need escaping you consider typing the string directly into the Content parameter of the ContentResult as shown below. Feel free to put the text into a variable I did not to get the illustration simple.

#### Solution 2:

An alternative solution would be to include an embedded txt file in the project that will be loaded up for you. The benefit here is that all the escaping will be done for you. The code below will return the SnippetContent page as static string that browser will interpret as html

Dont forget to replace {AssembleName} with the name of your Assemble that contains the embedded resource .this is actually the name of the assemble but the assemble and project are usually named the they usually have the same name.

Your assemble Name can be found in your project properties

```
private ActionResult Index(Controller controller)
{
var assembly = Assembly.GetExecutingAssembly();
var resourceName = "{AssembleName}.SnippetContent.txt";

string result;
using (Stream stream = assembly.GetManifestResourceStream(resourceName))
using (StreamReader reader = new StreamReader(stream))
{
result = reader.ReadToEnd();
}

return new ContentResult() { Content = result, ContentType = "text/html", ContentEncoding = System.Text.Encoding.UTF8 };
}
```

This is what in in the SnippetContent.txt

This is how the browser will display that content

How to add a embedded resource. Dont forget to click save all to save the project file after doing this.

While this solution is more complex is will automatically add escape characters \ for you.
In order to display the same content using the first solution more escape characters \ would need be added.

To use solution 1 to generate the same output you would need:
"Check out my 'escaped' \"Snippet\" <b> bold Move! </b>"
