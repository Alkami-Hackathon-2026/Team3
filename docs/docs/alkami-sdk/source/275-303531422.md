Since Albus 1.9.0, CSSNano was replaced with CSSO in the Vue Preset to provide better CSS optimization with a performance boost. To make this change, your project's PostCSS configuration will need to be updated.

## Automatic Upgrade to CSSO

To automatically upgrade your project to CSSO after updating your Albus dependencies, you can simply re-run Catalyst in your repo's root directory to generate the necessary files:

npx albus catalyst -C Alkami.Client.Widget.MyWidget

Once this is completed, you'll notice that the postcss.config.js was changed. You'll want to commit this change. Once complete, your CSSO upgrade will be complete and you can continue developing!

## Manual Upgrade

To manually upgrade to CSSO after updating your Albus dependencies, you will want to replace your current postcss.config.js with the following contents:

repo-root/Alkami.Client.Widget.MyWidget/postcss.config.js

```
module.exports = {
plugins: {
autoprefixer: {},
'postcss-csso': {
restructure: false,
},
},
};
```
