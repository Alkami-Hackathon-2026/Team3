This page describes how to enroll in Alkami University's SDK training. Non-developers are welcome to attend the training.

Ensure your computer or virtual machine can run the SDK. The Merlin SDK Wizard provides information about hardware and software requirements.

To enroll in the SDK training:

- To access the enrollment page, go to https://au.myabsorb.com/#/signup.
- In the Key Name field, enter SDK Training.
- Click Sign Up. The Sign Up page opens.
- Fill in the required fields:First NameLast Name Email Password Re-enter Password Financial Institution
- Click Sign Up. Your new account is created in approximately 30 seconds.

Start the SDK training courses. They are organized in the proper order.

Contact your Alkami Account Executive with issues or inquiries.
