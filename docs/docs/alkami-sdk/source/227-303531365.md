Once the main entry point has imported all of the global libraries and done the Vue instance registration, it's time for the first component of the application. This component accomplishes these things:

- Sets the initial HTML structure for the page
- Manages a global loading state
- Registers areas for the router to attach to
- Kicks off additional requests for data as needed

Let's look at an example:

App.vue - HTML Template

```
<template>
<div class="app">
<NavBar />
<router-view name="page" />
</div>
</template>
```

App.vue - Script Section

```
<script setup lang="ts"> // setup automagically returns and exports all the globals in the script tag
import { onMounted } from 'vue';
import { useStore } from './store';
import { logoutUser } from './api/requests';

// Child Components
import NavBar from '.components/NavBar.vue'

const store = useStore();

async function logoutUserCall() {
await logoutUser();
this.$router.push({ name: 'login' });
};

onMounted(() => {
store.getInitialData();
});
</script>
```
