### Session Information

Last client conference we unveiled our internal design system, Iris. This year we want to talk about a new way to implement Iris components through the front end JavaScript framework Vue. This project is a deep integration with the framework allowing developers to quickly iterate on building products complete with lifecycle events, dynamic data, and seamless updates to boot. Join us to see the future of building front ends on the Alkami platform!

Presenter: Lance Turri
