The components folder is where all the components for the application live. These are different than the components that live in the "Views" folder because they are not associated with a route definition. Ultimately these components will all be imported by a view at one point during the user experience, and are not one of the main landing pages of the experience.

All components should be written using the single file component (SFC) model with the script tag leveraging TypeScript, style tag using the SCSS syntax, and standard HTML in the template. Additionally, the styles should always use the "scoped" tag to minimize naming collisions in the application.

Component.vue | HTML

```
<template>
<div class="tenant-card">
<div
class="iris-card iris-card--shadow"
data-hoverable
role="button"
tabindex="0"
@click="selectTenant"
@keydown.prevent.stop.enter.space="selectTenant"
>
<div class="tenant-card__header iris-card__header">
<h4 class="tenant-card__title iris-card__title truncate">
{{ props.tenant.name }}
</h4>
<div class="tenant-card__url truncate">
{{ props.tenant.bankUrlSignatures[0] }}
</div>
</div>
</div>
</div>
</template>
```

Things of note:

- Write accessible HTML by using the correct roles and other aria standards
- Only one element can be at the root of a template tag
- If there are a lot of HTML properties, consider breaking each of them onto their own line to ease readability in the future
- Along the same lines, group the properties first by HTML attributes followed by Vue attributes.

Component.vue | Script

```
<script setup lang="ts">
// Import Interfaces
import { computed } from '@vue/reactivity';
import { defineProps } from 'vue';
import { ITenant } from '../interfaces/ITenant';
import router from '../router';
import { useStore } from '../store';

const store = useStore();

// Type your props for your Component
interface Props {
tenant: ITenant;
}
// DO NOT DESTRUCTURE PROPS, they will loose their reactivity
const props = defineProps<Props>();

async function selectTenant() {
selectedTenant.value = props.tenant;
await router.push('explore');
}

// computed property to utilize the store
const selectedTenant = computed({
get: () => {
return store.selectedTenant;
},
set: (newValue: ITenant) => {
store.setSelectedTenant(newValue);
},
});
</script>
```

Things of note:

- The "lang" attribute should always be "ts" to leverage TypeScript
- setup will automagically setup the component for us
- Group interface imports and child component imports to improve readability
- Always give a return type for a computed property

Pro Tip

To get full TypeScript support for a prop, create an interface for the Props and define the custom Type within the interface.

Component.vue | SCSS

```
<style lang="scss" scoped>
.tenant-card {

}

.tenant-card__title {
font-size: 24px;
padding-bottom: 5px;
}

.tenant-card__url {

}
</style>
```

Things of note:

- The "lang" attribute should be "scss" to leverage SCSS language features.
- The "scoped" attribute should always be used to prevent naming collisions with the rest of the application
