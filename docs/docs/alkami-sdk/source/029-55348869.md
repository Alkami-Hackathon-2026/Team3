Componentization!

Alkami is moving forward at a ferocious pace to componentize the remaining WebClient plugins. This process is ongoing and we expect it to run through the entire year. Each new SDK release will become leaner and we will begin to remove dependencies into their own features.

For the interim, we will be iterating on the SDK release process to turn it into a lean and quick install. At this time we are still working through some of the feature dependency and apologize for any instability that needs troubleshooting.
