### 1. Prerequisites

This article assumes you have already completed the SDK Setup (https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html) and at this point you should be able to login to the Admin and Client sites.

### 2. Install Required Elements

Note: After installing these elements, I've found it necessary to reboot and run Restart-SDKServices to get the new elements up and running correctly.

##### Install/Upgrade Business ACH Elements
Business ACH

```
choco upgrade -y Alkami.Apps.BusinessAdmin Alkami.Client.Widgets.BusinessAdmin.Users Alkami.MS.Username.Service.Host Alkami.Admin.Widgets.Operations Alkami.Admin.Widgets.OperationsSidebar Alkami.MicroServices.BusinessReportsData.Service.Host Alkami.MicroServices.BusinessEvents.Service.Host Alkami.MicroServices.Limits.Service.Host Alkami.MS.BusinessPayees.Service.Host Alkami.MS.PaymentCompany.Service.Host Alkami.Admin.Widgets.RetailACH Alkami.MicroServices.Reports.Export.Service.Host Alkami.MS.Reporting.BusinessReports.Service.Host Alkami.Apps.BusinessACH Alkami.MicroServices.AchTemplates.Service.Host Alkami.MicroServices.BusinessAchConfiguration.Service.Host Alkami.MicroServices.BusinessACHProcessing.Service.Host Alkami.MicroServices.NachaFileGenerator.Service.Host Alkami.App.Providers.ACH.NachaOutputBusiness Alkami.App.Providers.ACH.NachaOutput Alkami.MS.EM.Processor.ScheduledACH.Host Alkami.MS.OrbProxy.Service.Host
```

##### Install/Upgrade Business Wire Elements

Note: You'll notice that there are duplicate elements here compared to the ACH setup, that's because these are intended to ensure everything is setup for ACH/Wires even if you just run one of these

Business Wires

```
choco upgrade -y Alkami.Apps.BusinessAdmin Alkami.Client.Widgets.BusinessAdmin.Users Alkami.MS.Username.Service.Host Alkami.Admin.Widgets.Operations Alkami.Admin.Widgets.OperationsSidebar Alkami.MicroServices.BusinessEvents.Service.Host Alkami.MicroServices.Limits.Service.Host Alkami.MS.BusinessPayees.Service.Host Alkami.MS.PaymentCompany.Service.Host Alkami.Admin.Widgets.RetailACH Alkami.MicroServices.Reports.Export.Service.Host Alkami.MS.Reporting.BusinessReports.Service.Host Alkami.Services.Tenant Alkami.Services.BusinessSecurity Alkami.App.Processor.Wire.FedwireOutput Alkami.Apps.BusinessWires Alkami.MS.BusinessWires.Service.Host Alkami.MS.WireProcessor.WireXChange.Service.Host Alkami.MS.EM.Processor.ScheduledWire.Host Alkami.MS.EM.Processor.WireStatusChange.Host Alkami.MS.WireCustomization.Service.Host Alkami.MS.OrbProxy.Service.Host

```

### 3. Configure Business Flavor

Run the following SQL (uncomment the 'COMMIT TRAN' at the end of each) to convert the old Widgets to the new Widgets

Once you've successfully ran the sql then you may navigate to the Business Banking Flavor under Setup > Packages and enable the Business ACH and Business Wire widgets for the flavor/package.

Business ACH Widget

```
WHILE @@TRANCOUNT > 0 ROLLBACK
SET XACT_ABORT ON
SET NOCOUNT ON
SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED

USE DeveloperDynamic

BEGIN TRAN

--Configuration variables6
DECLARE @OldWidgetName NVARCHAR(100) = 'AchPayments', -- If one exists
@WidgetName NVARCHAR(100) = 'BusinessACH',
@WidgetDisplayName NVARCHAR(100) = 'Business ACH',
@WidgetAssemblyInfo NVARCHAR(100) = 'Alkami.Client.Widgets.BusinessACH',
@WidgetDescription NVARCHAR(100) = 'Create and Manage ACH Payment Templates',
@WidgetIconName NVARCHAR(100) = 'ach-payments',
@WidgetIsActive BIT = 1, --Should be able to add the widget to a flavor and be visible to use
@WidgetDisplaySettings INT = 7, -- Platforms the widget should be available
@WidgetType INT = 7,
@WidgetNotificationExists BIT = 1, -- If 0 then no widget notification will be created
@WidgetNotificationIsBusinessOnly BIT = 1;

--------------------------------------------------------
--Changes below here should be uncessary for new widgets
--------------------------------------------------------

--Script variables
DECLARE @BankId BIGINT,
@WidgetId BIGINT,
@LocalizableResourceWidgetName NVARCHAR(MAX) = 'Widget.' + @WidgetName,
@LocalizableResourceId BIGINT,
@LocalizableItemId BIGINT,
@LocalizableItemSettingDisplayNameId BIGINT,
@LocalizableItemSettingDescriptionId BIGINT,
@WidgetNotificationActionId BIGINT,
@OldWidgetId BIGINT,
@OldLocalizableResourceWidgetName NVARCHAR(MAX) = 'Widget.' + @OldWidgetName,
@OldLocalizableItemId BIGINT,
@OldLocalizableResourceId BIGINT,
@OldWidgetNotificationActionId BIGINT;

DECLARE @RowCount BIGINT;

SELECT @BankId = Id FROM core.Bank
SELECT @OldWidgetId = Id FROM core.Widget WHERE Name = @OldWidgetName
SELECT @WidgetId = Id FROM core.Widget WHERE Name = @WidgetName
SELECT @LocalizableResourceId = Id FROM dbo.LocalizableResource lr WHERE lr.Name = @LocalizableResourceWidgetName
SELECT @OldLocalizableResourceId = Id FROM dbo.LocalizableResource lr WHERE lr.Name = @OldLocalizableResourceWidgetName
SELECT @LocalizableItemId = Id FROM core.Item WHERE ItemType = 'Localizable Resource' AND ParentId = @LocalizableResourceId
SELECT @OldLocalizableItemId = Id FROM core.Item WHERE ItemType = 'Localizable Resource' AND ParentId = @OldLocalizableResourceId
SELECT @LocalizableItemSettingDisplayNameId = Id FROM core.ItemSetting WHERE ItemId = @LocalizableItemId AND Name = 'DisplayName'
SELECT @LocalizableItemSettingDescriptionId = Id FROM core.ItemSetting WHERE ItemId = @LocalizableItemId AND Name = 'Description'
SELECT @WidgetNotificationActionId = Id FROM core.WidgetNotificationAction WHERE WidgetID = @WidgetId
SELECT @OldWidgetNotificationActionId = Id FROM core.WidgetNotificationAction WHERE WidgetID = @OldWidgetId

--Insert/Update Widget
IF @WidgetId IS NULL
BEGIN
INSERT INTO core.Widget
(BankID, Name, AssemblyInfo, Salt, Active, IconImage, IconContentType, CanBeRemoved, Slug, CreateDate, DisplaySettings, WidgetType, IconName)
VALUES
(@BankId, @WidgetName, @WidgetAssemblyInfo, 0, @WidgetIsActive, null, null, 1, null, GETUTCDATE(), @WidgetDisplaySettings, @WidgetType, @WidgetIconName)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.Widget records'

SET @WidgetId = SCOPE_IDENTITY()
END
ELSE
BEGIN
UPDATE core.Widget
SET IconName = @WidgetIconName
WHERE Id = @WidgetId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.Widget records'
END

SELECT * FROM core.Widget WHERE Id = @WidgetId

--Insert Localizable Resource
IF @LocalizableResourceId IS NULL
BEGIN
INSERT INTO dbo.LocalizableResource
(Name, SecondaryId)
VALUES
(@LocalizableResourceWidgetName, -1)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' dbo.LocalizableResource records'

SET @LocalizableResourceId = SCOPE_IDENTITY()
END

SELECT * FROM dbo.LocalizableResource WHERE Id = @LocalizableResourceId

--Insert Localizable Resource Item
IF @LocalizableItemId IS NULL
BEGIN
INSERT INTO core.Item
(ItemType, ParentId, SecondaryId, Name, CreatedUtc, Version, Deleted, LastUpdate)
VALUES
('Localizable Resource', @LocalizableResourceId, 1033, @LocalizableResourceWidgetName, GETUTCDATE(), '1.0.0.0', 0, NULL)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.Item records'

SET @LocalizableItemId = SCOPE_IDENTITY()

END

SELECT * FROM core.Item WHERE Id = @LocalizableItemId

--Insert widget display name
IF @LocalizableItemSettingDisplayNameId IS NULL
BEGIN
INSERT INTO core.ItemSetting
(ItemId, Name, Value, CreatedUtc, Version, LastUpdate)
VALUES
(@LocalizableItemId, 'DisplayName', @WidgetDisplayName, GETUTCDATE(), '1.0.0.0', NULL)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.ItemSetting records'

SET @LocalizableItemSettingDisplayNameId = SCOPE_IDENTITY()
END

SELECT * FROM core.ItemSetting WHERE Id = @LocalizableItemSettingDisplayNameId

--Insert widget descrption (shown when selecting a widget to add as a user)
IF @LocalizableItemSettingDescriptionId IS NULL
BEGIN
INSERT INTO core.ItemSetting
(ItemId, Name, Value, CreatedUtc, Version, LastUpdate)
VALUES
(@LocalizableItemId, 'Description', @WidgetDescription, GETUTCDATE(), '1.0.0.0', NULL)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.ItemSetting records'

SET @LocalizableItemSettingDescriptionId = SCOPE_IDENTITY()
END

SELECT * FROM core.ItemSetting WHERE Id = @LocalizableItemSettingDescriptionId

--Insert widget notification action
IF @WidgetNotificationExists = 1 AND @WidgetNotificationActionId IS NULL
BEGIN
INSERT INTO core.WidgetNotificationAction
(WidgetId, Name, BusinessOnly, EnabledByDefault)
VALUES
(@WidgetId, @WidgetDisplayName, @WidgetNotificationIsBusinessOnly, 0)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.WidgetNotificationAction records'

SET @WidgetNotificationActionId = SCOPE_IDENTITY()
END

SELECT * FROM core.WidgetNotificationAction WHERE Id = @WidgetNotificationActionId

--Update Widget Settings
UPDATE core.WidgetSetting
SET WidgetID = @WidgetId
WHERE WidgetID = @OldWidgetId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.WidgetSetting records'

SELECT * FROM core.WidgetSetting WHERE WidgetId = @WidgetId

-- Update Flavor Widgets
UPDATE core.FlavorWidget
SET WidgetID = @WidgetId
WHERE WidgetID = @OldWidgetId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.FlavorWidget records'

select * from core.FlavorWidget WHERE WidgetID = @WidgetId

-- Update User Widgets
UPDATE core.UserWidget
SET WidgetID = @WidgetId
WHERE WidgetID = @OldWidgetId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.UserWidget records'

select * from core.UserWidget WHERE WidgetID = @WidgetId

-- User Widget Notification Preference
UPDATE notify.UserWidgetNotificationPreference
SET WidgetNotificationActionID = @WidgetNotificationActionId
WHERE WidgetNotificationActionID = @OldWidgetNotificationActionId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' notify.UserWidgetNotificationPreference records'

select * from notify.UserWidgetNotificationPreference WHERE WidgetNotificationActionID = @WidgetNotificationActionId

-- Delete Old Widget
DELETE FROM core.Widget
WHERE Id = @OldWidgetId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Deleted ' + CAST(@RowCount as nvarchar(10)) + ' core.Widget records'

--Delete Old Widget localizable item settings
IF @OldLocalizableItemId IS NOT NULL
BEGIN

SELECT csd.*
FROM core.ChangesetDetail csd
JOIN core.Changeset cs ON cs.Id = csd.ChangesetId
WHERE cs.ItemId = @OldLocalizableItemId;

DELETE csd
FROM core.ChangesetDetail csd
JOIN core.Changeset cs ON cs.Id = csd.ChangesetId
WHERE cs.ItemId = @OldLocalizableItemId;

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Deleted ' + CAST(@RowCount as nvarchar(10)) + ' core.ChangesetDetail records'

SELECT * FROM core.Changeset WHERE ItemId = @OldLocalizableItemId
DELETE FROM core.Changeset WHERE ItemId = @OldLocalizableItemId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Deleted ' + CAST(@RowCount as nvarchar(10)) + ' core.Changeset records'

SELECT * FROM core.ItemSetting WHERE ItemId = @OldLocalizableItemId
DELETE FROM core.ItemSetting WHERE ItemId = @OldLocalizableItemId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Deleted ' + CAST(@RowCount as nvarchar(10)) + ' core.ItemSetting records'

SELECT * FROM core.Item WHERE Id = @OldLocalizableItemId
DELETE FROM core.Item WHERE Id = @OldLocalizableItemId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Deleted ' + CAST(@RowCount as nvarchar(10)) + ' core.Item records'
END

--Delete localizable resource
IF @OldLocalizableResourceId IS NOT NULL
BEGIN

SELECT * FROM dbo.LocalizableResource WHERE Id = @OldLocalizableResourceId
DELETE FROM dbo.LocalizableResource WHERE Id = @OldLocalizableResourceId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Deleted ' + CAST(@RowCount as nvarchar(10)) + ' dbo.LocalizableResource records'
END

ROLLBACK TRAN
--COMMIT TRAN

SET TRANSACTION ISOLATION LEVEL READ COMMITTED
WHILE @@TRANCOUNT > 0 ROLLBACK
```
