If you are needing to compile sass files separately from the legacy preset. This preset is what you need. This works lovely alongside the Webpack Preset.

### Installation

To install this preset use the following command:

```
$ npm install @alkami/albus-preset-sass --save-dev
```

#### Additional Requirements

This preset has additional file requirements. Either run albus catalyst or manually create them (/spaces/SDKC/pages/303531407/Additional+Files).

- postcss.config.js
- .browserslistrc

All of these files go into the solution's root.

### Plugins

This preset only has one plugin that runs since it is so targeted in its purpose: compile-sass.

#### Compile-sass

This plugin handles executing the SCSS compilation command.

Default configuration

```
presetConfiguration: {
'sass': {
pluginConfiguration: {
'compile-sass': {
sassOptions: { // options to pass to the node-sass*
outputStyle: 'compressed'
},
destination: '.', // Where the files end up on build
files: [ // Glob of files to be minified
'<projectNamespace>/Styles/**/*.scss'
],
clean: [ // Glob of files to be cleaned
'<projectNamespace>/Styles/**/*.min.css{,.map}'
],
deploy: [ // Glob of files to be deployed
'<projectNamespace>/Styles/**/*.min.css{,.map}'
],
watch: [ // Glob of files to be watched
'<projectNamespace>/Styles/**/*.scss'
]
}
}
}
```

If you would like to see what options are supported in node sass, see this link: Node sass options (https://github.com/sass/node-sass#options)
