## Certificates

Certificates being used for Singing and Encryption differ due to their usage.

Signing certificates should be generated by Alkami as they provide the vendor with the signature of who is issuing the request and is done with a private key (pfx).

Encryption certificates are generated by the vendor and they are sent to Alkami as a public key (crt) which we use to encrypt data and can't decrypt ourselves.

Please see Installing Encryption & Signing Certificates for StandardSSO (/spaces/SDKC/pages/556889814/Installing+Encryption+Signing+Certificates+for+StandardSSO) for how to install these certificates.

## Signing and Encrypting

There are multiple combinations of signing and encrypting the assertion and/or response. Please see below on how to configure:

Services → Saml → Request → SigningParameters
Services → Saml → Request → EncryptionParameters

#### SignatureLevel
- A signed SAML Response with an unencrypted AssertionSigningParameters.SignatureLevel: Response AND don't provide EncryptionParameters
- A signed SAML Response with an encrypted AssertionSigningParameters.SignatureLevel: Response AND provide EncryptionParameters
- An unsigned SAML Response with a signed AssertionSigningParameters.SignatureLevel: Assertion AND SigningParameters.SignAssertionOnly: false
- An unsigned SAML Response with an encrypted signed AssertionSigningParameters.SignatureLevel: Assertion AND SigningParameters.SignAssertionOnly: true AND provide EncryptionParameters
- A signed SAML Response with an encrypted signed AssertionSigningParameters.SignatureLevel: Response AND SigningParameters.SignAssertionOnly: true AND provide EncryptionParameters

Methods

NOTE: When working with a certificate whose Signature algorithm is SHA256RSA you will need to configure the following:

- SigningParameters.SignatureMethod = "http://www.w3.org/2001/04/xmldsig-more#rsa-sha256"
- SigningParameters.DigestMethod = "http://www.w3.org/2001/04/xmlenc#sha256"

To check go to the details of the certificate and look for Signature Algorithm.

## Namespace Prefixes
- AssertionNamespacePrefix - Prefix to use for the assertion namespaces.
- ProtocolNamespacePrefix - Prefix to use for the protocol namespaces.
