### Welcome!

The following guide is a collection of thoughts around the best way to build a Vue widget on the Alkami platform. It is part instruction, part explanation of what goes into a Vue application and the recommended way to structure it to ensure consistency and scale-ability across our application.

NOTE: This is not an introduction to Vue itself, but a guide on how to structure a Vue application on the Alkami platform. It is recommended to familiarize yourself with Vue (https://vuejs.org/guide/introduction.html) before reviewing these documents.

Devtools

To get the best developer experience possible it is highly recommended to develop Vue applications in VSCode with the Volar (https://marketplace.visualstudio.com/items?itemName=Vue.volar) extension installed as well as the browser extension for Vue Devtools (https://devtools.vuejs.org/). Together these will vastly improve the speed at which you can develop and debug Vue applications.
