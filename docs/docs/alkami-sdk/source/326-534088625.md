Follow these steps to run the starter app.

##### Flutter

Install Flutter matching the version defined in the latest app release version (https://confluence.alkami.com/spaces/SDKC/pages/538189394/Release+Versions). Alkami engineers use Visual Studio code, so we recommend following these instructions:

https://docs.flutter.dev/install/quick (https://docs.flutter.dev/install/quick)

Recommended: Use FVM to manage flutter versions: https://fvm.app/ (https://fvm.app/)

Android Studio

Download and install the latest version of Android Studio here.

https://developer.android.com/studio/install (https://developer.android.com/studio/install)

Be sure to match the Java and Gradle versions to the latest app release version (https://confluence.alkami.com/spaces/SDKC/pages/538189394/Release+Versions). Search for gradle_version and java_version.

Xcode

Download and install the specific version of Xcode from the latest app release version (https://confluence.alkami.com/spaces/SDKC/pages/538189394/Release+Versions). Search for xcode_version.

https://xcodereleases.com/ (https://xcodereleases.com/)

##### Retrieving dependencies

To make use of dependencies required by both the starter app and Alkami Embedded, entitlement tokens need to be set on your machine as environment variables.

Entitlement tokens should be accessibly as a secret within this ticket. HNSCMFCU-404 (https://jira.alkami.com/browse/HNSCMFCU-404) - Getting issue details... STATUS

It's recommended to set entitlement tokens using the global shell profile. This can be done by editing the ~/.zshrc file to include the following:

```
export MAVEN_PROGET_ALKAMI_MOBILEPLATFORM_USER=<insert_feeds.alkamitech.com_username>
export MAVEN_PROGET_ALKAMI_MOBILEPLATFORM_PASS=<insert_feeds.alkamitech.com_password>
export COCOAPODS_CLOUDSMITH_ALKAMI_FLUTTER_PASS=<insert_alkami-flutter-entitlement-token>
export COCOAPODS_CLOUDSMITH_ALKAMI_VENDOR_PASS=<insert_alkami-vendor-entitlement-token>
```

Run the following command to set these variables.

```
exec zsh
```

To retrieve Flutter dependencies, add your 'Flutter' entitlement token to Dart storage.

```
echo '<insert COCOAPODS_CLOUDSMITH_ALKAMI_FLUTTER_PASS here>' | dart pub token add https://dart.cloudsmith.io/alkami/flutter/
```

In the base directory of your project, retrieve the Flutter dependencies.

```
flutter pub get
```

When the dependencies are successfully retrieved, they will be listed in a newly created file, pubspec.lock.

##### iOS

For iOS dependencies, navigate to the ios directory of the project and retrieve the Cocoapods dependencies.

```
pod install
```

When the Cocoapods dependencies are successfully retrieved, they will be listed in a newly created file, ios/Podfile.lock.

##### Android

Android Maven dependencies will be retrieved when building the Android app.

The Flutter app should be ready to run at this point. Understand how the app works by investigating the app contents.
