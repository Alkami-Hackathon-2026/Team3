If you are creating or updating a Widget that calls SymConnect, then there are some updates you may need to do.

You should now be using version 2.13 or later of the Alkami.MicroServices.SymConnectMultiplexer nuget packages.

However, version 2.13.0 of Alkami.MicroServices.SymConnectMultiplexer.Utilities requires that you also include

version 2.2.7 of Alkami.MicroServices.Accounts.Contracts

and version 1.14.0 of Alkami.App.Providers.Core.Common.SymConnect

There is a change to using the IsSymConnectResponseSuccess method. You can completely change your approach to making the SymConnect RepGen calls by using making full use of that is in Alkami.App.Providers.Core.Common.SymConnect, or simply stop using the IsSymConnectResponseSuccess method and rely on the StatusCode returned in the microservice response.

Example

```
// This code will not work the same way anymore

if (response.HasError || response.StatusCode != SymConnectStatusCodes.Success) ||
! Alkami.App.Providers.Core.Common.SymConnect.Utility.IsSymConnectResponseSuccess(
(Alkami.App.Multiplexer.Contracts.ServiceContracts.ICallSymConnectResponse) response, true, out string moreDetails))
{...}

// change it to just look like this
if (response.HasError || response.StatusCode != SymConnectStatusCodes.Success)
{...}

```
