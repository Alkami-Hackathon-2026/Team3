### Additional Videos

The following training videos are available for download.

| Summary | Description |
| Generic SSO Provider and Widget | (Old video, only here for legacy use in case someone has a very old solution that used the old approach to providers before Alkami Microservices were available) A common use of the SDK is to create a Widget that connects to a Provider in order to retrieve and display content. This video will demonstrate how to connect a Widget to a Provider. A GenericSSOprovider is used since that template will create a simple Provider that contains everything we need. Unless you are creating an actual core provider, or one of the other specific provider types, use the GenericSSOprovider even if you are not actually performing a Single Sign-on operation. |
| Adding Configurable Settings to a Widget | This SDK training video will show you how to add configurable settings to a Widget. The settings are stored in the core.WidgetSetting database table. |
| Convert SSO Provider To MS - Training (short version) | (only relevant if you have a very old provider that you need to convert. Probably something built before 2018) If you have an existing GenericSSO legacy provider and are new to Alkami microservices, this video will show you the basics of refactoring your legacy provider functionality to a microservice. |
| Convert SSO Provider To MS - Training (extended content) | (only relevant if you have a very old provider that you need to convert. Probably something built before 2018) A step-by-step walk through on how to refactor your legacy GenericSSO provider functionality into a microservice. |
