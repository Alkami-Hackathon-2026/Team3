The following page will explain what needs to be installed into your SDK to test the use of Standard SSO configurations.

## Setup

The following packages will need to be installed into your SDK:

```
choco install Alkami.MicroServices.StandardSSO.Service.Host
-- then set this service to run automatically if you want to

choco install Alkami.Client.Widget.StandardSso

```
