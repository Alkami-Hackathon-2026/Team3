Welcome! Use this guide set up Alkami's Local SDK environment on Apple machines running ARM64 based processors M1 and M2.

## Base Requirements

Before beginning the process, ensure you are using or have access to the following hardware, software, and network access.

### Required Hardware

The hardware for this process is a Mac computer with a M1 or M2 processor.
Note: If you have an Intel based mac, you can follow the original steps listed for Windows.

### Required Software

The software required for this procedure

- Access to ParallelsIf you are an Alkamist and don't have a license please submit an INTIT ticket. You can use mine as a template
### Required Network Access

End users must have access to Alkami's NuGet feeds.

- Alkamists must have access to packagerepo.orb.alkamitech.com.
- External FI Clients must have access to feeds.alkamitech.com. Note: A username and password will be provided during on-boarding.

## Install the System

Complete the following steps to Install Windows on Parallels.

- Open Parallels.
- Select Get Windows 11 from Microsoft and then click Continue. The Installation Assistant Opens.
- In the Installation Assistant, click Install Windows. The Windows 11 install script runs.
- Accept the license agreement when prompted.
- When Windows Install is complete click the Click to continue option.
### Install Base Required Software

Use either of the following methods to install the prerequisite software, the EZ Method (http://confluence.alkami.com#EZmethod) or the Manual Method.

#### EZ Method

- Download the following zip file : SDKPreInstall.zip
- Move the zip file to the local drive C:\.
- Right click File > Extra All... .
- Open up Powershell in Administrator mode, and navigate to location of downloaded file. Execute and let it do it's thing.
- When the script is complete, go to Installing Package Manager.
#### Manual Method

Complete the following steps to install MS SQL Server and MS SQL Sever Management Studio.

##### Install MS SQL Server
- Download the MS SQL Server install script from https://github.com/jimm98y/MSSQLEXPRESS-M1-Install .
- Unzip the install folder in Mac's download folder.
- Navigate to the Window's Download Folder.
- Copy folder to C:\ .
- Navigate to C:\MSSQLEXPRESS-M1-Install-main\src.
- Double click the install2022Developer batch file.
- When prompted for permission to run PowerShell, click Allow. The script will begin downloading the required files. When the download is complete, the install will automatically run. When the install is complete, the script will automatically install SSMS.When the SSMS installation is complete, the Manual Method is finished.Pro-Tip: If PowerShell appears to do nothing, press Enter to have it continue.
##### Install MS SQL Sever Management Studio 2022
- Go to Download Visual Studio Tools - Install Free for Windows, Mac, Linux (microsoft.com).
- Download the Community Edition, or the Professional Edition if you have a license.
- Run the installer, select the following packages to install: ASP.NET and web development and .NET desktop development.
- Click Install and wait for the installation to complete.
- Make sure to start Visual Studio and select theme before going onto next step. Note: Visual Studio must be set up to have the template installers to run properly.
- Go to https://www.7-zip.org/a/7z2300-arm64.exe and install 7zip. Note: 7zip is required to properly install some packages and un-zip some package files.

## Install The Package Manager
- Open PowerShell as Administrator.
- Run the following command to install Chocolatey. ``` # Set and environment variable to install a specific version of Chocolatey. The current version of Chocolatey, v2.0.0, is known to cause installation errors. $env:chocolateyVersion = '1.4.0' Set-ExecutionPolicy Bypass -Scope Process -Force; iex ((New-Object System.Net.WebClient).DownloadString('https://chocolatey.org/install.ps1')) ```
- Run the following command to install Nuget. ``` choco install nuget.commandline ```
- Run the following commands to Configure NuGet Feeds.For Internal Alkamists Employees: ``` nuget sources add -name "Alkami Dev" -source https://packagerepo.orb.alkamitech.com/nuget/nuget.dev nuget sources add -name "Alkami Third-Party" -source https://packagerepo.orb.alkamitech.com/nuget/ThirdParty choco source add -n=AlkamiChocoDev -s "'https://packagerepo.orb.alkamitech.com/nuget/choco.dev'" ``` For External FI Clients: ``` nuget sources add -name "Alkami Dev" -source https://feeds.alkamitech.com/nuget/nuget.dev -u <username> -p <password> nuget sources add -name "Alkami Third-Party" -source https://feeds.alkamitech.com/nuget/ThirdParty -u <username> -p <password> choco source add -n=AlkamiChocoDev -s "'https://feeds.alkamitech.com/nuget/choco.dev'" -u="'<username>'" -p="'<password>'" ```
- Run the following command to reserve ports. ``` Set-NetConnectionProfile -InterfaceAlias Ethernet -NetworkCategory "Private" netsh int ipv4 Add excludedportrange protocol=tcp startport=12345 numberofports=2 netsh int ipv4 Add excludedportrange protocol=tcp startport=50000 numberofports=30 netsh http add iplisten 0.0.0.0 netsh http add iplisten :: ```
## SDK Install
- Ensure that the following frameworks are installed:Microsoft .NET 6.0 framework is required to the navigation and its associated services.Go to https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-6.0.406-windows-x64-installer.For the 2024.3 SDK release the Microsoft .NET 8.0 framework is required.Go to https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-8.0.400-windows-x64-installer.
- Run the following command as administrator in PowerShell to install the SDK. ``` Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass -Force;Set-ExecutionPolicy Bypass -Scope Process -Force; Enable-WindowsOptionalFeature -Online -FeatureName IIS-WebServerRole choco install Alkami.PowerShell.Configuration Alkami.PowerShell.Database Alkami.PowerShell.Choco Alkami.Powershell.IIS Alkami.Powershell.SDK -y Install-SDKRelease -Latest ```
## Template & Sample Install
- Run the following command as administrator in PowerShell to install the Alkami SDK templates and samples. ``` choco install Alkami.SDK.Templates -y choco install Alkami.SDK.Samples -y winrm quickconfig ```
