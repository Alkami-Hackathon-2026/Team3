Good morning developers! The 2020.02 SDK release has been uploaded and is available for download. There were no major contract changes but as always please build and test your projects against this release and reach out if there are any issues with this upgrade.

### Upgrade to .NET Framework 4.8

You may find there are some errors in regards to projects building against some of Alkami's newer NuGet packages. Updating your projects to Framework 4.8 will make sure they are compatible with some of our new packages.

### Alkami MachineSetup - ORB - SDK 2020.2.0.9

```
choco upgrade Alkami.MachineSetup.SDK -y
```
