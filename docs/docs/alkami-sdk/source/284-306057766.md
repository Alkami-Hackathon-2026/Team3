This tutorial describes how partners can configure the static card management provider. The goal is to run card management within a developer's SDK environment.

These instructions are intended for those using a Windows machine.

#### Before you begin, you must have the following:
- A clean SDK environment
- Validated the Alkami Platform. See Alkami Platform Validation in Log Into Developer Dynamic On Your Local SDK.
- All services running. Click here to see the services...
- Download the following scripts:cardmanagement_packages.ps1StaticCardManagementProviderConfiguration.sqlCard_Mapping.sqlCardManagementV2WidgetConfiguration.sqlSample_CardJson.txtCustomControlCardManagementProviderConfiguration.sql

Make sure these tables are created as part of package installation.

If not, then use the following script to create the missing tables.

Whenever you restart your machine, run this to restart your services. This automates the process of starting the services and gets the DLLs loaded into the memory.

```
Restart-SDKServices;Ping-AlkamiWebsites
```

#### To configure card management
- To add card management to the packages, open SQL Server Management Studio.Connect to the local database.Open CardManagementV2WidgetConfiguration.sqlGo to the end of the file and uncomment COMMIT TRAN and comment ROLLBACK TRAN. ``` /* TRANSACTION: Always track and submit this file with ROLLBACK turned on*/ --ROLLBACK TRAN COMMIT TRAN ``` Execute the script. - Run Card_Mapping.sql to map the static provider features for card management.The result is as follows: Card_Mapping.sql result Expand source ``` (2 rows affected) (1 row affected) (1 row affected) (35 rows affected) Completion time: 2023-11-03T10:06:40.8496005-05:00 ```
- To give permissions for card management, use the following procedure:In Admin, go to Setup > Staff.Click Admin Roles.From General Admin, select the Manage Card Configuration and Manage Card Image checkboxes.Log out of Admin.Log into Admin.
- Move cardmanagement_packages.ps1 to your C drive.As an Admin, run the following commands in Powershell: ``` cd\ ls .\cardmanagement_packages.ps1 ``` You can ignore all warnings.This installs the following packages:Alkami.Admin.CardManagementAlkami.Apps.CardManagementV2Alkami.MicroServices.CardManagement.Service.HostAlkami.MicroServices.CardManagementProviders.Static.HostAlkami.MS.CardAccounts.Service.Host
- Go to Windows Task Manager to verify the following services are running. If not, start them.CardManagementService.HostCardManagementProviders.Static.HostCardAccounts.Service.HostsWait a minute to ensure the services are running.

- To add the cards to the static provider, from Admin, go to Settings > Integration Settings.Click Providers.From the Provider Type, select CardManagement.For Static Card Management Provider, click Edit.Go to CardsJSON and paste the text from card_json.txt.Click Save Change.
- Add the widget to the package.In the FI Admin, go to Setup > Packages.Click Edit for the package to which you want to add CardManagement.Click the Widgets tab.Go to Card ManagementV2.Toggle Card Management to on.
- Use the following script to restart the services. This might take approximately 10 minutes. ``` Restart-SDKServices;Ping-AlkamiWebsites ```
- Launch your Alkami Platform and browse to https://developer.dev.alkamitech.com/CardManagementv2.
