In order to provide the most performant experience when running Vue in the browser, the Vue devtools are only accessible when running the unminified version of the library. Since we must include the minified reference in the cshtml file for production reasons, there are two options to enable devtools during the development experience.

#### ForceUseOfProductionAssetsInDebug

In the web.config file in WebClient there is a setting called ForceUseOfProductionAssetsInDebug. Essentially what this setting does is when a script or stylesheet is referenced using the HTML helper (e.g. @Html.ScriptWithCacheExpiration), we automatically force or remove a .min extension on that asset if the other version exists on the filesystem. By changing that setting to false while developing, the unminified version of the Vue libraries will be served (as well as all other scripts in the system) and you will be able to use the devtools as expected.

#### Leveraging the autoinject templating functionality

In addition to automatically injecting the files that come out of the configured webpack entry points, the injection plugin also allows the use of a template engine (lodash templating by default) to generate markup. Before the injection actually occurs, the plugin runs the template file through templating and passes the full webpack configuration to use as a model. Let's look at an example of how we can leverage this to change the extension based on the webpack environment mode:

Index.cshtml

```
@section JavaScriptIncludeContentPlaceHolder {
<!-- Block Syntax -->
<% if (webpackConfig.mode === 'production') { %>
@Html.ScriptWithCacheExpiration("~/lib/vue/vue.runtime.min.js")
@Html.ScriptWithCacheExpiration("~/lib/vuex/vuex.min.js")
@Html.ScriptWithCacheExpiration("~/lib/vue-router/vue-router.min.js")
<% } else { %>
@Html.ScriptWithCacheExpiration("~/lib/vue/vue.runtime.js")
@Html.ScriptWithCacheExpiration("~/lib/vuex/vuex.js")
@Html.ScriptWithCacheExpiration("~/lib/vue-router/vue-router.js")
<% } %>

<!-- Single line syntax -->
@Html.ScriptWithCacheExpiration("~/lib/vue/vue.runtime<%= webpackConfig.mode === 'development' ? '' : '.min' %>.js")
}
```

By using the internal webpackConfig we can ascertain if this is production vs development and load the development vs minified version, or load the file locally vs a CDN url.
