### Description

The Notifications Microservice is responsible for rendering predefined templates and sending the rendered template to the provided email address/sms/push enabled device. There are 2 supported templating languages, Razor and XSLT.

There are 2 key actions that the notifications microservice supports, registering a template, and sending a notification using a registered template.

### Registering a Template

The RegisterTemplate method takes a collection of Template objects as input. A template is specific to a TemplateName, MediumType, LocaleId and TemplateTransformType.

For example if you are creating templates for an Account Balance alert, and you want the alert to be able to be sent for Email, SMS and Push, and in English and Spanish, and you want your template to use Razor syntax, then you would create the following templates:

| TemplateName | MediumType | LocaleId | TemplateTransformType |
| AccountBalanceAlertTemplate | Email | 1033 | Razor |
| AccountBalanceAlertTemplate | Email | 21514 | Razor |
| AccountBalanceAlertTemplate | Sms | 1033 | Razor |
| AccountBalanceAlertTemplate | Sms | 21514 | Razor |
| AccountBalanceAlertTemplate | Push | 1033 | Razor |
| AccountBalanceAlertTemplate | Push | 21514 | Razor |

#### Template Transform Types

The 2 currently supported transform types are Razor and XSLT.

Using the Razor syntax, you create your template as if you were creating a Razor view in ASP.net with a few exceptions.

- Do not specify the model at the top of your template. The model will be dynamically added by the notifications microservice. The notifications microservice does not have access to the type of your model, all the notification service receives is a JSON representation of your model that is then converted to a dynamic object. #### Global Templates

By default a template will be rendered using the global template. The global template provides a standardized header and footer for you templates to promote consistency between templates. If the global template is not appropriate for your template then it can be excluded by adding an exclude directive at the top of the template

Razor Syntax Exclude Global Template

```
@* ExcludeDefaultGlobalTemplate() *@
```

XSLT Syntax Exclude Global Template

```
<!-- <xsl:exclude-global-template /> -->
```
