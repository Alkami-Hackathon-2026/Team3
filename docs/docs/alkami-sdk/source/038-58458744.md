## .NET Framework 4.7.2 Developer Pack

The Alkami platform and microservices are now building and running in Microsoft .NET 4.7.2 and will require developers to update to the proper developer pack version. Please use the link below to update your system before installing or upgrading the Alkami SDK.

https://dotnet.microsoft.com/download/dotnet-framework/net472 (https://dotnet.microsoft.com/download/dotnet-framework/net472)

## Authorization Microservice v1.4

There are new package requirements for an IPAddress and UserAgent to generate tokens with the API. The Authorization Microservice has been installed by default as part of this SDK release, no action is needed from the developer.
