TITLE: Prevent "Are you still here" on client
PARENT: Samples and Tutorials

The following code samples illustrate how to keep the are you still here message from displaying on the client. This can be useful when the user is working inside an iFrame and the click events are not propagating to the parent widget.
Note: The setInterval is meant to be illustrative. Do not use setInterval to call the eventhandler in production. Instead use something like the IframeEventHandler to call eventHandler.

```
<script>
function eventHandler() {
window.parent.postMessage('idletimeout-reset');

}

//setInterval is only to show that the code works at preventing are you still here timeout
//do not use set interval to call the event handler in production
//Instead use something like the IframeEventHandler shown further down

setInterval(eventHandler, 30000);//should never see an are you still here message on front end
</script>

//you could post something like the below inside an IFrame to make sure user events inside the Iframe keep the are you still here message from populating.
function IframeEventHandler() {
window.parent.postMessage('idletimeout-reset');
}

['keydown', 'mousedown', 'touchstart', 'touchend'].forEach((eventName) => {
document.addEventListener(eventName, eventHandler);
}
```
