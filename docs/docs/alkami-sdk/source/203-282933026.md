#### In a Feature Request JIRA Ticket please include the following:

It has been recently brought to our attention that the description in the Feature Request template has changed. Please copy the content below the description heading and replace the description in the ticket so that it resembles the screenshot below the content. Remember to give as much information as possible, there cannot be too much information in a project proposal.

### Description: Complete all the sections associated for your project.

Project Information:

- What is the business purpose of your widget/service?New widget/service?Existing Widget/service?Which users will have access to the widget?Is this driven by a permission? If so, determine if View As User (Read Only) users should have access. linkIs this limited by account type?Is this driven by packages?Where will the widget be accessed?Screenshot(s) of Current BehaviorScreenshot(s) of Expected BehaviorWhat is the timeline you are anticipating for the launch?

Technical Information:

- What calls are being implemented?How are the calls authenticated?Is the sensitive data transferred in the body, header, URL, etc.?How is the data partitioned or validated to ensure that the correct data is transferred?Is there hashing or encryption involved, and if so what algorithms and key lengths are being used?Please provide a data flow diagram for any vendor/3rd Party integrations.

Other Information:

- Are there any certificates that are required?Any particular configurations?Please share any vendor integration details if applicable

Ensure the Feature Request ticket has the following settings:

- Label: sdk_project_proposal
- Team: SDK
- Component: SDK

Feature Request tickets do not have the Team field available on the create screen. In order to correctly create the project proposal you will need to edit the ticket after creation and set the Team field to SDK.
