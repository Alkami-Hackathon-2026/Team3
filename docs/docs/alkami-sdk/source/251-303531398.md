TITLE: Complex Interface for a Prop
PARENT: 5. Tips and Tricks

By default, Vue only supports using primitive types for prop validation. While you can create a validator on the prop manually, it's much easier to let Vue take care of that under the hood. To type a prop with a more complex interface, you can use type casting to set an Object to that new interface.

Component.vue

```
<script setup lang="ts">
// Import Interfaces
import { defineProps } from 'vue';
import { ITenant } from '../interfaces/ITenant';

// Type your props for your Component
interface Props {
tenant: ITenant;
}

// DO NOT DESTRUCTURE PROPS, they will loose their reactivity
const props = defineProps<Props>();

</script>
```
