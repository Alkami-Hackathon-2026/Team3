Please check the Midas release notes for any specific feature updates.

Remember to make sure your OS and Visual Studio are updated/patched.

```
choco upgrade Alkami.MachineSetup.SDK.Features -y;
```

After running the Feature update some of the services are set to start manually. To ensure all services automatically restart at reboot, after installing Features packaging, you will need to run the following command to update your SDK Services Startup.

```
Set-SDKServiceStartupType -ServiceName @('Alkami.MS.MessageCenterManagement.Service.Host','Alkami.Services.Subscriptions.Host','Alkami.MS.Username.Service.Host') -StartupType 'Automatic'
```

### SDK Template Update for Visual Studio 2022

If you have installed Visual Studio 2022, you will need to run the following command to update your SDK Templates.

```
choco upgrade Alkami.SDK.templates -y;
```
