This preset is utilized to copy files from one place to another. Generally this is used to copy files from node modules to their actual homes.

## Installation

To install this preset use the following command:

```
$ npm install @alkami/albus-preset-copy --save-dev
```

### Configuration

Below is a typical example on how to use the copy preset

Example Configuration

```
module.exports = {
global: {
runType: 'series'
},
tokens: {
projectNamespace: 'Alkami.Apps.Widget',
orbWidgetName: 'Widget'
},
presets: ['copy', /*other preset*/],
presetConfiguration: {
copy: {
pluginConfiguration: {
copy: {
patterns: [
{
from: '../../node_modules/jquery',
to: './lib/jquery',
clean: [
'./lib/jquery/**/*.*',
]
}
]
}
}
}
}
};
```

For an example on how to use, see a real Configuration in Orb Albus Configuration (https://bitbucket.corp.alkami.net/projects/APPDEV/repos/orb/browse/Alkami.Client/Alkami.Client.WebClient/albus.config.js?at=c64108da9382462dc4b051535a7ae27d30087a43)

Note: runType can be set to 'series' to have the presets run in order instead of parallel. In the case you want to have a copy happen before everything else, specify this global property and set the order of the presets via the presets array.
