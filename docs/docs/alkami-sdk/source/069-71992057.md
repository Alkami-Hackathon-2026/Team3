The Radium service has a new dependency on the Alkami Legacy Sync Users package and the Alkami Risk Evaluation Module had a minor version bump. A Common.SymConnect NuGet package is now available, existing providers connecting to a local Sym and not using the SymConnect Multiplexer should update to this new package.

## Alkami Legacy Sync Users

The Core Standard team has removed the SyncUserJob from the Radium solution and moved it to a new home, Alkami.Legacy.Sync.Users. This package will now be required or the Radium service will not start.

https://feeds.alkamitech.com/feeds/choco.dev/Alkami.Legacy.Sync.Users/1.0.2 (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.Legacy.Sync.Users/1.0.2)

## Alkami Risk Evaluation Module v2.3.0

This new version of the Risk Evaluation Module now depends on the Stepup Manager Microservice to help facilitate risk operations.

https://feeds.alkamitech.com/feeds/choco.dev/Alkami.MicroServices.StepUpManager.Service.Host/1.11.0 (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.MicroServices.StepUpManager.Service.Host/1.11.0)

## Alkami.App.Providers.Core.Common.SymConnect

If your componentized provider references Alkami.App.Providers.Shared.SymConnect, please update your references to the Common.SymConnect NuGet package or switch to the SymConnect Multiplexer (https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.MicroServices.SymConnectMultiplexer.Client/2.3.4).

https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.App.Providers.Core.Common.SymConnect/1.1.4 (https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.App.Providers.Core.Common.SymConnect/1.1.4)

## Alkami.Admin.API

Alkami's Admin API controllers have been removed from the Admin Web Client solution and have a new package available here. (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.Admin.API/1.0.2)
