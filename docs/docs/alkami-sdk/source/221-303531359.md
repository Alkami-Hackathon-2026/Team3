### Transpiled Only Capabilities

The following capabilities may be used only while using a transpiler such as our supported and recommended one, Typescript.

- Optional Chaining
- Null Coalescing
- Logical Assignment Operators
- async/await
- Imports
- Decorators (though discouraged as decorators as they are speced today are different from what is available and are not Stage 3)
### Unsupported Features

While we would love to encourage the use of recent ECMAScript standard additions. newer versions will have questionable support because of fundamental changes to the core implementation of the language. If you would like to use these features, utilizing a transpiler like TypeScript should enable their usage.

Avoid using these Promise static functions in browser code:

- race()
- allSettled()
- any()

The support for them differs wildly in browsers and polyfills were too large to include on every page.

Avoid Smooth Scrolling on the scroll functions (https://developer.mozilla.org/en-US/docs/Web/API/Element/scrollIntoView). These are not well supported and can cause browsers to throw.
