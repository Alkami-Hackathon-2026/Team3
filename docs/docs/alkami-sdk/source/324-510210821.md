## Overview

The purpose of this page is to assist SDK clients with the installation of the correct core packages for their stage-match scripts and establishing a connection to their test Core system. The versions listed in the installation/upgrade commands below are for example only. If you are on the latest SDK release you can omit the "--version" and version number from the command. If you are not on the latest release then you will need to determine the version installed by looking at the version.txt file in C:\Orb\WebClient and find the package that matches the Major and Minor version number (2025.3). If you are on an SDK release earlier than 2025.3 then you will need to upgrade to take advantage of these consolidated core packages.

## Step-by-step guide
### This needs to be added for every core: (failure to add this package can result in registration fields not showing for member registration)Beginning with the 2025.4 SDK release this will be included by default. You will still need to install this if you are on 2025.3 or earlier.

choco upgrade alkami.app.providers.core.service.client --version 5.5.220 -y

## Primary Core Providers
### Symitar (a.k.a Episys)
- Installation of required choco packages.choco upgrade Alkami.SDK.Core.Symitar --version 2025.3 -y
- Configuration for SymXchange is required.You will need to update the appsettings.json file located in the "C:\ProgramData\chocolatey\lib\Alkami.MicroServices.SymConnectMultiplexer.Service.Host\lib" folder. Stop the Multiplexer service in the Services panel, open the appsettings.json file and replace the PortConfiguration section with what is below. Make sure that you replace the BankIdentifier with your bank identifier. You can't find it in the AlkamiMaster database in the dbo.tenant table in your stage match tenant record. ``` "PortConfiguration": [ { "BankIdentifier": "Your Bank Identifier here", "PortValues": [0] } ] ```
- After the appsettings.json has been updated and saved you will need to restart the Alkami.Microservices.Symconnect.Multiplexer.Service.Host in the services panel.
