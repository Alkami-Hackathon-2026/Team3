Standard SSO supports defining what data will the option dropdown render for each option available for the user to select, be it accounts or cards, by leveraging using expressions.

The following section can be defined at the top level of the SSO configuration to configure the options rendered information.

SelectionConfiguration

```
{
...
"SelectionConfiguration": {
"PrimaryInfo": "REPLACE_ME",
"SecondaryInfo": "REPLACE_ME",
"TertiaryInfo": "REPLACE_ME"
},
...
}
```

The previous definition will render using the Iris Account Dropdown (https://iris.alkamitech.com/web/components/dropdown.html#code_account_dropdown) definition for primary, secondary, and tertiary information display.

In the previous example for the first option, the following can be seen as:

- PrimaryInfo: Steve's Checking Account
- SecondaryInfo: **********123
- TertiaryInfo: $1,000.00

The default values when not using a SelectionConfiguration override will be as follows:

Account's Default SelectionConfiguration

```
{
...
"SelectionConfiguration": {
"PrimaryInfo": "{{ AccountDisplayName }}",
"SecondaryInfo": "{{ MaskedAccountNumber }}",
"TertiaryInfo": ""
},
...
}
```

NOTE: Options that are not overridden will use their default values.

Card's Default SelectionConfiguration

```
{
...
"SelectionConfiguration": {
"PrimaryInfo": "{{ MaskedCardNumber }}",
"SecondaryInfo": "{{ AccountDisplayName }}"
},
...
}
```

Example of using the following Configuration can render custom values for the options as needed to be configured.

Example SelectionConfiguration

```
{
...
"SelectionConfiguration": {
"PrimaryInfo": "Account Holder: {{ AccountHolder }}",
"SecondaryInfo": "{{ AccountDisplayName }}",
"TertiaryInfo": "#{{ AccountNumber }}"
}
...
}
```
