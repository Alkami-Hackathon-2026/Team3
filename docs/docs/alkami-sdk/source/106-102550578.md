There is really no new instructions for this release. However we remind you that you should upgrade the nuget packages in your projects (especially Widgets) each time you submit a new version. However, there are a few packages that have specific version requirements and you must not upgrade to the latest versions of those specific packages. You should always check this page https://confluence.alkami.com/sdk/nuget-package-requirements-what-versions-are-current-82794502.html (https://confluence.alkami.com/sdk/nuget-package-requirements-what-versions-are-current-82794502.html) for guidance and upgrade your reference packages accordingly before you do your final build and test prior to submitting to Alkami.

Also, a reminder that the proper upgrade command for your SDK is now.

| choco upgrade alkami.machinesetup.sdk.features -y |

Refer to previous release notes for this year in if you missed that change.

It's always a good idea to take a look at https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html (https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html) before upgrading your SDK in case there are any changes to the instrucitons that you might have missed.
