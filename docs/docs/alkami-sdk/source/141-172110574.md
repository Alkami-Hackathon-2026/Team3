TITLE: Vendor - Developed Solution Release Process for SDK

The following reflects the standard processes involved when a Financial Institution (FI) or a Gold Standard Partner submits a Feature Request for a vendor solution to be developed and/or deployed.
Note: The term Vendor used here refers to both third-party vendors hired by Clients and Gold Standard Partners.

Important note: on each submission ticket, please list the client(s) that you expect to receive the code you are submitting.
