Alkami.Helpers is a collection of more advanced or unique methods and classes.

#### uniqueID()

Generates a random string to be used as an ID.

Arguments

- None

Returns

- (string): Returns a unique string from randomly generated characters.

Example

```
uniqueID() // => 'f05a556e-7e25-f958-ad98-2fc635192468'
uniqueID() // => '65784c63-ef15-9786-6e96-3858b51dc169'
uniqueID() // => '3159ccd8-03c8-e7d1-cbd8-33e8c539cab9'
uniqueID() // => '23b6bc78-aa15-5058-85e8-8c785235c738'
```

#### KEY_CODES

A constant object that has keyboard key code mappings to their name for the 'keyCode' and 'which' properties on KeyboardEvent.

NOTE: keyCode and which are deprecated in favor for key. Check out the key property (https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key) and Key Value (https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/key/Key_Values) documentation on MDN.

Available Mappings

- BACKSPACE
- COMMA
- DELETE
- DASH
- DOWN
- END
- ENTER
- ESCAPE
- HOME
- LEFT
- MINUS
- PAGE_DOWN
- PAGE_UP
- PERIOD
- RIGHT
- SPACE
- TAB
- UP

Example

```
inputElement.addEventListener('keypress', (event) => {
if (event.which === Alkami.Helpers.KEY_CODES.DELETE
|| event.which === Alkami.Helpers.KEY_CODES.BACKSPACE
|| event.which === Alkami.Helpers.KEY_CODES.PERIOD
|| event.keyCode === Alkami.Helpers.KEY_CODES.TAB
|| event.which === Alkami.Helpers.KEY_CODES.COMMA) {
return true;
}

if (event.which === Alkami.Helpers.KEY_CODES.MINUS
|| event.which === Alkami.Helpers.KEY_CODES.DASH) {
return false;
}

return false;
});
```

#### Ajax

Alkami.Helpers.ajax is a helper function to make asynchronous HTTP calls via javascript. It provides a wrapper around the fetch interface to give the developer a helping hand in what can be a low level task.

##### Ajax Options (AjaxOptions)

```
interface AjaxOptions {
url: string; // URL to send the request to
contentType?: string; // The content type to use.
// Popular ones would be:
// * application/x-www-form-urlencoded
// * multipart/form-data
// * application/json
headers?: { [key: string]: string }; // Key value pair of headers for the request
data?: string | {} | FormData | URLSearchParams; // Data to send to the server
responseType?: 'xml' | 'html' | 'json' | 'text'; // The type of data expected back from the server
method: 'GET' | 'HEAD' | 'POST' | 'PUT' | 'DELETE' | 'CONNECT' | 'OPTIONS' | 'TRACE' | 'PATCH'; // The HTTP Method to use to send the data. `GET` by default.
}
```

##### ajax(options)

Perform an asynchronous HTTP request. It returns a Promise (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_promises) wrapped Response (https://developer.mozilla.org/en-US/docs/Web/API/Response) making it perfect for the async await pattern (https://javascript.info/async-await).

Arguments

- options (AjaxOptions)

Defaults

```
const defaults = {
method: 'GET'
}
```

Based on data, you might get a default contentType if not specified.

| data | contentType |
| Object | application/json |
| FormData | multipart/form-data |
| URLSearchParams | application/x-www-form-urlencoded |

Also using the specified contentTypes, the ajax function will try to automatically serialize the data into the correct format.

for example: {a: 'a', b: 1} for a specified application/x-www-form-urlencoded will send the correct request body of a=a&b=1.

Returns

- (Promise<Response>): Returns a promise that resolves into the response. The Promise will reject if the HTTP Request fails or has a response code not in the 200s.

Example 1: Simple GET

```
async function fetchTasks() {
const response = await Alkami.Helpers.ajax({
url: '/Tasks',
responseType: 'json', //to let the endpoint know we expect json returned.
});

const data = await response.json();
// manipulate data if you need to
return data;
}
```

Example 2: Provide data for query string

```
async function fetchTask(taskId) {
const response = await Alkami.Helpers.ajax({
url: '/Tasks',
responseType: 'json',
data: {
taskId
}
});
// GET request from `/Tasks?taskId=1` if taskId was `1`

const responseData = await response.json();
// manipulate data if you need to
return responseData;
}
```

Example 3: POST data as if a form

```
async function createTask( data ) {

const response = await Alkami.Helpers.ajax({
url: '/Tasks',
method: 'POST',
contentType: 'application/x-www-form-urlencoded',
responseType: 'json',
data
});

const responseData = await response.json();
// manipulate data if you need to
return responseData;
}
```

Example 4: POST using form

```
async function postForm(formElement) {
const data = formElement.formData;

const response = await Alkami.Helpers.ajax({
url: '/Tasks',
method: 'POST',
responseType: 'json',
data
});
// will POST form with contentType of `multipart/form-data`
// great for if you have file fields

const responseData = await response.json();
// manipulate data if you need to
return responseData;
}
```

Example 5: Handling rejection

```
async function createTask( data ) {
try {
const response = await Alkami.Helpers.ajax({
url: '/Tasks',
method: 'POST',
contentType: 'application/x-www-form-urlencoded',
responseType: 'json',
data
});

const responseData = await response.json();
// manipulate data if you need to
return responseData;

} catch (error) {
if(error instanceof Response) {
const errorData = await error.json();

Alkami.FlashBanner.showError(errorData.errorMessage);
return errorData;
}

throw error;
}
}
```

Example 6: Using Promises

```
function createTask (data) {
const promise = Alkami.Helpers.ajax({
url: '/Tasks',
method: 'POST',
contentType: 'application/x-www-form-urlencoded',
responseType: 'json',
data
});

return promise
.then((response) => response.json())
.catch((error) => {
if(error instanceof Response) {
return error.json().then((errorData) => {

Alkami.FlashBanner.showError(errorData.errorMessage);
return errorData;
});
}

return Promise.reject(error);
});
}
```

#### Cache

Alkami.Helpers.createCache is a helper to create a cacheable value in session storage or memory if session storage isn't available.

##### createCache(cacheKey: string)

Creates a cache item in session storage if able, otherwise creates in in memory cache.

Arguments

- cacheKey String

Returns

- (Cache) : Returns a Cache object in which values can be stored in.

Example

```
const response = await (await fetch('/API/Globals')).text();
const cache = Alkami.Helpers.createCache('Alkami.Globals');
cache.value = response;

// Later
const globals = JSON.parse(cache.value);
```

##### Cache (Cache)

```
interface Cache {
readonly key: string; // Key the cache is stored in
value: string; // get or set value in Cache
invalidate(): void; // completely remove value from storage
}
```

#### Dialog

Alkami.Helpers.Dialog is a set of helpers to programmatically create a prompt (e.g. Yes or No dialog) to display to a user. It is incredibly flexible in what it can create and is driven by a well typed set of options.

To see what is possible with these methods, let's take a look at the options objects.

##### Dialog Options (IDialogOptions)

```
interface IDialogOptions {
id?: string; // ID attribute for the prompt
cls?: string; // Class attribute for the prompt
content: string | HTMLElement; // HTML String or Element to be injected into the prompt body element
destroyOnClose?: boolean; // Remove the prompt element from the DOM when closed
size?: string; // Size of the prompt ('small', 'medium', 'large')
title?: string; // Title of the prompt
handlers: { [key: string]: EventListener }; // Any event listeners to register to the prompt
buttons: IDialogButtonOptions[]; // Button options to be created in the prompt footer
}
```

##### Dialog Button Options (IDialogButtonOptions)

These options are used to be passed into the buttons key in the main dialog options object.

```
export interface IDialogButtonOptions {
cls?: string; // Class attribute on the button
handlerName: string; // Name of the handler to be called when the button is activated. Reference to the handlers object passed into the main options
href?: string; // Optional href to be added to a link at the bottom
id?: string; // ID for the button
tag?: string; // What tag to be used to create the element. If using href, this should be 'a'
text?: string; // Text to be displayed inside of the button
type?: string; // What type of iris-button to use ('primary' | 'secondary')
closePrompt?: boolean; // Whether or not to close the prompt when clicked
}
```

##### createDialog(options)

Creates a prompt with the given options.

Arguments

- options (IDialogOptions)

Defaults

```
const defaults = {
id: 'alkami_modal_' + modalCount,
cls: '',
content: '',
destroyOnClose: false,
size: 'large',
title: '',
handlers: {},
buttons: [],
};
```

Returns

- (Iris.PromptComponent): Returns and Iris Prompt Component so you can interact with the Iris API.

Example 1 (Simple dialog, no buttons)

```
const adBlockerDetectionDialog = Alkami.Helpers.createDialog({
id: 'ad-blocker-detection-dialog',
title: 'Ad Blocker Detected',
content: '<p>The ad blocker may cause interference when trying to complete a transaction or task. We recommend you disable ad blocker for the best experience.</p>',
size: 'large',
destroyOnClose: true
});

// Attach custom event listeners on the dialog
document.getElementById('ad-blocker-detection-dialog').addEventListener('iris.prompt.closed', event => {
localStorage.setItem('adBlockerPromptSeen', 'true');
});

// Open the dialog after it's been created
adBlockerDetectionDialog.open = true;
```

Example 2 (Custom handlers passed in for the buttons)

```
const sessionBodyMarkup = '<div><p>You have been inactive for a while. You will be logged out in <span id="session-timeout-countdown" style="font-weight:bold"></span> seconds.</p></div>';
const stillHereButtonText = "I'm still here!";
const logoutButtonText = "Logout";
const modalTitleText = 'Are you still there?';

const sessionPrompt = Alkami.Helpers.createDialog({
id: 'session-dialog',
title: modalTitleText,
content: sessionBodyMarkup,
handlers: {
'logout': function(e) {
e.target.innerHTML = 'Please wait...';
window.location.href = "/Logout";
},
'cancel': function(e) {
window.clearInterval(sessionDialogCountdown);
idleTimeout.resetTimer();
}
},
buttons: [
{
text: logoutButtonText,
type: 'secondary',
handlerName: 'logout',
closePrompt: false
},
{
text: stillHereButtonText,
handlerName: 'cancel',
closePrompt: true
}
]
});
```

#### Presets

In addition to the very flexible createDialog method, there are also two additional presets that already have options defined to create specific types of prompts.

##### createCloseDialog(content, options)

This dialog preset creates a prompt that has a single "Okay" button at the bottom. Use this preset when you are informing a user of informational content.

Arguments

- content (string)
- options (IDialogOptions)

Defaults (only sets the button options)

```
const buttons = [{
text: Alkami.Localization.SiteText['Modal.Confirm.Button.Okay'],
handlerName: 'close',
closePrompt: true,
}];
```

NOTE: If you want to take a specific action when the prompt closes, make sure to pass in a handler named close to the main options object.

Returns

- (Iris.PromptComponent): Returns and Iris Prompt Component so you can interact with the Iris API.

Example

```
const closeDialogContent = `<div>Body content for the prompt.</div>`

Alkami.Helpers.createCloseDialog(closeDialogContent, { title: 'Informational' });
```

##### createYesNoDialog(content, options)

This dialog preset creates a prompt that has two buttons ('yes' and 'no') at the bottom. Use this preset when you are looking for a user to confirm an action to be performed.

Arguments

- content (string)
- options (IDialogOptions)

Defaults (only sets the button options)

```
const buttons = [{
text: Alkami.Localization.SiteText['Modal.Confirm.Button.No'],
handlerName: 'no',
type: 'secondary',
closePrompt: true,
}, {
text: Alkami.Localization.SiteText['Modal.Confirm.Button.Yes'],
handlerName: 'yes',
closePrompt: true,
}];
```

NOTE: If you want to take a specific action when a user clicks one of the buttons, make sure to pass in a handler named yes or no to the main options object.

Returns

- (Iris.PromptComponent): Returns and Iris Prompt Component so you can interact with the Iris API.

Example

```
const yesOrNoDialogContent = `<div>Are you sure you want to logout?</div>`;

Alkami.Helpers.createYesNoDialog(yesOrNoDialogContent, { title: 'Are you sure?' });
```

##### createConfirmationDialog(content, confirmationText, options)

This dialog preset creates a prompt that has two buttons ('confirm' and 'cancel') at the bottom. Use this preset when you are looking for a user to confirm an action to be performed. You can configure the confirmation button text easily through the confirmationText property;

Arguments

- content (string)
- confirmationText (string)
- options (IDialogOptions)

Defaults (only sets the button options)

```
const buttons = [{
text: Alkami.Localization.SiteText['Modal.Confirm.Button.Cancel'],
handlerName: 'cancel',
type: 'secondary',
closePrompt: true,
}, {
text: Alkami.Localization.SiteText['Modal.Confirm.Button.Confirm'],
handlerName: 'delete',
closePrompt: true,
}];
```

NOTE: If you want to take a specific action when a user clicks one of the buttons, make sure to pass in a handler named close or delete to the main options object.

Returns

- (Iris.PromptComponent): Returns and Iris Prompt Component so you can interact with the Iris API.

Example

```
const deleteConfirmationContent = `<div>Deleting this thing is super destructive. Are you sure?</div>`;

Alkami.Helpers.createConfirmationDialog(deleteConfirmationContent, 'Delete', {
title: 'Are you sure?',
handlers: {
'confirmation': function(e) {
// do something destructive here...
},
}
});
```

#### Form

Alkami.Helpers have several helpful functions geared towards forms.

##### bindPostLink(element)

Binds a link to use the postLink function

Arguments

- element (HTMLElement)

Returns

- (void): Returns void.

Example

```
const linkElements = Array.from(document.querySelectorAll('a.post-link'));
linkElements.forEach((linkElement) => bindPostLink(linkElement));
```

##### disableSubmit(element, disabledText)

Disables the submit button element and replaces the text.

Arguments

- element (HTMLElement)
- disabledText (string)

Returns

- (void): Returns void.

Example

```
const buttonElement = document.getElementById('btn_submit');
disableSubmit(buttonElement, 'Sending Data');
```

##### enableSubmit(element)

Enables the submit button element and replaces any disabled text specified by disableSubmit with the original text of the button.

Arguments

- element (HTMLElement)

Returns

- (void): Returns void.
##### postLink(url)

Makes a POST HTTP request instead of a GET out of a url. Useful when linking with sensitive data or building disposable forms.

Arguments

- url (string or URL)

Returns

- (void): Returns void.

Example

```
postLink('/AccountV2/Transactions?accountId=123&startDate=2018-01-01&endDate=2018-12-01');
```
