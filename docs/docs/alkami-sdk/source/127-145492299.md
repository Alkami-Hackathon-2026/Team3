### Slide Deck (as PDF)

Something important that was not covered in the webinar is that when the new login workflow is enabled, the old challenge questions will not be used for authentication. The Bank Setting DisableSecurityQuestions is not used, unless you stop the authentication workflow service and revert to the legacy login process and then that Bank Setting is honored.
