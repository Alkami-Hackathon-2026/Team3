If you already have an existing project and want to convert it to Albus, make sure to complete everything on this page before following the Getting Started (/spaces/SDKC/pages/303531406/Getting+Started) guide.

#### Clear out dependencies from package.json file

The first step is to clear out all dependencies from the package.json file at the root of your solution. These will be listed in either the dependencies or devDependencies key in that file. Delete every dependency in those keys except any that begin with @types since those will still be needed to properly add TypeScript support to your project. Afterwards, your package.json file will look something like this:

Cleansed package.json

```
{
...
dependencies: {},
devDependencies: {
@types/knockout: 3.4.1
},
...
}
```

#### Delete legacy files

After setting up the package.json file, we need to clear out files from the legacy implementation. Go ahead and delete these files / folders (if they exist) from the solution directory:

- gulpfile.js
- package-lock.json
- node_modules/
- prebuild.ps1

#### Add necessary @types packages (optional)

If your solution directory contains a folder named typings then you will also need to install some additional packages to add TypeScript support to all of your files. For every file inside that folder, we need to add the corresponding npm package and finally delete that folder entirely. As an example, for a folder structure like this:

Typings Folder Listing

```
├── typings # Folder that contains all of the definition files for third party libraries
├── jquery
│ └── index.d.ts # TypeScript definition file
└── knockout
└── index.d.ts # TypeScript definition file
```

We need to install the jQuery and knockout TypeScript definition files. To do this, run these commands at the root of your directory:

TypeScript Definition Install

```
$ npm install @types/jquery --save-dev
$ npm install @types/knockout --save-dev
```

This will add the definition files to your project and will automatically load them when your project compiles. You can now delete the typings folder from your repository. If you would like to see what definition files are available, you can search available packages at the official TypeScript typings search (https://microsoft.github.io/TypeSearch/).

#### Continue with the installation

Now that we have cleared out the legacy implementations, you can continue with the installation instructions beginning with "Install Albus" on the Getting Started (/spaces/SDKC/pages/303531406/Getting+Started) page.
