This will be the guide to follow for submitting code projects through our One-Click Submission process.

For all FI named projects (Bellco, SECU and FourLeaf) the standard One-Click Submission process will be used.

https://confluence.alkami.com/sdk/one-click-submission-538188377.html (https://confluence.alkami.com/sdk/one-click-submission-538188377.html)

For the OTS named common projects there is some work to be done prior to submission. Obviously the project will need to be built and tested locally but prior to submission the AlkamiManifest.xml files in the nupkg (root and the src folder) will need to be updated with the BankIdentifier of the first FI using 7Zip.

```
<bankIdentifiers>
<bankIdentifier name="Training">639264ff-5ce5-4a9b-b194-682cb1be16a1</bankIdentifier>
</bankIdentifiers>
```

Once the manifest has been saved close the editor and make sure that you update it in the archive.

The package can now be submitted through the One-Click Submission process for this FI.

The process will need to be repeated for the other FIs. Following this pattern adds a little more front end work but will ensure that all packages are added to the package groups for consistent deployments that will persist over any lane shift or pod move.
