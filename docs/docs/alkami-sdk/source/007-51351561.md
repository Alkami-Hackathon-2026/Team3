Alkami uses Inedo's ProGet Server (https://inedo.com/proget) to host our software packages for internal development and external SDK development.

As an SDK developer, you will be pulling NuGet (https://www.nuget.org)packages from Alkami's public feed and pushing Chocolatey (https://www.chocolatey.org)packages to your private Alkami feed.

### Accessing your feed

Your feeds have been configured by the Alkami SDK team for your use and are availble at https://feeds.alkamitech.com (https://feeds.alkamitech.com).

Please reach out to the sdksupport@alkamitech.com (mailto:sdksupport@alkamitech.com) channel for information regarding this onboarding task.

### Adding your package

SDK developers are only able to add/publish packages to their assigned dev feed and have read only rights to all other feeds. In this example my developer has access to their FI specific feeds, fi1.choco.dev, fi1.choco.stage, fi1.choco.prod as well as package feeds provided by Alkami.

- Click on your Chocolatey dev feed, in this case it will be fi1.choco.dev

- To the top right of the page is an Add Package button that you'll need to click
- A dialog will ask how you'd like to upload, almost all cases will be Upload From Disk

- Select the package from a folder on your computer and click the Upload button on the previous prompt

- You should then be able to view and download this package from your private dev feed

- In addition to information and instructions on how to install, the main URL for the package's page will be used to submit this project to Alkami.
