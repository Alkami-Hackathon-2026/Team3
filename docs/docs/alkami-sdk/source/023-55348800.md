64Bit Microservices

All microservices must now run in 64Bit configurations for debug and release assemblies. The “Service.Host.csproj” file will need to be updated to set a new property named “Prefer32Bit” to false in the release and debug property groups.

Icon References

Please take time to review the new icon reference guide provided with the 2018.01 SDK release as many of the images have have been updated.

New column in "core.Item" table

This release introduces a breaking change to the SQL scripts used to insert records into the DeveloperDynamic.core.Item table. Alkami has added a new column called “LastUpdate” which required SDK SQL scripts to be altered.

Any scripts should be modified as follows and re-tested in the latest SDK version:

Variable Declaration

```
-- This is the old code that needs to be changed
DECLARE @itemSettingOutput TABLE (Action NVARCHAR(max),NewItemSettingId BIGINT,NewItemId NVARCHAR(max),NewName NVARCHAR(max),NewValue NVARCHAR(MAX),NewCreatedUtc DATETIME,NewVersion NVARCHAR(max),OldItemSettingId BIGINT ,OldItemId NVARCHAR(max) ,OldName NVARCHAR(max) ,OldValue NVARCHAR(MAX) ,OldCreatedUtc DATETIME ,OldVersion NVARCHAR(max))

-- It should be replaced with this
DECLARE @itemSettingOutput TABLE(Action NVARCHAR(max), NewItemSettingId BIGINT, NewItemId NVARCHAR(max), NewName NVARCHAR(max), NewValue NVARCHAR(MAX), NewCreatedUtc DATETIME, NewVersion NVARCHAR(max), NewLastUpdate DateTime, OldItemSettingId BIGINT, OldItemId NVARCHAR(max), OldName NVARCHAR(max), OldValue NVARCHAR(MAX), OldCreatedUtc DATETIME, OldVersion NVARCHAR(max), OldLastUpdate DateTime)
```

Merge Statement

```
-- This is the old code that needs to be changed
MERGE core.ItemSetting as target
using (Select ItemID, Name, Value, GETUTCDATE(), '2.0.0.0'
from @itemSettings) as source (ItemID, Name, Value, CreatedUTC, Version)
on (target.ItemID = source.ItemID and target.Name = source.Name)
When MATCHED and (target.Value <> source.Value) then
Update Set target.Value = source.Value, target.CreatedUTC = source.CreatedUTC, target.Version = PARSENAME(target.Version,4) + '.' + PARSENAME(target.Version,3) + '.' + CONVERT(NVARCHAR, CAST(PARSENAME(target.Version,2) AS INT) + 1) + '.' + PARSENAME(target.Version,1)
When Not Matched Then
INSERT VALUES (source.ItemID, source.Name, source.Value, source.CreatedUTC, source.Version)
Output CONCAT($ACTION, ' ItemSetting'), inserted.*, deleted.* INTO @ItemSettingOutput;

-- It should be replaced with this
MERGE core.ItemSetting as target
using (Select ItemID, Name, Value, GETUTCDATE(), '2.0.0.0'
from @itemSettings) as source (ItemID, Name, Value, CreatedUTC, Version)
on (target.ItemID = source.ItemID and target.Name = source.Name)
When MATCHED and (target.Value <> source.Value) then
Update Set target.Value = source.Value, target.CreatedUTC = source.CreatedUTC, target.Version = PARSENAME(target.Version,4) + '.' + PARSENAME(target.Version,3) + '.' + CONVERT(NVARCHAR, CAST(PARSENAME(target.Version,2) AS INT) + 1) + '.' + PARSENAME(target.Version,1)
When Not Matched Then
INSERT (ItemID, Name, Value, CreatedUTC, Version) VALUES (source.ItemID, source.Name, source.Value, source.CreatedUTC, source.Version)
Output CONCAT($ACTION, ' ItemSetting'), inserted.*, deleted.* INTO @ItemSettingOutput;
```

“More” link has been removed

This is a non-breaking change that was implemented at the behest of many product owners. Previously, a “More” link was available for each widget under the “Widget Options” page. This link would display a WidgetSummary containing a short description of what the widget does. This link has been removed as of 2018.01.

There is no immediate change required, but all widgets should eventually deprecate the use of the WidgetSummary. There is no deadline for removal, please do so at your own convenience.
