The purpose of this document is to illustrate a way that the developer can inject an updated JSON object in place of the stored configuration that is retuned. This will allow the developer to add widgets that might not be configured in Nav Builder so that they will be able to access them inside of the native mobile apps. Specifically this is for use in the Flutter version apps but might work in the older apps as well but those apps have not been tested.

This document assumes that the developer has already installed and configured Charles Proxy for testing of the mobile apps. If that is not the case please follow this documentation linked below and finalize that setup before proceeding.

Charles Proxy for Mobile Devices (/pages/viewpage.action?pageId=135988994)

#### Setting up the Intercept and Injection
- In the Flutter application, enable Charles proxy through the Developer Tools Debug menu and set your IP address. In order to get to the "Developer Tools" options you will need to tap 5 times in the white space above the environment select and it will display at the bottom of the screen. Click on Developer Tools and select the "Debugging" tab.y
- Make sure that Charles Proxy is running and capturing traffic.
- Login to your mobile app
- Go to Charles Proxy and switch to the Sequence tab. You will need to find the "navigations" entry illustrated in the image below. This is where you will get the current navigation configuration that can be altered to add new widget entries.
- Copy the response in the bottom box from the JSON Text tab. You can now edit the JSON to add widgets to be able to navigate to in the mobile app. Sample JSON Expand source ``` { "identifier": "e5b71097-e812-46b6-919c-d9c774afd6c7", "sections": [{ "displayName": "Tools", "description": null, "icon": "settings", "sectionItems": [{ "displayName": "Message Center", "widgetName": "MessageCenter", "url": "/Mobile/MessageCenter", "useNative": false }, { "displayName": "NotificationSettings", "widgetName": "NotificationSettings", "url": "/Mobile/NotificationSettings", "useNative": false }, { "displayName": "Settings", "widgetName": "Settings", "url": "/Mobile/Settings", "useNative": false } ] } ], "staticItems": [{ "displayName": "Alerts", "icon": "notifications", "widgetName": "NotificationSettings", "url": "/Mobile/NotificationSettings", "useNative": false } ], "utilityItems": [{ "displayName": "Settings", "icon": "settings", "widgetName": "Settings", "url": "/Mobile/Settings", "useNative": false }, { "displayName": "Contact", "icon": "phone", "widgetName": null, "url": "/Mobile/Contact", "useNative": false }, { "displayName": "Support", "icon": "support", "widgetName": null, "url": "/Mobile/Support", "useNative": false }, { "displayName": "Log Out", "icon": "logout", "widgetName": null, "url": "/Mobile/Logout", "useNative": false } ] } ``` Edited JSON with the MyMoney widget added. Expand source ``` { "identifier": "e5b71097-e812-46b6-919c-d9c774afd6c7", "sections": [{ "displayName": "Tools", "description": null, "icon": "settings", "sectionItems": [{ "displayName": "Message Center", "widgetName": "MessageCenter", "url": "/Mobile/MessageCenter", "useNative": false }, { "displayName": "NotificationSettings", "widgetName": "NotificationSettings", "url": "/Mobile/NotificationSettings", "useNative": false }, { "displayName": "Settings", "widgetName": "Settings", "url": "/Mobile/Settings", "useNative": false }, { "displayName": "MyMoney", "widgetName": "MyMoney", "url": "/Mobile/USBFIMyMoney", "useNative": false } ] } ], "staticItems": [{ "displayName": "Alerts", "icon": "notifications", "widgetName": "NotificationSettings", "url": "/Mobile/NotificationSettings", "useNative": false } ], "utilityItems": [{ "displayName": "Settings", "icon": "settings", "widgetName": "Settings", "url": "/Mobile/Settings", "useNative": false }, { "displayName": "Contact", "icon": "phone", "widgetName": null, "url": "/Mobile/Contact", "useNative": false }, { "displayName": "Support", "icon": "support", "widgetName": null, "url": "/Mobile/Support", "useNative": false }, { "displayName": "Log Out", "icon": "logout", "widgetName": null, "url": "/Mobile/Logout", "useNative": false } ] } ``` Remember that any widget you add to the navigation will need to be installed in the environment you are testing in or you will receive a 404 error when attempting to navigate to it.
- Save the edited JSON file to a local drive so that it can be injected through Charles Proxy. Make sure that you name it with a ".json" extension.
- In order to inject the new JSON into the call stack go back to Charles Proxy and right-click on the "navigations" call where you copied the JSON and in the context menu select "Map Local...".
- This will bring up the map editor. You will need to remove everything from the Path (green box) except "/navigations/" and add an asterisk as shown in the image below. You will also need to choose the file you saved with the updated JSON configuration in the "Map To" section (blue box).
- Once all of this is in place you will need to close the app, reopen the app and login. You should now be presented with the updated navigation from your configuration. In the image below you can see the addition of "MyMoney" on the right as opposed to the original navigation on the left.

#### Reverting the changes
- When you want to go back to the original navigation and not use the local altered version you will need to open Charles Proxy and select Tools => Map Local...
- Uncheck "Enable Map Local" and this will stop the injection of the altered local JSON file. You can also just uncheck that specific local map in case there are other local maps that you need to stay active.
