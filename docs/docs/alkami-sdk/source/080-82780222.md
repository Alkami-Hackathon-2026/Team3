### Knockout.js Upgrade Details

The 2020.01 upgrade relieves a known XSS vulnerability. When using a template binding, the previous version of knockout would fall through silently when a name was not passed; v3.5.0 will assert and discontinue processing the knockout templates. Even though this was a minor release update, it is prudent to do a quick smoke test of any knockout based widgets.

To mitigate, please make sure all template bindings are pointing to an existing template and that each view have a default "loading" template available when transitioning between view states. For more information on proper template use, see the official Knockout.js Template Binding guide. (https://knockoutjs.com/documentation/template-binding.html)
