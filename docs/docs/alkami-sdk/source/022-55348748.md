### Maintenance Branches

Moving forward maintenance branches for ORB will no longer be created and we will no longer be offering maintenance SDK releases. 2019.01.0.709 and 2019.01.1.875 (Maintenance) (https://extranet.alkamitech.com/pages/viewpage.action?pageId=55348895) will be the last maintenance branch cut for the SDK. As more items are componetized, there are fewer changes in ORB and the main release branch will be sufficient moving forward, beginning with 2019.02 (2019.02 Preview (https://extranet.alkamitech.com/display/SDKC/2019.02+Preview)).
