## Overview

This page documents what requirements are needed and capabilities are available to integrate a Standard SSO implemented SSO widget with the Card Management widget.

### Card Management Overview

Card Management supports two distinct methods to return card information:

#### GetCards

Original method to retrieve card information, this is used by Card Management Widget. This method will retrieve the cards and aggregate the information from all the configured providers.

- Cards are stored in the database
- CardIdentifier populated
#### GetCardNumbers

Secondary method which will only call the providers that supports the card attribute CardNumbers. This method will not do any aggregation logic by calling secondary providers.

- Cards are not stored in the database
- CardIdentifier is not populated
#### SymConnect Provider

Currently only the SymConnect provider will populate cards with AccountIdentifier properly mapping cards to accounts.

##### Card Filtering

The provider perform filtering depending on the presence of account identifiers in the filter request.

If AccountIdentifiers has values it will return only the cards that belong to the accounts, f not it will utilize the SUPPORTEDCARDTYPES.

#### Additional Details

##### Which CardSource should I use?

When the requirement is to utilize the Card Management Widget to then navigate to the SSO through Standard SSO, use GetCards as the CardSource because it is the same source the widget utilizes.

When the FI is not using the Card Management Widget or the SSO is not supported through the Card Management Widget, use GetCardNumbers as the CardSource because it will retrieve the cards independent of the Widget configuration and dependencies.

FilterOnAccounts: Currently GetCards does not support filtering on accounts and the value for this setting should be set to false when using GetCards. When set to false the Card Management Provider SymConnect MS will fall back to use the SUPPORTEDCARDTYPES item setting to filter cards.

##### Which CardDesignator should I use?

CardIdentifier is not available when using GetCardNumbers CardSource.

ExternalReference is only available for the SymConnect Card Management Provider.

##### Repgen Management

Note: If your FI has a custom RepGen for these, then you will need to talk to Product as there will be dev changes needed if the custom RepGen is not up to date. A development ticket will need to be created for Carbon to update the custom RepGen.
