### Configuration Tool

The Configuration tool (https://packagerepo.orb.alkamitech.com/feeds/choco.dev/Alkami.Microservices.StandardSSO.ConfigTool/) is a very instrumental tool that helps with the creation, validation, and testing of the Standard SSO's configuration. The tool has the following features:

- Supports generation of configuration through a visual designer.
- Validate configuration (using the Standard SSO's Engine).
- Evaluate configuration (using real or mocked responses).
- Provides several example configurations to help explore the Standard SSO's feature set.
- Allows for exporting the resulting request as a cURL request (which subsequently can be imported into Postman).If the result's URI is relative it will use the Request's RelativeUriHost from the Input Data tab as the host to build an absolute URI.

NOTE: It is highly recommended to check the syntax of the configuration with the StandardSSO Configuration Tool.

### How to install

Using the command line on your application server, execute the following command to install the Alkami.Microservices.StandardSSO.ConfigTool for the first time, or after removal.

```
choco install Alkami.Microservices.StandardSSO.ConfigTool -y
```

To upgrade the microservice if it is already installed use this command instead.

```
choco upgrade Alkami.Microservices.StandardSSO.ConfigTool -y
```

To specify a specific version include the the following for both install and upgrade: --version {versionNumber}.

### How to test
- Open the Configuration tool. You can open any sample request file as needed.

2. Open the sample JSON file under the Raw JSON tab.

3. Add your Raw JSON config and click Validate. It will show Success upon validation.

4. Evaluate the configuration by adding your values under Input Data.

5. Click Execute to execute your config. This will create the SSO Url. You can either copy the Url and paste directly in browser or copy the response by clicking Copy to Clipboard and test it using postman.
