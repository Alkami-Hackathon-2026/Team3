## ITransfersCoreProxyServiceContract

The Transfers Core Proxy service provides a way to execute the transfers core provider methods.

ITransfersCoreProxyServiceContract

```
/// <summary>
/// Transfers Core Proxy service provides a way to execute the transfers core provider methods
/// </summary>
[ServiceContract]
[RequiresPermissions]
public interface ITransfersCoreProxyServiceContract
{
/// <summary>
/// Add a transfer from an account to another account
/// </summary>
[OperationContract]
Task<AddTransferResponse> AddTransferAsync(AddTransferRequest request);

/// <summary>
/// Add a transfer credit to an account
/// </summary>
[OperationContract]
Task<AddTransferCreditResponse> AddTransferCreditAsync(AddTransferCreditRequest request);

/// <summary>
/// Add a transfer debit to an account
/// </summary>
/// <param name="request"></param>
/// <returns></returns>
[OperationContract]
Task<AddTransferDebitResponse> AddTransferDebitAsync(AddTransferDebitRequest request);
}
```

TransferAccount

```
/// <summary>
/// Transfer account information
/// </summary>
[DataContract(IsReference = true)]
public class TransferAccount
{
/// <summary>
/// Identifier of account
/// </summary>
/// <remarks>
/// In the cases of a <see cref="TransferType.CryptoCredit"/> this is not a required value for the source account and will be ignored.

/// </remarks>
[DataMember]
public Guid? AccountIdentifier { get; set; }

/// <summary>
/// Transaction code to be used for this account.
/// </summary>
/// <remarks>
/// </remarks>
[DataMember]
public string TransactionCode { get; set; }

/// <summary>
/// Account number
/// </summary>
/// <remarks>
/// This is not a required value except in the cases of a <see cref="TransferType.CryptoCredit"/> or <see cref="TransferType.CryptoDebit"/>
/// In the case of a <see cref="TransferType.CryptoCredit"/> this number must be populated on the source account with the number of the external crypto currency account
/// In the case of a <see cref="TransferType.CryptoDebit"/> this number must be populated on the destination account with the number of the external crypto currency account
/// </remarks>
[DataMember]
public string AccountNumber { get; set; }
}

#### Response
BaseTransferResponse

```
[DataContract(IsReference = true)]
[KnownType(typeof(TransferResponse))]
[KnownType(typeof(TransferCreditResponse))]
[KnownType(typeof(TransferDebitResponse))]
public abstract class BaseTransferResponse
{
/// <summary>
/// Unique identifier for transfer request this response is for.
/// </summary>
/// <remarks>
/// Used to correlate request to response when executing multiple requests
/// </remarks>
[DataMember]
public Guid RequestIdentifier { get; set; }

/// <summary>
/// Whether the transfer was successful
/// </summary>
[DataMember]
public bool IsSuccessful { get; set; }

/// <summary>
/// Key used to uniquely identify transfer on the core
/// </summary>
[DataMember]
public string TransferKey { get; set; }

/// <summary>
/// Whether the core was in night mode when executing transfer
/// </summary>
/// <remarks>
/// If the transfer was successful and the core was in night mode it just means that the transfer won't post immediately
/// </remarks>
[DataMember]
public bool IsInNightMode { get; set; }

/// <summary>
/// Core message
/// </summary>
/// <remarks>
/// This is the message returned from the core provider. It is often technical and not user friendly
/// </remarks>
[DataMember]
public string CoreMessage { get; set; }

/// <summary>
/// Transfer errors if the transfer was not successful
/// </summary>
[DataMember]
public List<TransferError> TransferErrors { get; set; }

/// <summary>
/// Whether the result contains an error
/// </summary>
[DataMember]
public bool HasError { get; set; }
}

### AddTransferCreditAsync

Add a transfer credit to an account. This is a one-sided transfer that typically pulls from a GL Account. GL can be passed in through the GLAccountNumber property. If set, it will be used, however, if left null, the service will determine GL based on Transfer Type and use the configured values.

| Transfer Type | GL Account Used |
| ACHCredit | ACHGLAccountNumber |
| CryptoCredit | CryptoGLAccountNumber |

Example usages are Crypto Credit (Selling Crypto ) and ACH Credit (Incoming ACH)

### AddTransferDebitAsync

Add a transfer debit to an account. This is a one-sided transfer that typically sends to a GL Account. GL can be passed in through GLAccountNumber property. If set. it will be used, however, if left null, the service will determine GL based on Transfer Type and use the configured values.

| Transfer Type | GL Account Used |
| ACHDebit | ACHGLAccountNumber |
| CryptoDebit | CryptoGLAccountNumber |

Example usage is Crypto Debit (Buying Crypto) and ACH Debit (Outgoing ACH) .
