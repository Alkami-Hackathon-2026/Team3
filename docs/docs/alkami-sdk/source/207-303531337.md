Alkami.Dom is a collection of various DOM based helper methods (hiding and showing elements, emitting brower events, etc.). If a method directly acts on an element, it's probably here.

#### ancestors(element, [query])

Retrieves a list of all the ancestor elements of the element provided and then can optionally filter on a querySelector. If you only need one ancestor element, you might look into element.closest (https://developer.mozilla.org/en-US/docs/Web/API/Element/closest)

Arguments

- element (HTMLElement)
- [query] (string)

Returns

- (HTMLElement[]): Returns an array of elements that are ancestors of element.

Example

```
const element = document.getElementById('#widget_sidebar');
const ancestorDivs = Alkami.Dom.ancestors(element, 'div');

// let's put a class on all parent divs to give them a hook
// on styling for the sidebar.
ancestorDivs.forEach((div) => {
div.classList.addClass('has-sidebar');
});
```

#### dispatchEvent(target, eventName, [detail = {}], [bubbles = true], [cancelable = true])

A wrapper function around emitting browser events. This method uses the custom event (https://developer.mozilla.org/en-US/docs/Web/API/CustomEvent/CustomEvent) object type.

Arguments

- target (EventTarget)
- eventName (string)
- [detail = {}] (object)
- [bubbles = true] (boolean)
- [cancelable = true] (boolean)

Returns

- (void): Returns void.

Example

```
Alkami.Dom.onDocumentReady(() => {
widgetNav.GetWidgetNav().then((list) => {
emitLoadedEvents('widgetNavLoaded');
});
});
```

#### fadeIn(element, [duration=400], finishFunction?)

Fades an element in over a specified amount of time using the opacity CSS property.

Arguments

- element (HTMLElement)
- [duration=400] (number)
- finishFunction? (function)

Returns

- (void): Returns void.

Example

```
const elementToFade = document.getElementById('fade_element');

Alkami.Dom.fadeIn(elementToFade, 200, () => {
elementToFade.setAttribute('aria-expanded', 'true');
});
```

#### fadeOut(element, [duration=400], finishFunction?)

Fades an element out over a specified amount of time using the opacity CSS property.

Arguments

- element (HTMLElement)
- [duration=400] (number)
- finishFunction? (function)

Returns

- (void): Returns void.

Example

```
const elementToFade = document.getElementById('fade_element');

Alkami.Dom.fadeOut(elementToFade, 200, () => {
elementToFade.setAttribute('aria-expanded', 'false');
});
```

#### fadeToggle(element, [duration=400], finishFunction?)

Fades an element in / out over a specified amount of time using the opacity CSS property.

Arguments

- element (HTMLElement)
- [duration=400] (number)
- finishFunction? (function)

Returns

- (void): Returns void.

Example

```
const elementToFade = document.getElementById('fade_element');

Alkami.Dom.fadeToggle(elementToFade, 200, () => {
const isFaded = elementToFade.getAttribute('aria-expanded');

elementToFade.setAttribute('aria-expanded', isFaded ? 'true' : 'false');
});
```

#### isVisible(element)

A simple method to inspect the DOM and find out if the element in question is currently visible on the page or not.

Arguments

- element (HTMLElement)

Returns

- (boolean | null): Returns boolean if element is visible.

Example

```
const element = document.getElementById('profile_nav');

if (Alkami.Dom.isVisible(element)) {
element.classList.remove('active');
}
```

#### onDocumentReady(callbackFunction)

A handler function that waits for the document to enter a ready state before executing the callback function.

NOTE: This is identical to the jQuery document ready (https://learn.jquery.com/using-jquery-core/document-ready/) method.

Arguments

- callbackFunction (function)

Returns

- (void): Returns void.

Example

```
Alkami.Dom.onDocumentReady(() => {
// Waits for the document to enter a 'ready' state before executing callback.
const promoContainerElement = document.getElementById('promo');

Alkami.Dom.hideElement(promoContainerElement);
});
```

#### parseHTML(htmlString)

Takes a string of HTML markup and creates the elements that can then be injected into the DOM.

NOTE: There can only be one root node (e.g. everything must be nested under one element).

Arguments

- htmlString (string)

Returns

- (HTMLElement): Returns programatically created element with string set as the markup.

Example

```
const promptHtmlString = `<div class="iris-prompt" aria-hidden="true" data-size="small">
<section class="iris-prompt__content">
<header class="iris-prompt__header">
<h2 class="iris-prompt__title">Prompt title</h2>
</header>
<div class="iris-prompt__body"></div>
</section>
</div>`;

const promptElement = Alkami.Dom.parseHTML(promptHtmlString);
document.body.appendChild(promptElement);
```

#### passiveEventListener(query, listenerFn)

Creates an event listener that will fire if the target element matches the element. Very similar to jQuery's selector based on (https://api.jquery.com/on/#on-events-selector-data-handler) function.

You can use this event listener in cases you want to lazily handle attaching an event listener to elements not available in the DOM yet.

Arguments

- query (string)
- listenerFn ( (event, passiveTarget): void )

Returns

- (EventListener): Returns a function to pass to addEventListener and removeEventListener

Example

```
const listener = function(event, target) {
if (!target.href) { return; }

event.preventDefault();
Alkami.Helpers.postLink(target.href);
};
const postLinkListener = Alkami.Dom.passiveEventListener('a.post-link', listener);
document.addEventListener('click', postLinkListener);
```

Note: to get the passiveTarget you will want to either use the this context or add a second parameter to your listener

#### removeChildNodes(parentElement)

Iterates through each of the childNodes of the element and removes them from the DOM. Useful for clearing out content before injecting elements into an element.

Arguments

- parentElement (HTMLElement)

Returns

- (void): Returns void.

Example

```
const elementToClearOut = document.getElementById('parent_element');

Alkami.Dom.removeChildNodes(elementToClearOut);
```

#### sanitizeHTML(html)

Removes potentially harmful HTML from the string.

Arguments

- html (string)

Returns

- (string): returns the sanitized HTML value.

Example

```
const html = '<a href="javascript:console.log(document.domain)">Click me</a>';

const result = Alkami.Dom.sanitizeHTML(html);
// <a>Click me</a>
```

#### sanitizeHTMLRecursively(object)

Returns a copy of an object with any potentially harmful HTML from any property or array element inside the object removed.

Arguments

- object (Object)

Returns

- (string): returns the sanitized object.

Example

```
const objWithHtml = {
html: '<a href="javascript:console.log(document.domain)">Click me</a>',
id: 1
};

const result = Alkami.Dom.sanitizeHTML(objWithHtml);
// {
// html: '<a>Click me</a>',
// id: 1
// }
```

#### slideDown(element, [duration=400], finishFunction?)

Reveals a hidden element by increasing its height over a specified amount of time.

Arguments

- element (HTMLElement)
- [duration=400] (number)
- finishFunction? (function)

Returns

- (void): Returns void.

Example

```
const elementToSlide = document.getElementById('slide_element');

Alkami.Dom.slideDown(elementToSlide, 200, () => {

});
```

#### slideToggle(element, [duration=400], finishFunction?)

Hides or reveals an element by changing it's height over a specified amount of time.

Arguments

- element (HTMLElement)
- [duration=400] (number)
- finishFunction? (function)

Returns

- (void): Returns void.

Example

```
const elementToSlide = document.getElementById('slide_element');

Alkami.Dom.slideToggle(elementToSlide, 200, () => {
const isHidden = elementToSlide.getAttribute('aria-expanded');

elementToSlide.setAttribute('aria-expanded', isHidden ? 'true' : 'false');
});
```
