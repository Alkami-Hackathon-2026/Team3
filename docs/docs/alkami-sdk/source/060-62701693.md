The samples and tutorial source code are available in the Alkami SDK Samples package. These samples will require the developer to have access to the NuGet package feeds and a licensed version of 2022.

## Installation

```
choco install Alkami.SDK.Samples --source https://feeds.alkamitech.com/nuget/choco.dev/
```

## Example Source Code

The samples include source code for our Alkami.Client solution; dig in for our patterns and practices when writing widgets.

## The "My Money" Feature

This feature is a set of growing components that demonstrate how to use the SDK to create a rich feature stack of Alkami's basic building blocks: a client widget, an admin widget, and a provider service. The "My First..." series will guide developers through creation, implementation and deployment of the widgets and the service. The "My Money" tutorials will be updated regularly as we rework many of the older samples into the new feature components with updated patterns and practices.

The MyMoney sample describes several functionalities available to SDK developers including:

- Connecting to Alkami microservices
- Using the Alkami GenericProxy service
- Using Vue and Iris components in mobile for a simple overview

## Widgets

Path: C:\AlkamiSDK\Samples\Widgets

Each of the sample widgets are name spaced as "Sample.Client.Widget.[Name]" and will deploy to the C:\Orb\WebClient\Areas directory as "Sample[Name]". The widgets are ready to go out of the box, build each project to deploy the content and libraries to the ORB folder.

Be sure to run the .sql script!
