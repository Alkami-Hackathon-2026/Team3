## Overview

The purpose of this document is to outline the process of deploying Standard SSO. NOTE: TI and Support usually manage Standard SSO deployments.

## Team Release Page

There is a new Team Release Page that is separate from the standard pages created for each major release. This is because these components are independent of any major release package and do not have to follow the standard release cycle. The new page can be found here: SSO Framework Serverless Environment (/pages/viewpage.action?pageId=95012802)

One other difference between this Team Release page and previous ones is that there is a column for "Staging Approvals". Since there is only one Proget feed and there is no promotion process to go from a QA feed to a Staging feed, this column will be used to control when a Staging deployment is done.

## Configuring an Environment for Standard SSO

To configure Standard SSO, the following steps must be followed:

- Install the Standard SSO Widget component
- Install the Standard SSO MicroService component
- Run the StandardSSO Configuration Widget Template.sql. This DB script will add an entry to:sso.Configuration table contains the config, in JSON format, needed by Standard SSO MS sso.ConfigurationHistory tableWidget tableAdd an entry in the table with a SLUG and matching widget Name
