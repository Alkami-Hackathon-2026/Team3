Accounts Microservice is an essential microservice at Alkami. It is responsible for all CRUD operations related to accounts, account types and account type classes. This guide will walk you through using the accounts microservice.

#### Before you begin
- Ensure you have access to [https://feeds.alkamitech.com](https://feeds.alkamitech.com)
- Validate you have Alkami.MicroServices.Accounts.Service.Host running in your IIS
- You have referenced these two packages in your code Alkami.MicroServices.Accounts.Contracts and Alkami.MicroServices.Accounts.Service.Client

### Guide

Reference the contract file (https://feeds.alkamitech.com/package-files/download?packageId=Alkami.MicroServices.Accounts.Contracts&version=2.45.0&feedName=nuget.dev&path=src%2FAlkami.MicroServices.Accounts.Contracts%2FIAccountServiceContract.cs) to see the full list of endpoints. In this guide we'll focus on retrieving account information by using GetAccountAsync().

In order to retrieve account information, we must first get user accounts by calling the Security Microservice

Add Alkami.MicroServices.Security.Client (https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.MicroServices.Security.Client) and Alkami.MicroServices.Security.Contracts (https://feeds.alkamitech.com/feeds/nuget.dev/Alkami.MicroServices.Security.Contracts)to package

Get User Accounts With Security Microservice

```
...
public static Func<ISecurityServiceContract> securityService = () => new SecurityServiceClient();
...

List<UserAccount> GetUserAccounts()
{
var memberRequest = new GetUserRequest()
{
UserId = CurrentUser.Id,
Mapping = new UserMapper()
{
ShouldIncludeExternalUserAccounts = true,
ShouldIncludeUserAccounts = true,
ShouldIncludePermissions = true,
ShouldIncludeUserAccountPermissions = true
}
};
this.AugmentRequest(memberRequest);

// Get the user account from the Security microservice
var userAccount = AsyncHelper.RunSync(() => securityService().GetUserAsync(memberRequest));

// Return an empty list if the user account doesn't exist or is marked as deleted.
if (userAccount == null || userAccount.Users.FirstOrDefault().IsDeleted)
return new List<UserAccount>();

// There should only be one user in the UserAccount so we will grab the first one and it' associated accounts.
return userAccount.Users.FirstOrDefault().UserAccounts;
}
```

Retrieve an account by using an accountId.

AccountFilter provides an implementation for us to filter accounts, in this example, we are filtering base on an exact match with the accountId and we also want to include any ExternalAccounts in the result set.

The mapper tells the service whether to include certain pieces of data in the response. In this example we want to include AccountType and RoutingInfo in the result set, as well as applying an account Mask to MaskAccountNumber.

Get An Account

```
Account GetAnAccount(long accountId)
{
Account result = new Account();
var accountRequest = new GetAccountRequest()
{
Filter = new AccountFilter() { Ids = new List<long> { accountId }, IncludeExternal = true },
Mapping = new AccountMapper()
{
IncludeAccountType = true,
IncludeAccountTypeFields = null,
IncludeRoutingInfo = true,
AccountMaskSettings = new AccountMaskSettings()
{
FormatOnlyAccountHolder = false,
JoinAccountHolderNumberFormatString = BankSettings.GetSettingOrDefault(BankSettingName.JoinAccountHolderNumberFormatString, "{0}{1}"),
PadOutput = false
}
}
};

this.AugmentRequest(accountRequest);

// Get the account from the Accounts microservice
var accountsResponse = AsyncHelper.RunSync(() => accountsService().GetAccountAsync(accountRequest));

// Because we are filtering by accountId, there should always only be one account under this criteria
if (accountsResponse.Accounts != null && accountsResponse.Accounts.Count == 1)
result = accountsResponse.Accounts[0];
return result;
}
```
