This page is a good place to start for tackling a business banking feature. Some of these sections may differ if you are connected to a test core. In those cases, it may be better to setup a user directly from the admin portal within your staging environment.

### Business Entities (Users)

The SDK's DeveloperDynamic database has two business users representing two separate entities: Rene Beecken and Alina Adamec. You can see these users, their login usernames and their business details within the admin portal, https://admin-developer.dev.alkamitech.com/Users/ManageUser (https://admin-developer.dev.alkamitech.com/Users/ManageUser)

Once we've added the Business Admin feature to our SDK, you'll use one of these users to create new sub-users.

### Enabling the Business Administration widget

The SDK does not come with the Business Admin widget by default and will require us to configure the feature.

Run the following SQL scripts:

Install Widget

```
WHILE @@TRANCOUNT > 0 ROLLBACK
SET XACT_ABORT ON
SET NOCOUNT ON
SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED

--USE DeveloperDynamic

BEGIN TRAN

--Configuration variables
DECLARE @OldWidgetName NVARCHAR(100) = 'BusinessAdministration',
@WidgetName NVARCHAR(100) = 'BusinessAdmin',
@WidgetDisplayName NVARCHAR(100) = 'Business Admin',
@WidgetAssemblyInfo NVARCHAR(100) = 'Alkami.Client.Widgets.BusinessAdmin',
@WidgetDescription NVARCHAR(100) = 'Create and Manage Business Users and Roles, as well as authorizing submissions',
@WidgetIconName NVARCHAR(100) = 'business-admin',
@WidgetIsActive BIT = 0, --Should be able to add the widget to a flavor and be visible to use
@WidgetDisplaySettings INT = 7, -- Platforms the widget should be available
@WidgetType INT = 0,
@WidgetNotificationExists BIT = 1, -- If 0 then no widget notification will be created
@WidgetNotificationIsBusinessOnly BIT = 1;

--------------------------------------------------------
--Changes below here should be uncessary for new widgets
--------------------------------------------------------

--Script variables
DECLARE @BankId BIGINT,
@OldWidgetId BIGINT,
@WidgetId BIGINT,
@LocalizableResourceWidgetName NVARCHAR(100) = 'Widget.' + @WidgetName,
@LocalizableResourceId BIGINT,
@LocalizableItemId BIGINT,
@LocalizableItemSettingDisplayNameId BIGINT,
@LocalizableItemSettingDescriptionId BIGINT,
@WidgetNotificationActionId BIGINT;

DECLARE @RowCount BIGINT;

SELECT @BankId = Id FROM core.Bank
SELECT @OldWidgetId = Id FROM core.Widget WHERE Name = @OldWidgetName
SELECT @WidgetId = Id FROM core.Widget WHERE Name = @WidgetName
SELECT @LocalizableResourceId = Id FROM dbo.LocalizableResource lr WHERE lr.Name = @LocalizableResourceWidgetName
SELECT @LocalizableItemId = Id FROM core.Item WHERE ItemType = 'Localizable Resource' AND ParentId = @LocalizableResourceId
SELECT @LocalizableItemSettingDisplayNameId = Id FROM core.ItemSetting WHERE ItemId = @LocalizableItemId AND Name = 'DisplayName'
SELECT @LocalizableItemSettingDescriptionId = Id FROM core.ItemSetting WHERE ItemId = @LocalizableItemId AND Name = 'Description'
SELECT @WidgetNotificationActionId = Id FROM core.WidgetNotificationAction WHERE WidgetID = @WidgetId

--Insert/Update Widget
IF @WidgetId IS NULL
BEGIN
INSERT INTO core.Widget
(BankID, Name, AssemblyInfo, Salt, Active, IconImage, IconContentType, CanBeRemoved, Slug, CreateDate, DisplaySettings, WidgetType, IconName)
VALUES
(@BankId, @WidgetName, @WidgetAssemblyInfo, 0, @WidgetIsActive, null, null, 1, null, GETUTCDATE(), @WidgetDisplaySettings, @WidgetType, @WidgetIconName)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.Widget records'

SET @WidgetId = SCOPE_IDENTITY()
END
ELSE
BEGIN
UPDATE core.Widget
SET IconName = @WidgetIconName
WHERE Id = @WidgetId

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.Widget records'
END

SELECT * FROM core.Widget WHERE Id = @WidgetId

--Insert Localizable Resource
IF @LocalizableResourceId IS NULL
BEGIN
INSERT INTO dbo.LocalizableResource
(Name, SecondaryId)
VALUES
(@LocalizableResourceWidgetName, -1)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' dbo.LocalizableResource records'

SET @LocalizableResourceId = SCOPE_IDENTITY()
END

SELECT * FROM dbo.LocalizableResource WHERE Id = @LocalizableResourceId

--Insert Localizable Resource Item
IF @LocalizableItemId IS NULL
BEGIN
INSERT INTO core.Item
(ItemType, ParentId, SecondaryId, Name, CreatedUtc, Version, Deleted, LastUpdate)
VALUES
('Localizable Resource', @LocalizableResourceId, 1033, @LocalizableResourceWidgetName, GETUTCDATE(), '1.0.0.0', 0, NULL)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.Item records'

SET @LocalizableItemId = SCOPE_IDENTITY()

END

SELECT * FROM core.Item WHERE Id = @LocalizableItemId

--Insert widget display name
IF @LocalizableItemSettingDisplayNameId IS NULL
BEGIN
INSERT INTO core.ItemSetting
(ItemId, Name, Value, CreatedUtc, Version, LastUpdate)
VALUES
(@LocalizableItemId, 'DisplayName', @WidgetDisplayName, GETUTCDATE(), '1.0.0.0', NULL)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.ItemSetting records'

SET @LocalizableItemSettingDisplayNameId = SCOPE_IDENTITY()
END

SELECT * FROM core.ItemSetting WHERE Id = @LocalizableItemSettingDisplayNameId

--Insert widget descrption (shown when selecting a widget to add as a user)
IF @LocalizableItemSettingDescriptionId IS NULL
BEGIN
INSERT INTO core.ItemSetting
(ItemId, Name, Value, CreatedUtc, Version, LastUpdate)
VALUES
(@LocalizableItemId, 'Description', @WidgetDescription, GETUTCDATE(), '1.0.0.0', NULL)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.ItemSetting records'

SET @LocalizableItemSettingDescriptionId = SCOPE_IDENTITY()
END

SELECT * FROM core.ItemSetting WHERE Id = @LocalizableItemSettingDescriptionId

--Insert widget notification action
IF @WidgetNotificationExists = 1 AND @WidgetNotificationActionId IS NULL
BEGIN
INSERT INTO core.WidgetNotificationAction
(WidgetId, Name, BusinessOnly, EnabledByDefault)
VALUES
(@WidgetId, @WidgetDisplayName, @WidgetNotificationIsBusinessOnly, 0)

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.WidgetNotificationAction records'

SET @WidgetNotificationActionId = SCOPE_IDENTITY()
END

SELECT * FROM core.WidgetNotificationAction WHERE Id = @WidgetNotificationActionId

--Copy Widget Settings from old widget
IF @OldWidgetId IS NOT NULL
BEGIN
MERGE INTO core.WidgetSetting AS [Target]
USING
(
SELECT
Id,
WidgetId,
Name,
Value,
CreateDate
FROM
core.WidgetSetting
WHERE WidgetId = @OldWidgetId
) AS [Source] ON [Target].WidgetId = @WidgetId AND [Target].Name = [Source].Name
WHEN NOT MATCHED THEN
INSERT
(WidgetId, Name, Value, CreateDate)
VALUES
(@WidgetId, [Source].Name, [Source].Value, GETUTCDATE());

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.WidgetSetting records'
END
ELSE
PRINT 'Old Widget Id is null'

SELECT * FROM core.WidgetSetting WHERE WidgetId = @WidgetId

ROLLBACK TRAN
--COMMIT TRAN

SET TRANSACTION ISOLATION LEVEL READ COMMITTED
WHILE @@TRANCOUNT > 0 ROLLBACK
```

Configure Widget Flavor

```
WHILE @@TRANCOUNT > 0 ROLLBACK
SET XACT_ABORT ON
SET NOCOUNT ON
SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED

USE DeveloperDynamic

----------------------------------------------------------------------------------------------
--Summary
----------------------------------------------------------------------------------------------
-- The following script replaces an old widget with a new widget in all configured flavors.

BEGIN TRAN

----------------------------------------------------------------------------------------------
--Variables
----------------------------------------------------------------------------------------------
DECLARE @TargetFlavors TABLE (FlavorId BIGINT);

DECLARE
@BankId BIGINT,
@NewWidgetName NVARCHAR(100),
@OldWidgetName NVARCHAR(100),
@NewWidgetId BIGINT,
@OldWidgetId BIGINT,
@ErrorMessage NVARCHAR(100);

DECLARE @RowCount BIGINT

----------------------------------------------------------------------------------------------
--Configuration
----------------------------------------------------------------------------------------------
SET @NewWidgetName = 'BusinessAdmin';
SET @OldWidgetName = 'BusinessAdministration';

--If a flavor name is misspelled, it will NOT be configured
--so ensure the flavor names are correct or use flavor Ids to insert into
--the @TargetFlavors table
INSERT INTO @TargetFlavors (FlavorId)
SELECT Id
FROM core.Flavor f
WHERE f.Name IN ('Business Banking Flavor')

----------------------------------------------------------------------------------------------
--Validation
----------------------------------------------------------------------------------------------
SELECT @BankId = Id FROM core.Bank
SELECT @NewWidgetId = Id FROM core.Widget w WHERE w.Name = @NewWidgetName
SELECT @OldWidgetId = Id FROM core.Widget w WHere w.Name = @OldWidgetName

IF @BankId IS NULL
THROW 50001, 'Missing BankId', 1;

IF @NewWidgetId IS NULL
BEGIN
SET @ErrorMessage = 'Unable to find existing Target Widget with Name = ' + @NewWidgetName;
THROW 50001, @ErrorMessage , 1;
END

SELECT
@BankId AS BankId,
@NewWidgetId AS NewWidgetId,
@OldWidgetId AS OldWidgetId

SELECT
tf.FlavorId AS FlavorId
FROM @TargetFlavors tf

----------------------------------------------------------------------------------------------
--Script
----------------------------------------------------------------------------------------------

--If the old widget exists but not the new widget, update the old widget in place to point to the new widget
UPDATE oldFlavorWidget
SET WidgetID = @NewWidgetId
OUTPUT deleted.*, inserted.*
FROM @TargetFlavors tf
LEFT JOIN core.FlavorWidget oldFlavorWidget ON oldFlavorWidget.FlavorID = tf.FlavorId AND oldFlavorWidget.WidgetID = @OldWidgetId
LEFT JOIN core.FlavorWidget newFlavorWidget ON newFlavorWidget.FlavorID = tf.FlavorId AND newFlavorWidget.WidgetID = @NewWidgetId
WHERE
oldFlavorWidget.ID IS NOT NULL
AND newFlavorWidget.ID IS NULL

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.FlavorWidget records'

UPDATE oldUserWidget
SET WidgetID = @NewWidgetId
OUTPUT deleted.*, inserted.*
FROM @TargetFlavors tf
JOIN core.Users u ON u.FlavorID = tf.FlavorId
LEFT JOIN core.UserWidget oldUserWidget ON oldUserWidget.UserID = u.Id AND oldUserWidget.WidgetID = @OldWidgetId
LEFT JOIN core.UserWidget newUserWidget ON newUserWidget.UserID = u.Id AND newUserWidget.WidgetID = @NewWidgetId
WHERE
oldUserWidget.ID IS NOT NULL
AND newUserWidget.ID IS NULL

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Updated ' + CAST(@RowCount as nvarchar(10)) + ' core.UserWidget records'

--If the old widget and the new widget doen't exist then insert the new widget
INSERT INTO core.FlavorWidget
(FlavorID, WidgetID, AddedByDefault, FavedByDefault, CreateDate, Ordering, IsDefault, DisplaySetting, NativeDisplaySetting)
OUTPUT inserted.*
SELECT
tf.FlavorId AS FlavorID,
@NewWidgetId AS WidgetID,
1 AS AddedByDefault,
1 AS FavedByDefault,
GETUTCDATE() AS CreateDate,
0 AS Ordering,
0 AS IsDefault,
NULL AS DisplaySetting,
0 AS NativeDisplaySetting
FROM
@TargetFlavors tf
LEFT JOIN core.FlavorWidget oldFlavorWidget ON oldFlavorWidget.FlavorID = tf.FlavorId AND oldFlavorWidget.WidgetID = @OldWidgetId
LEFT JOIN core.FlavorWidget newFlavorWidget ON newFlavorWidget.FlavorID = tf.FlavorId AND newFlavorWidget.WidgetID = @NewWidgetId
WHERE
oldFlavorWidget.ID IS NULL
AND newFlavorWidget.ID IS NULL

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.FlavorWidget records'

INSERT INTO core.UserWidget
(UserID, WidgetID, IsFavorite, Ordering, DeactivationDate, CreateDate, IsMobileFavorite, MobileOrdering)
OUTPUT inserted.*
SELECT
u.Id AS UserID,
@NewWidgetId AS WidgetID,
0 AS IsFavorite,
0 AS Ordering,
NULL AS DeactivationDate,
GETUTCDATE() AS CreateDate,
0 AS IsMobileFavorite,
0 AS MobileOrdering
FROM @TargetFlavors tf
JOIN core.Users u ON u.FlavorID = tf.FlavorId
LEFT JOIN core.UserWidget oldUserWidget ON oldUserWidget.UserID = u.Id AND oldUserWidget.WidgetID = @OldWidgetId
LEFT JOIN core.UserWidget newUserWidget ON newUserWidget.UserID = u.Id AND newUserWidget.WidgetID = @NewWidgetId
WHERE
oldUserWidget.ID IS NULL
AND newUserWidget.ID IS NULL

SET @RowCount = @@rowcount
IF (SELECT @RowCount) > 0
PRINT 'Inserted ' + CAST(@RowCount as nvarchar(10)) + ' core.UserWidget records'

ROLLBACK TRAN
--COMMIT TRAN

SET TRANSACTION ISOLATION LEVEL READ COMMITTED
WHILE @@TRANCOUNT > 0 ROLLBACK
```

### Logging In and the Business Admin Widget

Start by logging into the local environment using a business of your choice or with one of the two default accounts such as "roadrunner.admin"

Once in, the business admin widget is available under the "/BusinessAdmin" URL resource. This will take you to the "Authorizations" view but we'll be focused on Roles and Sub Users. For ACH Authorizations, see our guide on Business Banking Payees and ACH Authorizations.

Click on the "Roles" tab and then read the description.

Step 1 - Add a Role and give it a meaningful name and description. This can be changed later, once ready click "Create Role".

Step 2 - Adding accounts to your new role is easy, towards the bottom of the page click "Add Accounts" and select the applicable permissions.

With the permissions selected, choose from the Internal and External account lists and click the "Assign Accounts" button. The Accounts should now be listed under the "Accounts & Limits" section and this is all we need to create a Sub User. Feel free to continue to fill out the limits section for your selected accounts, once done click on the "Users" tab

Step 3 - Once on the "Users" tab, click the "Add a User" button in the left or top of the page and fill out the form using your own email and make sure to select the role you previously created.

Bill Williams should now be a registered user associated with your Business entity. From this screen we can administer all of Bill's access by switching him between roles.

### Logging In With a Sub User

Now that we have our user, log out and log back in using the sub user's registered username, in our case here it's 'second.roadrunner' and the credentials are the same as always, 12345. Bill will be asked to complete the registration process and then they're free to begin looking around.
