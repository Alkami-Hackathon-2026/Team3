Native SDK Install - Beta Release

See SDK Machine Setup (/spaces/SDKC/pages/40403249/SDK+Machine+Setup) for more information

We are proud to announce the Beta release of our native SDK. “Native” means the developer will no longer be required to download the Alkami SDK VM and can instead install the necessary components directly on a machine.

The installation uses the Chocolatey package manager and has a total size of less than 300mb. This will download and install, and configure the necessary components.

#### Minimum System Specifications
- Windows 8.1, 10+
- Visual Studio 2015/2017
- SQL Server 2012/2016/2017
- PowerShell 5.0
- “Run as Administrator” privilege in PowerShell
#### Preferred System Specifications
- Windows 10+ (1709 or later)
- Visual Studio 2017
- Sql Server Developer Edition 2016 or later
- 20+GB RAM
- Quad+ physical cores (with HT becomes 8, etc)
- 100GB extra disk space on C: for all components and examples over time
- Ability to make local machine changes as admin
#### Required Licensing
- Windows 8.1 or 10+ or Server 2016
- SQL Server 2012 or 2016
- Visual Studio 2015 or 2017
#### Unsupported Functionality
- Nag – Notification type alerts
- SMTP – No outbound emails
- SMS – No outbound sms messages
- Entrust/dedicated security – Uses the dynamic authentication module the same as the typical SDK process
- BillPay
- Wires/ACH/similar functionality
- Reporting in Admin

We will continue to support the legacy SDK Virtual Image through the end of 2018
VM use can continue after 2018, but FI will be responsible for base VM image and installing chocolatey packages

Chocolatey Feed Updates

It’s highly recommended to use the staging and production feeds as they contain the most hardened versions of libraries. Using the development and testing feeds is optional and comes with inherent risk as these are closest to the bleeding edge of new development.

##### ThirdPartyApproved 3rd-party nuget libraries
##### choco.canaryEarly release of certain code from development with no QACurrently used today but will be deprecated after Q3 2018 in favor if the dev, qa, stage and prod feeds.
##### choco.devLatest releases from development with little to no QA
##### choco.qaReleases that have passed internal dev team QA
##### choco.stageReleases Alkami QA approved packages for Staging environment
##### choco.prodReleases approved for Production environment
Authorization Widget

The Authorization widget has been componentized and requires installation to the ORB platform. This will be managed by the SDK install and should require no extra effort from the SDK developer.

This widget can be installed from any of the choco environment feeds mentioned above.
