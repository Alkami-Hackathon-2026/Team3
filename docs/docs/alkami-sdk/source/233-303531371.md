While the majority of the CSS for an application will be in the components themselves, there are times that additional styling is needed (i.e. for a third party library). In these cases, having a file in the styles folder that can be imported into the App.vue file is the best way to get those styles into the application. The reason it is imported into the App.vue file is that the style block in that component is not scoped and therefore will be available to every component making use of the third party library.

App.vue

```
<style lang="scss">
// Custom styles for snotify
@import './styles/_snotify-custom.scss'; // Import third party library here

html,
body {
height: 100%;
margin: 0;
padding: 0;
}
</style>
```
