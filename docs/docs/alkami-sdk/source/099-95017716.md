### Removed Event Management Microservice

The SDK Features (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.MachineSetup.SDK.Features) package will not have this as a dependency any longer. There are changes coming to the event architecture for SDK clients and we plan to reintroduce them at a future date. If you have a dependency on the Event Management microservice, you will need to add that in addition to the SDK Features package, there are no changes for you to implement to continue working with the existing event microservice infrastructure.

### Radium Jobs

The base SDK package (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.MachineSetup.SDK) has temporarily gained two Radium jobs, "Bill Pay (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.App.Providers.Radium.BillPay)" and "Approve ACH Batch (https://feeds.alkamitech.com/feeds/choco.dev/Alkami.App.Providers.Radium.ApproveACHBatch)." These will be removed in the near future, there are no actions necessary for your team.
