The full Go Live deployment of the new widget is a scripted change. Our team works on a weekly sprint schedule, and we will need 7-10 days advance notice in order to have the script created/scheduled.

- By scripting the Go Live, we're able to add the widget to the "More" section of your users' profile; there will be no action needed on their part to see the widget. Additionally, we can optionally make the new widget a Favorite. This will not disturb any widget preferences/adjustments your users have made over time.
- The Go Live script will be run in the morning of the day that is chosen for Go Live. These scripts are run out of a queue, and are typically completed by 9am Central (however, priority events have the potential to delay).
- No additional bounce is required for the Go Live (assuming you've done a Pilot test).

The above steps and the steps listed in the Production Pilot (/pages/viewpage.action?pageId=150657870) procedure are not necessarily linear. The config, pilot and go live requests could all be made at the same time as long as proper timing is considered (allowing for the initial pod bounce, sufficient Pilot testing and time to build the script).
