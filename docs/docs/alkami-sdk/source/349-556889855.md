The SSO Creation activity allows admins to create new SSO configurations from within the admin site. In addition to the configuration, a widget and site text will automatically be created for the configuration as well.

It can be access by clicking the "Create SSO" button on the landing page:

## Templates

You can select a pre-made template from the dropdown for many different integrations:

All templates will have the following settings

- Provider Name - The name of the SSO configuration
- Widget Name - The name of the associated widget that will be created
- Description - Short description of the SSO. Not shown anywhere to end user
- Display Settings - What platforms the widget will be enabled for (Default to all)

Additionally, there will be further template specific settings. These are based on what has typically been required for implementing the same SSO in the past. All fields are required. Clicking the Generate Config button will generate the associated SSO configuration:

The configuration will not be saved and no widget created until you click the Save SSO button.
