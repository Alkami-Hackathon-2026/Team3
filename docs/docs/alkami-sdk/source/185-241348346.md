This process is for new implementations only. For updates to existing implementations please create a standard support ticket.

These instructions will explain how to get your Standard SSO configuration set up.

This includes

- certificate creation and install.
- Running of the Jarvis configuration script

If you are creating a custom SSO micro service that this process can not deploy any custom code project i.e. microservice or widget.

Start creating the ticket just like you would a standard microservice issue

Then after clicking the next button

If package URL is required you can input any URL into this process, the URL is not actually used for this Component type.

After the ticket is created our automation will periodically scan and provide further instructions and updates on the ticket.

After the ticket is created get the SQL statement that includes the jarvis config and attach it to the ticket as init.Jarvis.sql. Our Automation will scan this file (usually in about 30 min) and then provide further instruction via comments on the ticket.

Once the init.Jarvis.config is attached the automation will scan it (usually in about 30 min) and determine what certificates are needed. Instructions will be added comments to the ticket like the ones below. Please note that CSTEST is a test projects and your naming instruction should include your own prefix.

Also note that Alkami will provide a signing certificate while an encryption certificate if needed will be provided by the vendor.

Note that tickets internal to Alkami will be created. You may not be able to this tickets directly and they are handled by different departments within Alkami. They may take several days to complete.
