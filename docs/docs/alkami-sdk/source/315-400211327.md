We encourage you to upgrade your SDK environments to this version soon so you will be able to test with the same version that is in the Alkami Stage environment and will soon be in the Production environment.

As always, please be sure you follow the current version of the SDK installation and instructions as posted on https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html (https://confluence.alkami.com/sdk/alkami-platform-machine-setup-48800506.html).
These instructions are frequently updated and some of the major callouts are below.

Microsoft .NET 6.0 & Microsoft .NET 8.0 frameworks are required.

- https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-6.0.406-windows-x64-installer.
- https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-8.0.400-windows-x64-installer.If you installed Visual Studio 2022 recently, the installer might report that you already have this installed.

When upgrading to the 2024.4 SDK release

- Check the version of Alkami.Services.Subscriptions.Host that is running in your SDK.| clist subscriptions -lo | If the you have a version greater than v5.4.0 installed you will need to downgradeStop The Alkami.Services.Subscription.Host in the Services panelRun the command below to force the downgrade| choco install Alkami.Services.Subscriptions.Host --version 5.4.0 -fy | Open the Services panel and start the Alkami.Services.Subscriptions.Host serviceIf the service is not set to Automatic (Delayed Start). Right click on the service and select properties and change the startup mode accordingly.
- Run the following SQL command to update the connection string for all tenants in the AlkamiMaster database. Without this update the newer services will not run their migrations and won't be properly registered in the database.Update dbo.tenant record connection strings| use AlkamiMasterupdate dbo.Tenant set ConnectionString = ConnectionString + 'TrustServerCertificate=true;'where not (ConnectionString like '%TrustServerCertificate=true;%') |

Don't forget that if you have a stage-match site that you may need to also manually upgrade the core-specific chocolatey packages related to the core connection.

There are some helpful troubleshooting and support tips on https://confluence.alkami.com/sdk/common-support-solutions-216493829.html (https://confluence.alkami.com/sdk/common-support-solutions-216493829.html) if you need them.
