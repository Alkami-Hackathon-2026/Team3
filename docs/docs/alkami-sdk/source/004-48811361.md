### Overview

A microservice comes in a few different configurations: logical, persisted database, and persisted master database. Regardless of these flavors, the following guide still applies. Internally, Alkami leverages the Bamboo build process to package a successfully built microservice. In the case of client development, custom meta data related to the package must be supported. The microservice installers have been updated to handle a custom .nuspec file that a client can edit with company specific meta data and file line items. The client will only need to setup the .nuspec file once without fear of losing the customized meta data when upgrading the installer add-on. The below steps will guide a client through the installation of a Microservice Installer. To be clear, a microservice does not contain an installer when created from a template, an external installer must be installed within the microservice project hierarchy. Yes, this is indeed installing an installer.

Pre-Req Quick Check

- Adequate experience and knowledge of the Alkami microservice architecture
- Familiarity with Nuget and Chocolatey
- Existing microservice created from the Alkami Microservice Template

### Step-by-step guide

A newly created vanilla microservice was created from template and a Debug build was ran successfully. There is no installer package needed anymore as the files and scripts are already included in the template.

#### Configuring a custom .nuspec file
- Using Windows Explorer, open the root directory of the Host project. The Installer folder in the service's Host project contain the logic for installing the service.
- Edit the .nuspec in the "Installer" folder. You'll want to un-comment line 18 (your line number may vary) but it will be the one containing the <file target="src> tag seen here in the screen shot, and save the file.

#### Properly Building and Packaging the Service
- Rebuild in "Release" mode after making the edits in the "Installer" directory. This will rebuild the service and package the service using chocolatey.
- On success, the .nupkg will be created within the "Installer" directory
