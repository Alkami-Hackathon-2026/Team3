## Configuring an Environment for Standard SSO

To configure Standard SSO, the following steps must be followed:

- Install the Standard SSO Widget component
- Install the Standard SSO MicroService component
- Run the StandardSSO Configuration Widget Template.sql
- This DB script will add an entry to:sso.Configuration table Contains the config, in JSON format, needed by Standard SSO MS sso.ConfigurationHistory tableWidget tableAdd an entry in the table with a SLUG and matching widget Name
