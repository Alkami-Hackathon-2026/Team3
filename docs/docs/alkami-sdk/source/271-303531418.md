TITLE: Aliasing Source Paths

In many of the guides online (as well as if experimenting with the vue-cli to prototype an experience), you will most likely see an import statement that starts with an @ symbol instead of traditional relative pathing:

Code Example Path Alias

```
// Instead of relative pathing
import MyComponent from '../../components/MyComponent.vue';

// We can use the @ symbol to indicate the root of the project
import MyComponent from '@/components/MyComponent.vue';
```

The @ symbol is an alias that webpack and TypeScript know to resolve to the root of your application. This makes importing various functions and components throughout your application much simpler and easier to read. To configure this, there are two things you need to modify in your configuration.

#### tsconfig.json

In your tsconfig.json file, we need to add a baseUrl property as well as a paths object to let TypeScript know what we are aliasing where.

tsconfig.json

```
"compilerOptions": {
"baseUrl": ".",
"paths": {
"@/*": [
"Scripts/*"
],
},
},
```

##### Full tsconfg for reference purposes:
Full Config | tsconfig.json

```
{
"extends": "./node_modules/@alkami/albus-preset-vue/configs/tsconfig.json",
"compilerOptions": {
"baseUrl": ".",
"paths": {
"@/*": [
"Scripts/*"
]
},
},
"include": [
"Scripts/**/*.ts",
"Scripts/**/*.vue"
],
"exclude": [
"node_modules",
"**/*.spec.ts",
"**/__tests__",
"**/__mocks__",
"packages/**"
]
}
```

#### albus.config.js

Additionally, we need to let webpack know what is aliased as well. To do this, modify your albus.config.js file to include the alias property in your webpack configuration:

albus.config.js

```
'webpack': {
entry: {
desktop: './Scripts/app.ts'
},
config: {
resolve: {
alias: {
// Add any aliases you have here
'@': path.resolve(process.cwd(), './Scripts'),
},
},
},
},
```

Now when your application gets compiled, it will know how to reach any import prefixed by the @ symbol. You can add as many aliases as you want. There is no limit to the paths you can list here.

##### Full configuration for reference:
Full Config | albus.config.js

```
const path = require('path');

module.exports = {
tokens: {
projectNamespace: 'Alkami.Apps.Widget',
orbWidgetName: 'Widget'
},
presets: ['vue'],
presetConfiguration: {
'vue': {
plugins: ['webpack'],
pluginConfiguration: {
'webpack': {
entry: {
desktop: './Scripts/app.ts'
},
config: {
resolve: {
alias: {
'@': path.resolve(process.cwd(), './Scripts'),
},
},
},
},
},
},
},
}
```
