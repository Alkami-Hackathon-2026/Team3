Alkami Embedded can start a session with a JWT.

This requires that an external OIDC user has been registered as an Alkami user. More information for OIDC user management can be seen here: Hanscom OIDC Provider (/pages/viewpage.action?pageId=556879312).

AlkamiEmbedded provides a simple way to start an Alkami OLB session.

Future<String?> startAuthSession(String jwt);

On success, Alkami Embedded will manage the authentication session, including making API requests and refreshing the associated access token as needed.

This method also returns the Alkami access token to make API requests directly.
