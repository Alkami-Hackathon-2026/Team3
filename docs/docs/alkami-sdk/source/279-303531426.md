TITLE: Combining Legacy and Vue Presets
PARENT: Tips and Tricks

Some projects find that they want to gradually integrate Vue into their UI while leaving their current code alone. This can easily be configured. This guide assumes you have already installed @alkami/albus-preset-legacy and @alkami/albus-preset-vue and ran npx albus catalyst.

#### tsconfig.json

Make sure that the tsconfig.json that is in your project folder is extending the Vue preset tsconfig.json and not the legacy one. It should look something like this:

tsconfig.json

```
{
"extends": "../node_modules/@alkami/albus-preset-vue/configs/tsconfig.json",
"include": [
"**/*.ts",
"**/*.vue"
],
"exclude": [
"node_modules",
"**/*.spec.ts",
"packages/**"
]
}
```

#### albus.config.js
##### No Legacy TypeScript

If the project doesn't have any typescript from the legacy part of the project. Add the following to your presetConfiguration in your configuration file.
_NOTE:_ you could also remove 'bundle-js', if you do not have any of the legacy bundling ([something].bundle.json) in your widget.

No legacy TypeScript | albus.config.js

```
presets: ['legacy', 'vue'],
presetConfiguration: {
legacy: {
plugins: [
'bundle-js',
'compile-sass',
'minify-js',
]
},
vue: {},
}
```

This configuration will compile all your sass, minify your JavaScript and compile the default entrypoint for Vue projects at Scripts/app.ts.

##### A Few Legacy TypeScript

If you only have one or two legacy ts files, You might just want to add those as entrypoints into your Vue configuration. Since the vue preset utilizes typescript and Webpack, it's a nice alternative to using the legacy typescript plugin. This is how you would configure those entry points:

Some legacy TypeScript | albus.config.js

```
presets: ['legacy', 'vue'],
presetConfiguration: {
legacy: {
plugins: [
'bundle-js',
'compile-sass',
'minify-js',
]
},
vue: {
webpack: {
entry: {
'app': './Scripts/app.ts',
'scriptname-ts': './Scripts/scriptname.ts',
'path/to/scriptname-ts': './Scripts/path/to/scriptname.ts',
},
}
},
}
```

##### Full of Legacy TypeScript

Now if your project heavily relied on building TypeScript the legacy way and creating entry points is not that viable, then you can use the legacy TypeScript plugin but you will need to craft a glob that excludes your Vue related TypeScript.

The configuration might look something like this if you follow the Vue project anatomy guidelines (/pages/viewpage.action?pageId=78847239):

Lots of legacy TypeScript | albus.config.js

```
presets: ['legacy', 'vue'],
presetConfiguration: {
legacy: {
plugins: [
'bundle-js',
'compile-sass',
'minify-js',
'compile-ts'
],
'compile-ts': {
files: [
'./Scripts/**/*.ts',
'!./Scripts/+(api|components|directives|filters|interfaces|store|styles|utils|views)/**/*.ts',
'!./Scripts/+(app|router|shims-vue.d).ts',
],
suffix: '-ts',
}
},
vue: { },
}
```
