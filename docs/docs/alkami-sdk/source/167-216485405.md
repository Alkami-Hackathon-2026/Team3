TITLE: Add a Sub-Nav Tab to MyAccountsV2

This page describes how to add a navigation link to the MyAccountsV2 page that displays account information to desktop users.

The following is the SQL to do this:

```
declare @widgetId as bigint
select @widgetId=ID from core.widget where name = 'MyAccountsV2'

if (@widgetId is null)
BEGIN
print 'Something is wrong. The MyAcocuntsV2 widget could not be found!'
END
ELSE
BEGIN
-- select * from core.widgetsetting
if EXISTS(Select * from core.WidgetSetting where WidgetID = @widgetId and [Name] = 'external_information_account_types')
BEGIN
print 'Updating existing widget setting'
update core.WidgetSetting set value =
'[{"CoreName": "VCHK","Url": "/DemoHelloWorld","Label": "Rates", "UsexUrl": "false"}]'
where WidgetID = @widgetId and [Name] = 'external_information_account_types'
END
ELSE
BEGIN
print 'Adding new widget setting'
Insert into core.WidgetSetting (WidgetID,[Name],[Value]) Values (@widgetId,'external_information_account_types',
'[{"CoreName": "VCHK","Url": "/DemoHelloWorld","Label": "Rates", "UsexUrl": "false"}]')
END
END
```

Replace the CoreName value with a RegEx expression to match the name of the account type for which you want the tab to be visible.

You cannot do this in mobile.

You cannot change the icon shown to the left of your label.

You can provide a URL that links to a custom widget. The URL will automatically have the accountIdentifier for the account that is currently displayed in MyAccountsV2.
