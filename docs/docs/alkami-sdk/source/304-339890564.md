### Before you begin
- Ensure you have the latest version of Alkami SDK Templates Installed Link
- Running version of SDK Installed on local machine

### Guide

Start visual studio as admin. Find and select the template Alkami Client Widget

Fill out the Create a Client Widget Form and make sure the checkbox "Add Code for For Money Movement"

If you do not have your bank Identifier Handy, you can use the default DeveloperDynamic one (78554577-9DE6-43CD-9085-5868977156D1)

Widgets now should auto execute install_widget.sql, this can be confirmed by looking into the developerDynamic DB. In the case where the auto insertion did not happen, you will be required to run the install_widget.sql yourself.

Start by doing a clean build of the project. If Visual Studio is in Admin mode, the post installation should execute and successfully install the Widget. You can confirm this by checking the build output.

You should be able to see the widget by navigating to the URL.

This is an example of a basic layout showcasing the use of Iris Vue. The buttons aren't hooked up to any functionality yet. You can add functionality to these buttons by adding Vue Methods. For the purpose of the hackthon, you can experiment and add any functionality you like!
