TITLE: TSLint Deprecation Warnings Solution: Upgrading to ESLint from TSLint
PARENT: Release Notes

-----
Since Albus version 1.4.0, TSLint was officially deprecated and the upgrade to ESLint began. Now, with the latest version of Albus, TSLint support has been removed entirely in order to expand our linting capabilities for users of Albus.

Thankfully, the transition from TSLint to ESLint is an easy one.

### Automatically Upgrading to ESLint

To automatically upgrade your project to ESLint after upgrading your Albus dependencies, you can simply re-run Catalyst in your repo root to generate the necessary files and cleanup existing deprecated TSLint configurations:

npx albus catalyst -C Alkami.Client.Widget.MyWidget

Once this is completed, you'll notice two changes in your project:

- First, all tslint.json files have been removed
- Second, new .eslintrc.js files have been added to your solutions

You'll want to commit both of these changes. Once complete, your ESLint upgrade will be complete and you can continue developing!

### Manually Upgrading to ESLint

Start by deleting your tslint.json file, as it will no longer be needed, and will continue to produce warnings if it isn't removed.

#### Creating an ESLint Config

We've created two main base ESLint configuration packages for use with Albus to get started. All that is needed is to simply extend one of these, depending on whether or not you're using albus-preset-webpack or albus-preset-vue.

Luckily, these ESLint config packages, @alkami/eslint-config-vue-standard and @alkami/eslint-config-typescript-standard, are already preinstalled when you upgrade your other albus packages. So, there's no need to add additional packages to take advantage of ESLint.

##### albus-preset-vue

For projects using the Vue preset, create an ESLint configuration in your Solution directory with the following contents:

repo-root/Alkami.Client.Widget.MyWidget/.eslintrc.js

```
module.exports = {
'extends': '@alkami/eslint-config-vue-standard',
'parserOptions': {
'tsconfigRootDir': __dirname
}
};
```

##### albus-preset-webpack

For projects using the Webpack preset, create an ESLint configuration in your Solution directory with the following contents:

repo-root/Alkami.Client.Widget.MyWidget/.eslintrc.js

```
module.exports = {
'extends': '@alkami/eslint-config-typescript-standard',
'parserOptions': {
'tsconfigRootDir': __dirname
}
};
```

#### Using ESLint Unsafe Configuration Packages

In certain instances it may be necessary to use configuration that differs from Alkami's development standards. Because of this, we've also created two additional ESLint Configuration packages that provide a more lax solution for getting up and running with ESLint.

These packages have also been added as dependencies to their associated presets, so there's no need to install them manually.

##### albus-preset-vue

For projects using the Vue preset, create an ESLint configuration in your Solution directory with the following contents:

repo-root/Alkami.Client.Widget.MyWidget/.eslintrc.js

```
module.exports = {
'extends': '@alkami/eslint-config-vue-unsafe',
'parserOptions': {
'tsconfigRootDir': __dirname
}
};
```

##### albus-preset-webpack

For projects using the Webpack preset, create an ESLint configuration in your Solution directory with the following contents:

repo-root/Alkami.Client.Widget.MyWidget/.eslintrc.js

```
module.exports = {
'extends': '@alkami/eslint-config-typescript-unsafe',
'parserOptions': {
'tsconfigRootDir': __dirname
}
};
```
