For SDK users, there is an option to schedule deployments to preproduction environments (post staging, but before production).

### FI Steps
- Open the Jira Feature Request ticket submitted when the Vendor submitted your SDK package. (See Vendor Submits Widget or Service, section Submit Jira Delivery Request Ticket for Installation.)
- When prompted, submit your approval for Vendor submitted deployment.
### Vendor Steps
- Add a note to SDK Team member requesting preproduction install of element after Staging deployment by SDK Team. In your note, specify if you want the deployment copied exactly as it is in Stage into Prod.
- Assign status of Awaiting Configuration to the Jira ticket.
- Work with SDK and PSO on items shared in the Jira ticket.
### SDK Team Steps

SDK team creates RM ticket for install in preproduction.

### PSO Steps

PSO creates TI configuration ahead of install.
