### Session Information

This session will demonstrate how you can create custom alerts using the Event Management platform. Some of the topics covered will be :

- Overview of Event Management
- Overview of the Notifications Microservice
- Creating an Event Management Processor to send a real-time alert
- Creating an Event Managmeent Processor to send a scheduled alert

Presented by: Paul Palmer
