Where components are the building blocks of a Vue application, custom directives are mainly intended for reusing logic that involves low-level DOM access on plain elements.

The directives folder is used to house all custom Vue directives that can be used in the application. Each file exports a single method that can be registered globally or at a component level.

focus.ts

```
// A global custom directive called `v-focus`
export (element: HTMLElement) => {
element.focus();
};
```

To import this globally use the `app.directive` method in the main application entry point

app.ts

```
// Import the global directives
// =============================================================================
import focus from './directives/focus';

const app = createApp({});
app.directive('focus', focus); // The first parameter is a custom name for the directive
```

To import in a specific component, import with a `vName` syntax

Component.vue

```
<template>
<input v-focus />
</template>

<script setup lang="ts">
import vFocus from '../directives/focus';
</script>
```

Things of note:

- Each directive is in its own file and exported as an object
- The directive is either imported globally or at a component level
