## Software Application Validation

Complete the following steps in each of the programs referenced to validate your local build.

### Visual Studio
- Launch Visual Studio 2019 (or higher) using Run as administrator.
- Create a new project and select the Alkami Client Widget template. You might find it useful to set your filters as shown in the following screenshot.
- Click Next.
- Select Framework version 4.8 (if you do not see 4.8 in the framework list you will need to install it before proceeding).
- Click Create to build the project. Ensure it builds successfully. One of the things you are validating is that the Package Manager feeds sources for Alkami are configured correctly). Verify that your Visual Studio is up-to-date according to the Hardware and Software Requirements. Update it if your version is an old one.Note: While you are in Visual Studio you should receive any license or permissions errors. Confirm it is running properly. You can use a trial version, but confirm the trial will not expire prior to the last day of your scheduled training.
- Close Visual Studio.
### SQL Server Management Studio
- Open SQL Server Management Studio.
- Expand the databases list and ensure you see at least these two databases, AlkamiMaster and DeveloperDynamic.
### SDK Samples

Check to see if you have C:\AlkamiSDK\Samples and that this directory contains folders and files. If you do not find the folder, you can launch PowerShell as an administrator and enter the following command to install the samples:

```
choco install Alkami.SDK.Samples
```
