Q: What is Standard SSO and Jarvis?

A: Standard SSO is a tool that allows anyone to build most SSO integrations without creating a microservice or widget from scratch. This is done with a SQL script that configures the SSO. The SQL script consists of all the settings that the standard SSO microservice and widget need to correctly SSO.

Q: Is this tool available in the Alkami SDK?

A: Yes, this tool is available in the Alkami SDK.

Q: What kinds of SSOs does Standard SSO support?

A: Standard SSO supports most industry standard single sign-on interfaces including SAML, HTTP GET, HTTP POST, and so on.

Q: What information does standard SSO support?

A: Standard SSO can send any information outlined in the expression glossary: Standard SSO - Expression Glossary (/spaces/SDKC/pages/145509115/Standard+SSO+-+Expression+Glossary). The information sent in the SSO is determined in the standard SSO SQL configuration script.

Q: Does a standard SSO require a code deployment?

A: No, a standard SSO SQL script doesn't require a code deployment. Alkami must run the SQL script in the Alkami databases to set up the SSO settings

Q: Does standard SSO support using certificates?

A: Yes, standard SSO can support the use of certificates for signing or encryption.
