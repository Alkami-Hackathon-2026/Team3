### What is Albus?

At its foundation, Albus is an ecosystem of npm packages that work in harmony with each other to produce front end assets for experiences and interfaces on the Alkami platform.

The accompanying CLI package exposes commands (e.g., build, deploy, watch, test) to execute actions from those packages through a task runner (currently GULP) to produce those assets. Each functional package (referred to as a preset in the Albus ecosystem) is highly configurable in order to ensure it can work seamlessly in any number of situations or projects targeting the Alkami platform.

In one sentence

Albus is Alkami's componentized build system for front end assets that encapsulates our best practices and opinions for producing those assets.
