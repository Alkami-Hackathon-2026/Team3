## Errors When Saving
#### Malformed JSON

The most likely cause of an error when attempting to save a configuration is malformed JSON. This will be evident by the error message stating "unable to parse configuration":

You can check the syntax of your JSON using any JSON validator, such as this one (https://jsonlint.com/). Common reasons to invalid JSON are

- Missing commas
- Extra trailing commas
- Missing closing/opening brackets
- Mismatched/missing quotation marks
#### StandardSSO Syntax Errors
##### Expression that doesn't exist or typo in expression

Message: "Syntax error occurred in <location> for the expression:<incorrect expression>"

Cause: Most likely using an expression that doesn't exist or typo in expression name. Refer to Standard-SSO - Expression Glossary (/spaces/SDKC/pages/556889906/Standard-SSO+-+Expression+Glossary) for all valid expressions. Additionally, refer to Standard-SSO - Expression Syntax (/spaces/SDKC/pages/556889907/Standard-SSO+-+Expression+Syntax).

Example: Incorrect (FirstWrongName) expression in the form fields of the HttpRequest configuration.

##### Incorrect Use of an Expression

Message: "Invalid expression occurred in <location> for the expression: <expression>"

Cause: Incorrect or missing arguments to an operation expression

Example: Using "Left" expression without specifying both arguments

##### Other

Due to the breadth of configurations possible, there are many other errors that can occur for specific configurations. The error message will point to the location in the configuration and give a quick summary of the error. This can be used with the StandardSSO guide to deduce what the problem is.

#### An unknown error has occurred

If you receive this error message, please reach out to your Alkami contact or the Carbon team
