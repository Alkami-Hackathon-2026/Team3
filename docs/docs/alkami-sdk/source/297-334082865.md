This guide shows you how you can add a client package for an existing microservice to your existing widget. This allows the widget to integrate with the microservice and ultimately use the endpoints that the microservice exposes.

When a service is added, it's the widget's responsibility to bring those libraries with it when it's ready for deployment. This means that you must make sure the service libraries make it into the projects /bin directory so that Chocolatey can package it properly.

#### Before you begin
- Ensure you have access to [https://feeds.alkamitech.com](https://feeds.alkamitech.com)

### Guide
#### Importing the Reference

Search for the service and add the Alkami.MicroServices.Transactions.Client and Alkami.MicroServices.Transactions.Contract package. In this example we are importing Transactions Microservice.

#### Usage

```
Call the service in a C# class with the following delegate factory pattern:
```

```
/*The using statements are for example purposes, replace with references to real services*/
...
using Alkami.MicroServices.Transactions.Contracts;
using Alkami.MicroServices.Transactions.Contracts.Requests;
using Alkami.MicroServices.Transactions.Contracts.Responses;
using Alkami.MicroServices.Transactions.Service.Client;
...

/// <summary>
/// Replace the ITransactionServiceContract and TransactionServiceFactory types with the proper type to call a microservice
/// </summary>
public static Func<ITransactionServiceContract> TransactionServiceFactory = () => new TransactionServiceClient();

public ActionResult Transactions()
{
try
{
...
...Alkami.MicroServices.Transactions.
var transRequest = new GetTransactionsRequest();
this.AugmentRequest(transRequest);
var transactionsResponse = AsyncHelper.RunSync(() => TransactionServiceFactory().GetTransactionsAsync(transRequest));
var model = new WidgetModel {
Data = transactionsResponse.Data
};
return View("Transactions", model);
}
catch (Exception e)
{
Logger.Error("Error [GET] Controller/Transactions", e);
return View("Error");
}
}

```

#### Packaging

You must package these new Microservice libraries in the Chocolatey package.

Update Chocolatey's .nuspec file to target these new .dll files as package-able artifacts. A new line is under the existing <file src="bin\USBFI.* that targets the Transactions libraries we've previously referenced

```
<files>
<!-- The following defines where to find the files for packaging and what to exclude-->
<file src="tools\chocolateyInstall.ps1" target="tools" />
<file src="tools\chocolateyUninstall.ps1" target="tools" />
<file src="AlkamiManifest.xml" target="AlkamiManifest.xml" />
<file src="**\*.*" target="src" exclude="**\obj\**\*.*;**\.vs\**\*.*;**\bin\**\*.*;**\packages\**\*.*;**\.nuget\**\*.*;**\.git\**\*.*;**\.gitignore;**\node_modules\**\*.*;**\.suo;**\.user;**\Tests\**\*.*;**\Test\**\*.*;**\UnitTest\**\*.*;**\UnitTests\**\*.*;**\tools\**\chocolatey*.ps1" />

<!-- bin files | define the libraries that should be a part of this package -->
<file src="bin\USBFI.*" target="lib" exclude="**\*.config"/>
<file src="bin\Alkami.MicroServices.Transactions.*" target="lib" exclude="**\*.config"/>

<!-- WebClient content -->
<file src="**\Scripts\" target="content\Areas\App" />
<file src="**\Styles\" target="content\Areas\App" exclude="**\*.scss" />
<file src="**\Views\" target="content\Areas\App" />
<file src="**\Images\" target="content\Areas\App" />
<file src="**\_SiteText\" target="content\Areas\App" exclude="**\*.xx.xml"/>
</files>
```
