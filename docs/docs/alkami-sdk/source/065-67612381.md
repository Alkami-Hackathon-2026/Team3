## Stopping Alkami Services during upgrades

We've noticed some issues when services are running during an upgrade of the SDK. To ensure your Alkami Platform upgrade is successful, you may find it helpful to run the following command in PowerShell before upgrading:

PowerShell (Administrator)

```
# Before running an upgrade
Stop-IISAndServices

# Run the upgrade
choco upgrade alkami.machinesetup.sdk -y

# Start the services again
Start-IISAndServices
```

If those functions are not found in PowerShell, you should

PowerShell (Administrator)

```
choco install Alkami.PowerShell.IIS -y
```
