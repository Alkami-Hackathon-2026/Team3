Alkami.Utils is a collection of various low-level methods that perform small and repetitive operations. In other words they do one thing; no more, no less.

### Cookie
#### createCookie(name, value, days?)

Creates a cookie with a value and an optional expires value.

Arguments

- name (string)
- value (string)
- days? (number)

Returns

- (void): Returns void.

Example

```
if (!Alkami.Utils.CookieHelper.readCookie('browser_unsupported')) {
Alkami.Utils.CookieHelper.createCookie('browser_no_warn', 1);
}
```

#### readCookie(name)

Reads a cookie from the browser and returns the value.

Arguments

- name (string)

Returns

- (string | null): Returns the value of the cookie with the name from the cookie collection.

Example

```
if (!Alkami.Utils.CookieHelper.readCookie('browser_unsupported')) {
Alkami.Utils.CookieHelper.createCookie('browser_no_warn', 1);
}
```

#### eraseCookie(name)

Removes a cookie from the browser.

Arguments

- name (string)

Returns

- (void): Returns void.

Example

```
Alkami.Utils.CookieHelper.createCookie("testing", "moo", 1);

if (Alkami.Utils.CookieHelper.readCookie("testing") != null) {
Alkami.Utils.CookieHelper.eraseCookie("testing");
}
```

#### eraseAllCookies()

Deletes all cookies currently stored in the browser.

Arguments

- None

Returns

- (void): Returns void.

Example

```
if (this.loggedIn) {
this.initApp();
} else {
Alkami.CookieHelper.eraseAllCookies();
window.redirect('/login');
}
```

### Currency
#### parseCurrency(string)

Parses a currency string into a number.

Arguments

- string (string)

Returns

- (number): Returns a number representation of the currency string.

Example

```
Alkami.Utils.CurrencyHelper.parseCurrency('$34,545.43') // => 34545.43
Alkami.Utils.CurrencyHelper.parseCurrency('$0.00') // => 0
Alkami.Utils.CurrencyHelper.parseCurrency('0.00') // => 0
Alkami.Utils.CurrencyHelper.parseCurrency('34,454.3') // => 34454.3
```

#### formatCurrency(value, options)

formats a currency value into a string representing currency using the options provided.

Arguments

- value (number)
- options (IFormatCurrencyOptions)

```
interface IFormatCurrencyOptions {
useGroupingSeparators?: boolean; //default true
fractionalDigitsRequired?: boolean; //default true
showCurrencyIndicator?: boolean; //default true
useParenthesisNegativeMarker?: boolean; //default false
}
```

Returns

- (string): Returns a currency string representation of the value.

Example

```
Alkami.Utils.CurrencyHelper.formatCurrency(1); // => $1.00
Alkami.Utils.CurrencyHelper.formatCurrency(1.23); // => $1.23
Alkami.Utils.CurrencyHelper.formatCurrency(1000000); // => $1,000,000.00
Alkami.Utils.CurrencyHelper.formatCurrency(0); // => $0.00
Alkami.Utils.CurrencyHelper.formatCurrency(-3.24); // => -$3.24

// optional cents
Alkami.Utils.CurrencyHelper.formatCurrency(1, { fractionalDigitsRequired: false}); // => $1
Alkami.Utils.CurrencyHelper.formatCurrency(1.23, { fractionalDigitsRequired: false}); // => $1.23
Alkami.Utils.CurrencyHelper.formatCurrency(1000000, { fractionalDigitsRequired: false}); // => $1,000,000
Alkami.Utils.CurrencyHelper.formatCurrency(0, { fractionalDigitsRequired: false}); // => $0

// remove commas
Alkami.Utils.CurrencyHelper.formatCurrency(1000000, { useGroupingSeparators: false}); // => $1000000.00

// remove Dollar Sign '$'
Alkami.Utils.CurrencyHelper.formatCurrency(1.23, { showCurrencyIndicator: false}); // => 1.23

// use Parenthesis to indicate negative numbers
Alkami.Utils.CurrencyHelper.formatCurrency(-3.24, { useParenthesisNegativeMarker: true}); // => ($3.24)
Alkami.Utils.CurrencyHelper.formatCurrency(1.23, { useParenthesisNegativeMarker: true}); // => $1.23
```

#### isDate(date)

Checks whether the input passed in is a Date object.

Arguments

- date (any)

Returns

- (boolean): Returns boolean of if date input is a Date object.

Example

```

Alkami.Utils.DateHelper.isDate(test1) // => true
Alkami.Utils.DateHelper.isDate(test2) // => false
Alkami.Utils.DateHelper.isDate(test3) // => false
```

### Storage
#### hasStorage(type)

Checks whether the browser has access to a specific type of storage.

Arguments

- type ('local' | 'session')

Returns

- (boolean): Returns boolean of whether or not the browser has access to local or session storage.

Example

```
if (Alkami.Utils.StorageHelper.hasStorage('session')) {
window.sessionStorage[sessionStorageKey] = JSON.stringify(data);
}

if (Alkami.Utils.StorageHelper.hasStorage('local')) {
window.localStorage[localStorageKey] = JSON.stringify(data);
}
```

#### hasLocalStorage()

Checks if the browser has access to local storage.

Arguments

- None

Returns

- (boolean): Returns boolean of whether the browser has access to local storage.

Example

```
if (Alkami.Utils.StorageHelper.hasLocalStorage()) {
window.localStorage[this._localeStorageKey] = JSON.stringify(data);
}

if (!Alkami.Utils.StorageHelper.hasLocalStorage()) {
console.warn('Most likely in incognito mode.');
}
```

#### hasSessionStorage()

Checks if the browser has access to session storage.

Arguments

- None

Returns

- (boolean): Returns boolean of whether the browser has access to session storage.

Example

```
if (Alkami.Utils.StorageHelper.hasSessionStorage()) {
window.sessionStorage[this._localeStorageKey] = JSON.stringify(data);
}

if (!Alkami.Utils.StorageHelper.hasSessionStorage()) {
console.warn('Most likely in incognito mode.');
}
```

### String
#### camelize(word, [firstLetterInUppercase = true])

Converts a string to camelcase.

NOTE: Removes underscores and capitalizes words separated by them.

Arguments

- word (string)
- [firstLetterInUppercase = true] (boolean)

Returns

- (string): Returns word input converted to camelcase.

Example

```
Alkami.Utils.StringHelper.camelize('camels_are_very_cool', false) // => "camelsAreVeryCool"
Alkami.Utils.StringHelper.camelize('camels_are_very_cool', true) // => "CamelsAreVeryCool"
```

#### capitalize(text)

Capitalizes the first letter of the string.

Arguments

- text (string)

Returns

- (string): Returns word input converted to sentence case.

Example

```
Alkami.Utils.StringHelper.capitalize('capitalize me!') // => 'Capitalize me!'
```

#### dasherize(word)

Replaces underscores with dashes.

Arguments

- word (string)

Returns

- (string): Returns word input converted to kebabcase.

Example

```
Alkami.Utils.StringHelper.dasherize('profile_nav') // => 'profile-nav'
```

#### format(template, ...args)

Formats a string with template placeholders (e.g. {1}).

Arguments

- template (string)
- ...args (string[])

Returns

- (string): Returns string with template tags (e.g. {1}) interpolated with the arguments passed in.

Example

```
Alkami.Utils.StringHelper.format('{1} and {2} are friends.', 'Spike', 'Jet') // => 'Spike and Jet are friends.'
```

#### normalizePunctuation(text)

Replaces "smart punctuation" with standard ascii variants.

iOS 11 finally added a long-awaited feature for those of us who care about typographic details: smart punctuation. You can turn this on in Settings → General → Keyboards. When enabled, quotes and apostrophes (like "this" and 'this') are automatically turned into their proper counterparts (like "this" and 'this'), two hyphens in a row (--) are turned into a proper em-dash (—), etc.

https://daringfireball.net/2018/02/ios_messages_smart_punctuation (https://daringfireball.net/2018/02/ios_messages_smart_punctuation)

Arguments

- text (string)

Returns:

- (string): Returns text with standard punctuation.

Example

```
const inputString = 'This is a message from iOS with it's so—called "smart" punctuation.';
const sanitizedString = Alkami.Utils.StringHelper.normalizePunctuation(inputString);
//returns; This is a message from iOS with it's so-called "smart" punctuation.
```

#### parameterize(word, [sep = '-'])

Formats a string to have special characters replaced with - characters.

Arguments

- word (string)
- [sep = '-'] (string)

Returns

- (string): Returns word input with sep placed inbetween any character that is not a lowercase letter, digit, -, or _.

Example

```
Alkami.Utils.StringHelper.parameterize('what**a---weird\'string') // => "what-a-weird-string"
Alkami.Utils.StringHelper.parameterize('underscores_are_okay') // => "underscores_are_okay"
```

#### titleize(text)

Converts input string to titlecase.

NOTE: Does not replace underscores.

Arguments

- text (string)

Returns

- (string): Returns text input converted to titlecase.

Example

```
Alkami.Utils.StringHelper.titleize('what***does this---do') // => "What Does This Do"
Alkami.Utils.StringHelper.titleize('what_about_underscores') // => "What_about_underscores"
```

#### underscore(word)

Formats a string to put underscores in between capitals and digits. Arguments

- word (string)

Returns

- (string): Returns word input converted to snakecase.

Example

```
Alkami.Utils.StringHelper.underscore('UnderscorePascalCase') // => "underscore_pascal_case"
Alkami.Utils.StringHelper.underscore('can-this-handle-kebabcase') // => "can_this_handle_kebabcase"
Alkami.Utils.StringHelper.underscore('What-about-digits99-in-00text') // => "what_about_digits99_in_00text"
Alkami.Utils.StringHelper.underscore('WhatAbout99MultipleCapitalLLLetters') // => "what_about99_multiple_capital_ll_letters"
```
