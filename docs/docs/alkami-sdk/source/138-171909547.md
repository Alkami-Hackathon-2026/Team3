Audience

This document is intended for SDK developers that do not use a Stage match database with Core connectivity. The purpose of this document is to illustrate how to add fake external accounts for development of services and widgets.

- SDK clients that are using the stage match site should not be adding external accounts, but instead, sync their external accounts from their core providers.
- SDK clients that are using the DeveloperDynamic database and not a stage-match database can use.
- If you are a Gold Partner and you have access to a test core then you should work off of that core as if you were an SDK client.

Use the following commands to Add, Validate, or Remove External accounts.

### Add External Account

To set up external accounts, copy the following script, update the appropriate data, and execute the script in your local SQL Server instance against the DeveloperDynamic database.
Note: In the values of the first insert statement there are several 'null' values. This is the minimum data that needs to be included in the statement for it to be executed successfully. If more data is desired it can be added to the value of the appropriate column(s).

Add External Account

```
USE [DeveloperDynamic]
BEGIN

DECLARE @AccountIdentifier uniqueidentifier, @AccountTypeID bigint, @AccountNumber nvarchar(100), @AvailableBalance decimal(19,5), @LedgerBalance decimal(19,5),
@InterestRate decimal(19,5), @CoreProviderID bigint, @AccountHolder bigint
SELECT @AccountIdentifier = NEWID(), -- Create a new GUID
@AccountTypeID = 1534, -- ALKAMIACHCHK
@AccountNumber = '1111111111111111', -- Change this to something meaningful
@AvailableBalance = 1234.56,
@LedgerBalance = 1234.56,
@InterestRate = 0.0000,
@AccountHolder = 443459, -- This was the value used for all Mike Brady's accounts
@CoreProviderID = 1

DECLARE @MemberID bigint, @DisplayName nvarchar(100), @ThemeColorIndex int
SELECT @MemberID = 4858,
@DisplayName = 'External Test',
@ThemeColorIndex = 3

DECLARE @RoutingNumber nvarchar(11), @BankName nvarchar(100), @BankState nvarchar(2), @BankCity nvarchar(25), @DateOfLastRevision nvarchar(8)
SELECT @RoutingNumber = '11111111111',
@BankName = 'United States Best Financial Institution',
@BankState = 'TX',
@BankCity = 'Dallas',
@DateOfLastRevision = '106170'

DECLARE @ExternalAccountType smallint
SELECT @ExternalAccountType = 0

-- Insert Account record into core.account using the new AccountIdentifier

INSERT INTO [core].[Account]

,[InterestRate],[CollectedBalance],[YesterdayBalance],[InterestPaidYTD],[InterestPaidPYTD],[InterestPaidLTD],[LoanOpenDate],[OriginalBalance]
,[FirstLoanPaymentDate],[LastPaymentDate],[NextPaymentDate],[PrincipalAndInterestAmount],[NextPaymentAmountDue],[DailyInterestAccrued],[PastDueAmount]

,[LastCoreUpdate],[Locked],[ModifyDate],[CreateDate],[MICRAccountNumber],[RegDCount],[Warnings],[DividendPaymentFrequency],[DividendPaymentMethod]
,[DividendTransferAccountIdentifier],[MaturityDate],[MaturityPaymentMethod],[MaturityTransferAccountIdentifier],[AnnualPercentageYield],[DividendPaymentDate]
,[DividendPaymentInterval],[CoreProviderID],[RemoteIdentifier],[LastNagUpdateAdvisement],[CurrentTerm],[LastDepositDate],[LastRenewelDate],[LastWithdrawalDate]
,[EscrowBalance],[HoldAmount],[LastDepositAmount],[LastPaymentAmount],[LastWithdrawalAmount],[NetMemoAmount],[UncollectedFunds],[LastDirectDepositAmount]
,[LastDirectDepositDate],[AccountHolder],[CreditCardNumber],[MortgageNumber],[LastStatementBalance],[LastDividendPaidAmount],[LastTransactionDate],[CreditLimitAmount]
,[DividendRate],[DividendPaidYTD],[LastAccountUpdate],[LastTransactionsUpdate],[LastAccountHoldsUpdate],[CurrYTDWithholding],[CurrYTDFees],[CurrYTDPenalty],[PrevYrFees]
,[PrevYrWithholding],[PrevYrPenalty],[TaxesPaidYTD],[AggregateInstitutionId],[LateChargeDue],[InterestDue],[LastTransactionSyncScheduled],[LastTransactionSyncFinished]

VALUES
(NULL,@AccountIdentifier,@AccountTypeID,@AccountNumber,0,NULL,@AvailableBalance,@LedgerBalance,NULL,@InterestRate,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL

SET @AccountID = @@Identity

([UserID],[AccountID],[AccessLevelID],[DisplayName],[MobileDisplayName],[ThemeColorIndex],[HasMasterRights],[AddedByCore],[BillPayAccountKey],[CreateDate],[Ordering]
,[Deleted],[Relationship],[HideFromEndUser],[HiddenByEndUser],[RelationshipDescription],[IsHiddenFromBillPay],[IsBalancePeekEnabled],[LastUpdate])
VALUES
(@MemberID,@AccountID,NULL,@DisplayName,@DisplayName,@ThemeColorIndex,1,1,NULL,GETDATE(),7,0,3,0,0,NULL,0,0,NULL)

-- Insert RoutingNumberInfo record into core.routingnumberinfo

INSERT INTO [core].[RoutingNumberInfo]
([RoutingNumber],[BankName],[CreateDate],[RoutingNumberInfoType],[NewRoutingNumber],[IsBlockedForACH],[IsBlockedForWires],[BankShortName],[BankState],[BankCity]
,[DateOfLastRevision],[Deleted])
VALUES
(@RoutingNumber,@BankName,GETDATE(),0,NULL,0,0,NULL,@BankState,@BankCity,@DateOfLastRevision,0)

DECLARE @RoutingNumberInfoID bigint
SELECT @RoutingNumberInfoID = @@Identity

INSERT INTO [core].[ExternalAccount]
([ID],[RoutingNumberInfoID],[ExternalAccountType])
VALUES
(@AccountID,@RoutingNumberInfoID,@ExternalAccountType)

-- Update the newly created account record with the ID from the RoutingNumberInfo record as the RemoteIdentifier to denote it as an external account

UPDATE [core].[Account]
SET [RemoteIdentifier] = @RoutingNumberInfoID
WHERE [ID] = @AccountID

END
```

### Validate The Added External Accounts

The best way to validate that these new accounts is to install the MyMoney sample from the latest version of the Alkmai.SDK.Samples package. There is a change that will have to be made if it is not present in that version. The IncludeExternal property of the Filter in the GetAccountRequest will need to be added and set to true. The code sample below contains the change needed.

#### USBFIMyMoneyController
USBFIMyMoneyController

```
var accountRequest = new GetAccountRequest() { Filter = new AccountFilter() { Ids = accountIds, IncludeExternal = true }, Mapping = new AccountMapper() { IncludeAccountType = true, IncludeAccountTypeFields = null, IncludeRoutingInfo = true,
AccountMaskSettings = new AccountMaskSettings() { FormatOnlyAccountHolder = false, JoinAccountHolderNumberFormatString = BankSettings.GetSettingOrDefault(BankSettingName.JoinAccountHolderNumberFormatString, "{0}{1}"), PadOutput = false } } };
this.AugmentRequest(accountRequest);

var accountsResponse = AsyncHelper.RunSync(() => accountsService().GetAccountAsync(accountRequest));

accounts = new Dictionary<long, Account>();
if (accountsResponse.Accounts != null && accountsResponse.Accounts.Count > 0)
{
var externalAccounts = accountsResponse.Accounts.OfType<ExternalAccount>().ToArray();
foreach (var account in accountsResponse.Accounts)
{
accounts.Add(account.Id, account);
}
}
```

Once the above code change is in place the widget will need to be built and installed or rebuilt if the sample is already in the local SDK environment. After the updated version of the sample is in place put a breakpoint on the match to line 12. The line above that is only in place to validate that the external account are included and cast properly.

### Remove External Accounts

If for some reason you need to remove an external account that you created you can run the script below with the correct account number to remove all records pertaining to it.

Warning

Only use this script to remove accounts that have been created using the script above as adverse side effects might be caused and a complete wipe of the SDK installation might be necessary.

Remove External Accounts

```
USE [DeveloperDynamic]
BEGIN

DECLARE @AccountNumber nvarchar(100), @AccountID bigint, @UserAccountID bigint, @RoutingNumberInfoID bigint
SET @AccountNumber = '1111111111111111' -- Change this to the test account number that you want to delete.
SET @AccountID = (select [ID] from [core].[Account] where [Number] = @AccountNumber)
SET @UserAccountID = (select [ID] from [core].[UserAccount] where [AccountID] = @AccountNumber)
SET @RoutingNumberInfoID = (select [RoutingNumberInfoID] from [core].[ExternalAccount] where [ID] = @AccountID)

--ExternalAccount
DELETE FROM [core].[ExternalAccount] WHERE [ID] = @AccountID
--RountingNumberInfo
DELETE FROM [core].[RoutingNumberInfo] WHERE [ID] = @RoutingNumberInfoID
--UserAccount
DELETE FROM [core].[UserAccount] WHERE [ID] = @UserAccountID
--Account
DELETE FROM [core].[Account] WHERE [ID] = @AccountID

END
```
