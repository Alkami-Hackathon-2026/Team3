#### pubspec.yaml

All packages required by Alkami Embedded are listed under the dependencies section in pubspec.yaml.

The dependencies in pubspec.yaml are based on the needs of Alkami Embedded. For example, Hanscom FCU makes use of Vertifi remote deposit capture, card management, and Glia video chat. Packages corresponding to each feature are included as dependencies in pubspec.lock.

#### brandedAssets

This directory contains files used by Alkami Embedded to support included features, such as API keys for certain package, and assets that identify the app as yours, such as images and color schemes.

configuration
This includes configuration settings for many functional component of Alkami Embedded, such as keys and certificates to access Alkami APIs and different API environments.

configuration/build_configuration.json
This includes parameters that effect the behavior of the app when it is built. It can be edited to change those behaviors.

- isStoreBuild: When true, the production environment is automatically used. It also disables the debug menu.
- isDebugEnabled: This enables or disables the debug menu, regardless of the environment.
- appVersion: The app version the app is built with. This can be used to test or bypass version checks which force the user to upgrade the app.
- buildDate: This determines if new runtime configurations need to be fetched. If the date is recent enough, it's assumed the app has already been built with up-to-date configurations.

fonts
Any fonts that should be used in place of the default.

images
Images the identify the financial institution: specifically, the launch image and the logo that appears on most pages.

l10n
If any localized strings used in Alkami Embedded needed to be customized, they would be defined here.

theme
This includes many visual settings particular to your needs: colors, button shapes, background images, supplemental logos, the appearance of the FDIC logo, etc.

Note* The theme found in brandedAssets/theme is a backup theme bundled into the application build. Alkami Embedded will download theme tokens from Alkami's ThemeBuilder APIs on app launch.

#### main.dart

The app entry point. The initial version of main.dart acts as an example for using Alkami Embedded, demonstrating the initialization of Alkami Embedded (https://confluence.alkami.com/spaces/SDKC/pages/538187050/Initializing+Alkami+Embedded) and push notification interceptors (https://confluence.alkami.com/spaces/SDKC/pages/538193730/Alkami+Embedded+Push+Notification+Interceptors).

#### global_scaffold.dart

A stateful widget that acts as an omnipresent event handler for any features that require manipulating the entire widget tree, such as showing bottom sheets or other UI overlays. This is typically necessary for Digital ID events or app lifecycle state changes.

#### dependency_service_impl.dart

An implementation of the Alkami DependencyService. This includes features to be prepared when Alkami Embedded is initialized (https://confluence.alkami.com/spaces/SDKC/pages/538187050/Initializing+Alkami+Embedded). Most of these features correspond to dependencies defined in pubspec.yaml, or client-specific configurations, such as CardHub.
