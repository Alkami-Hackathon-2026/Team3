SDK projects must be tracked across many teams and processes. Alkami has found our JIRA projects are useful to uniquely identify what project belongs to which financial institution. Generally, it is acceptable to use the abbreviated project code used to submit your SDK work.

Do not include the word Mobile in SDK project names. Including Mobile in the project Name will conflict with Alkami routing causing the widget to not display in mobile.

### What is my unique identifier?

It's the short name of your JIRA Client Services or Delivery project, depending on when you became a part of the Alkami family.

This is easy to find as it's the short combination of letters that are prefixed to tickets created in the JIRA project to which you have been granted access. If you're not sure, then ask sdksupport (/display/~sdksupport@alkamitech.com) for the proper name.

### Example

This is a test submission, notice the identifier at the top: Client Services: Test / CSTEST-154. In this case, CSTEST is the client's (for example, Financial Institution's) unique identifier for the Client Services: Test JIRA project.

All projects, titles, and namespaces should adhere to this prefix. For this widget submission, the proper name is CSTEST.Client.Widget.MemberServices.

Client Services (AM) Projects

Many clients have a JIRA project named Client Services that appends an AM (for Account Management) to the end of the JIRA project code. The previous example might have been CSTESTAM, in which case it's better to drop the AM so it reads as CSTEST.
