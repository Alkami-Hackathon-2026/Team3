This document contains resources that will teach you how to write Cypress Tests. It is recommended that you have gone through the setup steps in this confluence document: Installing VS Code and configuring Environment Locally (/pages/viewpage.action?pageId=132709297).

The following repository contains a project that you can use for some hands on training:

https://bitbucket.corp.alkami.net/projects/AI/repos/cypressworkshop/browse?at=refs%2Fheads%2Fdevelop (https://bitbucket.corp.alkami.net/projects/AI/repos/cypressworkshop/browse?at=refs%2Fheads%2Fdevelop)

The directions on the repository will explain how to pull the code and work through the tests. If you find yourself having issues with specific tests or you want to check your work, you can find the answers here:

https://bitbucket.corp.alkami.net/projects/AI/repos/cypressworkshop/browse?at=refs%2Fheads%2Fimplemented-tests (https://bitbucket.corp.alkami.net/projects/AI/repos/cypressworkshop/browse?at=refs%2Fheads%2Fimplemented-tests)
