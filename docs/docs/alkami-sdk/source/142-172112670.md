### Submission Review

Alkami will complete the initial code review and send to Forify On Demand for static code analysis (security validation).
The code review and the static code analysis examine the code for potential security exploits and incorrect coding practices that would cause application instability such as not closing streams. The submission will not be reviewed to determine if it meets the functional requirements, or even if the submission works. Any issues will be detailed in the ticket for the submitter to resolve. Once the submitter has resolved the issues, they will begin the submission process again. If additional issues are found, this process will repeat. Once the submission has been accepted, the package will be promoted to the submitter's private staging feed and scheduled for staging deployment.

- The SDK Component Type must be correct. When your build is confirmed to be stable and secure and your package is accepted, it is loaded to the Stage server for Staging Deployment.

Allow up to three weeks for the completion of code testing in the Stage server - staging environment.
Note: Build cannot go directly to production, you must have it installed in Stage first and tested for sign off that it is ready to go to production.
