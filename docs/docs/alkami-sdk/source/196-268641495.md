Sometimes it is useful to be able to access your SDK site from across the public Internet.

Generally speaking, you will need the following:

- A working SDK site
- A static internal IP address on your SDK machine
- Ability to configure your Internet firewall
- An available public static IP address from your ISP
- The ability to modify the hosts file on the machine that you want browse from.

This diagram depicts what you will need to do:

Narrative: in this example we will suppose the IP address of your SDK machine is 192.168.1.2 and your available public IP address is 12.1.2.3. You will need to create a static address mapping in your firewall to map that public IP address to the SDK's IP address, and allow port for 443 traffic in. Then you'll simply need to make a host file entry on the computer you will use, point the developer.dev.alkamitech.com name to that public IP address.

Note that in many cases, it is not possible to go out through your firewall and come right back into the same firewall. So this configuration works as long as that computer with the browser is located across the public Internet.
