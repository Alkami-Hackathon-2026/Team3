We have completely overhauled the curriculum and moved from a multi-day virtual session to a self-serve model via Alkami U. This new approach is more scalable and accessible. With this new self-serve model, participants can start their training at their convenience, making the process more flexible and efficient.

It is preferred that each participant has a computer or a virtual machine that can run the SDK (the requirements are listed in Hardware and Software Requirements (/spaces/SDKC/pages/55347103/Hardware+and+Software+Requirements) document). Non-developers are welcome to attend. Click the link below to view the SDK Training enrollment process.
