## REST Endpoints — Alkami StandardSSO Service (v1)
### SsoController
#### POST /v1/sso/validate
- Purpose: Validate an SSO configuration payload and return validation issues.
- Request DTO: ValidateSsoHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/ValidateSsoHttpRequest.cs)ConfigurationData (string) — JSON string containing a configuration.
- Response DTO: ValidateSsoResponse (Alkami.MicroServices.StandardSSO.Contracts/Responses/ValidateSsoResponse.cs)Inherits BaseResponseIssues (List of Issue) — each Issue.Message is a human-readable validation message.
#### POST /v1/sso/evaluate
- Purpose: Evaluate an SSO configuration and return the data needed to perform/launch the SSO action.
- Request DTO: GetSsoHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/GetSsoHttpRequest.cs)ProviderName (string)Parameters (Parameters) — key/value or typed parameter object used by the provider.
- Response DTO: GetSsoHttpResponse (Alkami.MicroServices.StandardSSO.Contracts/Responses/GetSsoHttpResponse.cs)State (State) — execution state (engine-specific).FdicConfiguration (FdicConfiguration) — FDIC-related flags (see IsSpeedBumpRequired).DataSets (DataSet) — Accounts (List<Guid>), Cards (List<Card>), Options (List<Option>).RenderResult (RenderResult) — contains AutoLaunch (bool), Uri (URI), Headers (map), ContentType, Body, FormFields, Thumbprint.
#### POST /v1/sso/playground/evaluate
- Purpose: Evaluate SSO in the admin playground with optional OverrideConfig to test changes.
- Auth: Test Users jwt, not admin
- Request DTO: GetSsoPlaygroundHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/GetSsoPlaygroundHttpRequest.cs)ProviderName (string)Parameters (Parameters)OverrideConfig (string) — optional JSON string overriding stored configuration.
- Response DTO: GetSsoHttpResponse (same shape as /v1/sso/evaluate).
#### GET /v1/sso/playground/users?query={q}
- Purpose: Lookup users for playground/testing UI.
- Auth: Must be admin
- Request: query string query (string)
- Response DTO: UserLookupResponse (Alkami.MicroServices.StandardSSO.Contracts/Responses/UserLookupResponse.cs)Success (bool)Users (List of UserLookupResult) — Id, UserIdentifier (Guid), DisplayName, LoginId, CustomerId, BusinessName, booleans indicating business/subuser.IsValid (bool)
### TemplatesController
#### GET /v1/templates
- Purpose: Retrieve a paginated list of templates.
- Query params:includeValue (bool) — include Configuration JSON in results.includeDisabled (bool) — include disabled templates.pageIndex (int) — default 0.pageSize (int) — default 100.
- Response DTO: TemplateResponse (BaseResponse<Template>)Each Template includes:Id (int)Name (string)Configuration (string) — JSON blob if requestedCreatedDate, LastUpdateDate, LastModifiedBy, ConversionProviderName, ConversionWidgetAssemblyInfo, Disabled (bool)
#### GET /v1/templates/{id}
- Purpose: Get a single template by id.
- Path: id (int)
- Success: 200 with Template, 404 if not found.
#### POST /v1/templates/search
- Purpose: Search templates with filters/sorter/mapper.
- Request DTO: SearchTemplatesHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/SearchTemplatesHttpRequest.cs)Filter (TemplateFilter)Mapping (TemplateMapper)Sorter (TemplateSorter)PageIndex (int, default 0)PageSize (int, default 100)
### ConfigurationsController
#### GET /v1/configurations
- Purpose: Retrieve paginated configurations.
- Query params:includeValue (bool) — include Value JSON string.pageIndex (int) default 0pageSize (int) default 100
- Response DTO: ConfigurationResponse (BaseResponse<Configuration>)Configuration fields:Id (int)ProviderName (string)Value (string) — JSON blob of the configurationCreatedDate, LastModifiedDate, TemplateId
#### GET /v1/configurations/{id}
- Purpose: Get a single configuration by id.
- Path: id (int)
- Success: 200 with Configuration, 404 if not found.
#### POST /v1/configurations/search
- Purpose: Search configurations.
- Request DTO: SearchConfigurationsHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/SearchConfigurationsHttpRequest.cs)Filter (ConfigurationFilter)Mapping (ConfigurationMapper)Sorter (ConfigurationSorter)PageIndex (int)PageSize (int, default 100)
- Response: ConfigurationResponse shape.
#### POST /v1/configurations
- Purpose: Create a configuration.
- Request DTO: CreateConfigurationHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/CreateConfigurationHttpRequest.cs)Item (Configuration) — new configuration object (ProviderName, Value, ...).WidgetSettings (WidgetSettings) — optional
- Successful response: 201 Created with ConfigurationResponse containing created item(s).
#### PUT /v1/configurations/{id}
- Purpose: Update existing configuration by id. Controller validates Item.Id == id.
- Path: id (int)
- Request DTO: UpdateConfigurationHttpRequest (Alkami.MicroServices.StandardSSO.Service.Host/Models/UpdateConfigurationHttpRequest.cs)Item (Configuration) — must include an Id that matches path.WidgetSettings (optional)
- Success: 200 with ConfigurationResponse; 400 for mismatched id or validation issues.
#### GET /v1/configurations/{configurationId}/history
- Purpose: Get history entries for a configuration (audit).
- Path: configurationId (int)
- Response DTO: ConfigurationHistoryResponse (BaseResponse<ConfigurationHistory>)ConfigurationHistory fields: Id (long), ConfigurationId, OldValue, NewValue, OldProviderName, NewProviderName, CreatedDate, ChangeNotes
#### POST /v1/configurations/history-search
- Purpose: Search configuration history.
- Request DTO: SearchConfigurationHistoryHttpRequest (Alkami.MicroServices.StandardSSO.Contracts/Requests/SearchConfigurationHistoryHttpRequest.cs)Filter (ConfigurationHistoryFilter)Mapping (ConfigurationHistoryMapper)Sorter (ConfigurationHistorySorter)PageIndex, PageSize (default 100)
- Response: ConfigurationHistoryResponse shape.
