### Update to jQuery 3.5.0

We have updated the underlying jQuery version in the platform to v3.5.0. You can follow the official jQuery upgrade guide at https://jquery.com/upgrade-guide/3.5/ (https://jquery.com/upgrade-guide/3.5/).

### Security Scans for C# and JavaScript

As Alkami continues to scale up and out we find it more important than ever to protect our clients from nefarious code. The SDK team will be increasing the security thresholds of project submissions to better address some of the industry expectations when it comes to code security. It is possible that projects in the past will no longer meet the minimum security requirements that Alkami is setting forth for itself and their clients. The SDK team is dedicated to working with your through any refactoring that may come of a failing security scan and will not impose any subsequent costs when assisting with the mitigation strategies recommended by our security vendors.

Please reach out to Brent Dowdy [X] (/display/~bdowdy) with any questions.

### Add Your Widget Name To AlkamiManifest.xml

The AlkamiManifest.xml will be playing a more centralized role in how we process and deploy your projects. As of 2020.04, your widget "Display Name" will need to be present in the AlkamiManifest.xml as the "Widget Name" value. Currently, this is the name of your Visual Studio project and will need to be update to the proper human friendly display name.

Code Review and Future Automation Requirements

The SDK team will be adding "Suggestions" to submissions that do not have the WidgetName value set properly in the AlkamiManifest.xml. This will change soon as we begin to leverage a more automated code review process and the "Suggestion" will become a "NeedsWork," requiring another submission to make the correction.

### Submitting Configurations

We've remove the need to submit configurations as part of the SDK submission process. As of now, when you submit a new project, we will automatically create the configuration for your project and verify the values with you if we feel that's necessary. Changes to existing configuration can be requested in the description of any SDK submission ticket and we will accommodate or advise on how to complete that task.

As noted above, there will be an ongoing effort to transition more information to the AlkamiManifest.xml so that we can make the submission process more user friendly for the developer.

### Updates to SDK Machine Setup

New Install Command

If you would like to have the expected list of features that have been delivered in the previous releases, you must now run this command in place of the old one.

```
choco upgrade alkami.machinesetup.sdk.features -y
```

Moving forward, developers will install the SDK Features package in place of the previous Machine Setup SDK package. In the past, when you ran an install of the Alkami.MachineSetup.SDK package a full set of feature packages were installed in addition to the foundational services and libraries that make up the underlying framework. The SDK team has separated the platform services and modules from the full set of feature products so that we can better track our required platform packages and our optional feature packages.

In the 2020.04 release, the Alkami.MachineSetup.SDK Chocolatey package will remove Alkami product features so that the machine setup SDK package represents a minimum list of requirements that will allow a Brady user to login to the DeveloperDynamic instance of Alkami's platform.

### SDK Features Package

The SDK Features package is a set of feature products that were previously installed using the machine setup SDK package but are now installed in addition to the SDK machine setup. To better support custom environments, the SDK team has removed that list from the base SDK install and into their own features package. This will only change what package an SDK developer will install, there have not been any changes to the list of features we would expect to see when installing the sdk.

To update your SDK to the latest release, run this command to install the SDK Features package and the dependent Machine Setup SDK base package. The Alkami.MachineSetup.SDK is a dependency of the new SDK Features package, this means you only have to install the Features package going forward.

```
choco upgrade alkami.machinesetup.sdk.features -y
```
